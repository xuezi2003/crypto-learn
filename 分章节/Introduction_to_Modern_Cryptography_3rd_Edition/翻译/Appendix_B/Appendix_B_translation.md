**定理 B.1**（整数运算）给定整数 $a$ 和 $b$，可以在关于 $\|a\|$ 与 $\|b\|$ 的多项式时间内完成以下运算：

1. 计算和 $a + b$ 与差 a - b；

2. 计算乘积 $ab$；

3. 计算正整数 $q$ 与 $r < b$，使得 $a = qb + r$（即计算带余除法）；

4. 计算 $a$ 和 $b$ 的最大公因数 $gcd(a, b)$；

5. 计算整数 $X, Y$，使得 $Xa + Yb = \gcd(a, b)$。

以下结果在附录 B.2 中证明：

**定理 B.2**（模运算）给定整数 $N > 1$、$a$ 和 $b$，可以在关于 $\|a\|$、$\|b\|$ 与 $\|N\|$ 的多项式时间内完成以下运算：

1. 计算模约减 [a mod $N$]；

2. 计算和 $[(a+b)\bmod N]$、差 $[(a-b)\bmod N]$ 与积 $[ab\bmod N]$；

3. 判定 $a$ 在模 $N$ 下是否可逆，若可逆则计算乘法逆元 $[a^{-1} \bmod N]$；

4. 进行指数运算 $[a^{b} \bmod N]$。

下面把定理 B.2(5) 推广到任意群：

**定理 B.3**（群中的指数运算）设 $G$ 是一个群，按乘法记号书写。设 $g$ 是群中的一个元素，$b$ 是一个非负整数。则 $g^b$ 可以用 $\mathsf{poly}(\|b\|)$ 次群运算计算出来。

**定理 B.4**（选取均匀元素）存在一个随机化算法，具有以下性质：以 N 为输入，

- 该算法在关于 $\|N\|$ 的多项式时间内运行；

- 该算法以关于 $\|N\|$ 可忽略的概率输出 fail；且

- 在不输出 fail 的条件下，该算法输出 $\mathbb{Z}_N$ 中一个均匀分布的元素。

对 $\mathbb{Z}_N^*$ 也存在具有类似性质的算法。

由于上述定理所引用的两个算法输出 fail 的概率是可忽略的，我们忽略这种可能性（并把它留作隐含处理）。在附录 B.2 中，我们还讨论上述结论到从任意有限群中选取均匀元素的推广（对群元素的表示有某些要求）。

以下结果的证明在附录 B.3 中：

**定理 B.5**（测试与寻找生成元）设 $G$ 是一个阶为 $q$ 的循环群，并假定群运算与均匀选取群元素可以在单位时间内完成。

1. 存在一个算法，以 $q$、$q$ 的素因子分解和一个元素 $g \in \mathbb{G}$ 为输入，在 $\mathsf{poly}(\|q\|)$ 时间内运行，并判定 $g$ 是否是 $\mathbb{G}$ 的生成元。

2. 存在一个随机化算法，以 $q$ 和 $q$ 的素因子分解为输入，在 $\mathsf{poly}(\|q\|)$ 时间内运行，并且除一个关于 $\|q\|$ 可忽略的概率外，输出 $\mathbb{G}$ 的一个生成元。在输出是生成元的条件下，它在 $\mathbb{G}$ 的生成元中均匀分布。

## B.1 整数运算

### B.1.1 基本运算

我们对算法数论的探索，从讨论整数的加法/减法、乘法与带余除法开始。稍加思考即可发现，用解决这些问题的标准“小学”算法（grade-school algorithms），所有这些运算都可以在关于输入长度的多项式时间内完成。例如，两个正整数 $a$ 和 $b$（$a > b$）的加法，可以逐位扫描 $a$ 和 $b$ 的比特（从低位比特开始），在每一步计算出相应的输出比特和一个“进位比特”，从而在关于 $\|a\|$ 的线性时间内完成。（细节从略。）再以两个 $n$ 比特整数 $a$ 和 $b$ 的乘法为例：可以先产生一张由 $n$ 个长度至多为 ${2}n$ 的整数组成的表（其中每个整数等于 $a \cdot 2^{i-1} \cdot b_i$，$b_i$ 是 $b$ 的第 $i$ 个比特），然后把这 $n$ 个整数相加得到最终结果。（带余除法的有效实现要棘手一些，但同样可以做到。）

虽然这些小学算法足以证明前述问题可以在多项式时间内求解，但有趣的是，这些算法在某些情形下并非现有最好的算法。例如，上面给出的简单乘法算法用 $\mathcal{O}(n^2)$ 时间乘两个 $n$ 比特数，但存在一个运行时间为 $\mathcal{O}(n^{\log_2 3})$ 的更好的算法（而且那也还不是最好的）。对我们日常遇到的数的大小而言，这种差异微不足道；但当数很大时，差异就变得明显了。在密码学应用中，使用长达数千比特的整数（即 $n > 1000$）并不罕见，此时审慎地选择使用哪些算法就变得至关重要。

### B.1.2 欧几里得算法与扩展欧几里得算法

回忆 9.1 节的定义：两个整数 $a$ 和 $b$ 的最大公因数 $\gcd(a,b)$ 是同时整除 $a$ 和 $b$ 的最大整数 $d$。我们陈述一个关于最大公因数的简单命题，然后说明它如何导出计算 $\gcd$ 的高效算法。

**命题 B.6** 设 $a, b > 1$ 且 $b \nmid a$。则

$$\gcd(a,b)=\gcd(b,[a\bmod b]).$$

**证明** 若 $b > a$，结论是显然的；所以，假定 $a > b$。把 $a$ 写成 $a = qb + r$，其中 $q, r$ 是正整数且 $r < b$（参见命题 9.1）；注意 $r > 0$，因为 $b \nmid a$。由于 $r = [a \bmod b]$，只需证明 $\gcd(a, b) = \gcd(b, r)$。

该结论成立，因为对任意正整数 $d$ 有

$$d\mid a \text{ and } d\mid b\Longleftrightarrow d\mid(a-q b)\text{ and } d\mid b,$$

而 $r = a - qb$。

上述讨论启发我们给出递归的欧几里得算法（算法 B.7），用于计算两个整数 $a$ 和 $b$ 的最大公因数 $\gcd(a, b)$。算法的正确性由命题 B.6 直接得出。至于其运行时间，我们在下面证明：在输入 $(a, b)$ 上，算法进行的递归调用少于 ${2} \cdot \|b\|$ 次。由于检查 $b$ 是否整除 $a$ 以及计算 $[a \bmod b]$ 都可在关于 $\|a\|$ 与 $\|b\|$ 的多项式时间内完成，这蕴含整个算法在多项式时间内运行。

| 算法 B.7 |
| --- |
| 欧几里得算法 GCD |
| 输入：整数 $a$、$b$，满足 $a \ge b > 0$ |
| 输出：$a$ 和 $b$ 的最大公因数 |
| if $b$ 整除 $a$ |
| return $b$ |
| else return GCD $(b, [a \mod b])$ |

**命题 B.8** 考虑一次执行 $\mathsf{GCD}(a_0, b_0)$，其中 $a_0 \geq b_0 > 0$，并设 $a_i, b_i$（$i = 1, \ldots, \ell$）表示 $\mathsf{GCD}$ 的第 $i$ 次递归调用的参数。则对 ${0} \leq i \leq \ell - 2$，有 $b_{i+2} \leq b_i/2$。

**证明** 首先注意，对任意 $a > b$，有 $[a \bmod b] < a/2$。为看清这一点，考虑两种情形：若 $b \leq a/2$，则 $[a \bmod b] < b \leq a/2$ 是显然的。另一方面，若 $b > a/2$，则 $[a \bmod b] = a - b < a/2$。

现在固定满足 ${0} \leq i \leq \ell - 2$ 的任意 $i$。则 $b_{i+2} = [a_{i+1} \bmod b_{i+1}] < a_{i+1}/2 = b_i/2$。

**推论 B.9** 在算法 $\mathsf{GCD}(a,b)$ 的一次执行中，对 $\mathsf{GCD}$ 的递归调用至多有 ${2} \|b\| - 2$ 次。

**证明** 设 $a_i, b_i$（$i = 1, \ldots, \ell$）表示 GCD 的第 $i$ 次递归调用的参数。$\{b_i\}$ 始终大于零，并且一旦出现 $b_i = 1$，算法就不再作进一步的递归调用（因为此时 $b_i \mid a_i$）。上一命题表明，$\{b_i\}$ 每两次迭代至少按因子 2 递减。由此推出，对 GCD 的递归调用次数至多为 ${2} \cdot (\|b\| - 1)$。

由命题 9.2 可知，对正整数 $a, b$，存在整数 $X, Y$ 使得 $Xa + Yb = gcd(a, b)$。对欧几里得算法作一个简单修改，称为扩展欧几里得算法，除了计算 $\gcd(a, b)$ 之外还可以求出 $X, Y$；参见算法 B.10。习题 B.1 要求你证明扩展欧几里得算法的正确性，习题 B.2 要求你证明该算法在多项式时间内运行。

```
算法 B.10
扩展欧几里得算法 eGCD

输入：整数 $a, b$，满足 $a \geq b > 0$
输出：$(d, X, Y)$，满足 $d = \gcd(a, b)$ 且 $Xa + Yb = d$

if b 整除 a
    return (b, 0, 1)
else
    计算整数 $q, r$，满足 $a = qb + r$ 且 ${0} < r < b$
    (d, X, Y) := eGCD(b, r)        // 注意 Xb + Yr = d
    return (d, Y, X - Yq)
```

## B.2 模运算

我们现在把注意力转向模 $N > 1$ 的基本算术运算。我们用 $\mathbb{Z}_N$ 既表示集合 $\{0, \ldots, N-1\}$，也表示通过考虑该集合元素之间的模 N 加法所得的那个群。

### B.2.1 基本运算

整数上基本算术运算的高效算法立即蕴含模 $N$ 上相应算术运算的高效算法。例如，通过计算整数上的带余除法，可以在关于 $\|a\|$ 与 $\|N\|$ 的多项式时间内计算模约减 $[a \mod N]$。接下来考虑对两个元素 $a, b \in \mathbb{Z}_N$ 的模运算，其中 $\|N\| = n$。（注意 $a, b$ 的长度至多为 $n$。实际上，方便的做法是直接假定 $\mathbb{Z}_N$ 的所有元素长度都恰好为 $n$，必要时在左侧补 ${0}s$。）$a$ 与 $b$ 的模 N 加法可以先计算 $a + b$（一个长度至多为 $n + 1$ 的整数），再把这个中间结果对 $N$ 约减。类似地，模 N 乘法可以先计算长度至多为 ${2}n$ 的整数 $ab$，再对结果模 $N$ 约减。由于加法、乘法和带余除法都可以在多项式时间内完成，这些给出了模 $N$ 加法与乘法的多项式时间算法。

### B.2.2 计算模逆

到目前为止的讨论说明了如何在模 N 下进行加、减、乘。我们还缺的一种运算是“除法”，或者等价地，计算模 N 的乘法逆元。回忆 9.1.2 节的定义：元素 $a \in \mathbb{Z}_N$ 的（模 N）乘法逆元是满足 $a \cdot a^{-1} = 1 \mod N$ 的元素 $a^{-1} \in \mathbb{Z}_N$。命题 9.7 表明，$a$ 有逆元当且仅当 $\gcd(a, N) = 1$，即当且仅当 $a \in \mathbb{Z}_N^*$。因此，利用欧几里得算法，我们可以容易地判定给定元素 $a$ 在模 N 下是否有乘法逆元。

给定 $N$ 和满足 $\gcd(a, N) = 1$ 的 $a \in \mathbb{Z}_N$，命题 9.2 告诉我们存在整数 $X, Y$ 使得 $Xa + YN = 1$。这意味着 $[X \bmod N]$ 是 $a$ 的乘法逆元。满足 $Xa + YN = 1$ 的整数 $X$ 和 $Y$ 可以用上面所示的扩展欧几里得算法 eGCD 高效地求出。

| 算法 B.11 |
| --- |
| 计算模逆元 |
| 输入：模数 $N$；元素 a |
| 输出：$[a^{-1} \mod N]$（若存在） |
| $(d, X, Y)$ := eGCD $(a, N)$    // 注意 $Xa + YN = \gcd(a, N)$ |
| if $d \neq 1$ return “a 在模 $N$ 下不可逆” |
| else return [X mod $N]$ |

这导出了计算乘法逆元的多项式时间算法（算法 B.11）。

### B.2.3 模指数运算

一个更有挑战性的任务是模 $N$ 下的指数运算，即对底数 $a \in \mathbb{Z}_N$ 与整数指数 $b > 0$ 计算 $[a^b \bmod N]$。（当 $b = 0$ 时问题是容易的。当 $b < 0$ 且 $a \in \mathbb{Z}_N^*$ 时，$a^b = (a^{-1})^{-b} \bmod N$，鉴于我们可以计算逆元（如上一节所述），问题就归结为正指数的指数运算。）注意加法和乘法所用的基本方法（即计算整数 $a^b$，再把中间结果对模 N 约减）在这里行不通：整数 $a^b$ 的长度为 $\|a^b\| = \Theta(\log a^b) = \Theta(b \cdot \|a\|)$，因此即使存储中间结果 $a^b$ 也需要关于 $\|b\| = \Theta(\log b)$ 的指数时间。

我们可以通过在整个计算的每个中间步骤都对模 N 约减、而不是只在最后对模 N 约减来解决这个问题。这样做的效果是使中间结果在计算过程中始终保持“小”。即便有了这个重要的初步观察，设计模指数运算的多项式时间算法仍然并非易事。考虑算法 B.12 的朴素做法，它只是执行 $b$ 次乘以 $a$。这仍然需要关于 $\|b\|$ 的指数时间。

```
算法 B.12
模幂的朴素算法

输入：模数 $N$；底数 $a \in \mathbb{Z}_N$；整数指数 $b > 0$
输出：[a^b mod N]

x := 1
for i = 1 to b:
    x := [x · a mod N]
return x
```

这个朴素算法可以看作依赖于如下递推式：

$$[a^{b}\bmod N]=[a\cdot a^{b-1}\bmod N]=[a\cdot a\cdot a^{b-2}\bmod N]=\cdots$$

任何基于该关系的算法都需要 $\Theta(b)$ 时间。改用如下递推式可以做得更好：

$$[a^{b}\bmod N]=\left\{\begin{matrix}{\left[\left(a^{\frac{b}{2}}\right)^{2}\bmod N\right]}&{{\mathrm{when~}}b{\mathrm{~is~even}}}\\ {\left[a\cdot\left(a^{\frac{b-1}{2}}\right)^{2}\bmod N\right]}&{{\mathrm{when~}}b{\mathrm{~is~odd}}.}\\ \end{matrix}\right.$$

这样做导出了一个算法——出于显而易见的原因，被称为“平方-乘”（square-and-multiply）（或“反复平方”）——它只需要 $\mathcal{O}(\log b) = \mathcal{O}(\|b\|)$ 次模平方/乘法；参见算法 B.13。在该算法中，$b$ 的长度每次迭代减少 1；由此可知迭代次数为 $\|b\|$，因此整个算法在关于 $\|a\|$、$\|b\|$ 与 $\|N\|$ 的多项式时间内运行。更精确地说，模平方的次数恰好是 $\|b\|$，额外模乘法的次数恰好是 $b$ 的汉明重量（Hamming weight），即 $b$ 的二进制表示中 1 的个数。这就解释了 9.2.4 节所讨论的偏好：选择 RSA 公钥指数 $e$ 时希望它有较小的长度/汉明重量。

```
算法 B.13
高效模幂算法 ModExp

输入：模数 $N$；底数 $a \in \mathbb{Z}_N$；整数指数 $b > 0$
输出：[a^b mod N]

x := a
t := 1
// 维持不变量：答案为 $[t \cdot x^b \bmod N]$
while b > 0 do:
    if b 是奇数
        t := [t · x mod N], b := b - 1
    x := [x^2 mod N], b := b/2
return t
```

固定 $a$ 和 $N$，考虑由 $f_{a,N}(b)=[a^{b}\bmod N]$ 给出的模幂函数。我们刚刚看到计算 $f_{a,N}$ 是容易的。相反，计算这个函数的逆——即给定 $a$、$N$ 和 $[a^{b}\bmod N]$ 求 $b$——对适当选择的 $a$ 和 $N$ 被认为是困难的。求该函数的逆需要求解离散对数问题，我们将在 9.3.2 节详细讨论。

**利用预计算。**

如果底数 $a$ 事先已知，并且指数 $b$ 的长度有界，那么可以利用预计算和少量内存来加速 $[a^b \bmod N]$ 的计算。设 $\|b\| \leq n$。则我们预计算并存储 $n$ 个值

$$x_{0}:=a,\quad x_{1}:=[a^{2}\bmod N],\quad\ldots,\quad x_{n-1}:=[a^{2^{n-1}}\bmod N].$$

给定二进制表示为 $b_{n-1} \cdots b_0$（从最高位到最低位书写）的指数 $b$，我们有

$$a^{b}=a^{\sum_{i=0}^{n-1}2^{i}\cdot b_{i}}=\prod_{i=0}^{n-1}x_{i}^{b_{i}}\bmod N.$$

由于 $b_i \in \{0,1\}$，计算该结果所需的乘法次数恰好比 $b$ 的汉明重量少 1。

#### 任意群中的指数运算

上面给出的模指数运算高效算法可以直接推广，只要底层的群运算可以高效执行，就能在任何群中进行高效的指数运算。具体地说，若 $\mathbb{G}$ 是一个群且 $g$ 是 $\mathbb{G}$ 中的一个元素，则 $g^b$ 可以用至多 ${2} \cdot \|b\|$ 次底层群运算计算出来。也可以像上面描述的那样使用预计算。

若 $\mathbb{G}$ 的阶 $q$ 已知，则 $a^b = a^{[b \bmod q]}$（参见命题 9.53），因此可先对 $b$ 模 $q$ 约减来加速计算。

考虑（加法）群 $\mathbb{Z}_N$，刚才描述的群指数运算算法给出了一种计算“指数运算”

$$[b\cdot g\bmod N]\stackrel{\operatorname{def}}{=}[\underbrace{g+\cdots+g}_{b\text{ times}}\bmod N]$$

的方法，它与前面讨论的依赖于标准整数乘法后接模约减的方法不同。在比较求解同一问题的两种方法时，注意原来的算法使用了关于 $\mathbb{Z}_N$ 的特定信息；特别是，它（本质上）把“指数” $b$ 当作 $\mathbb{Z}_N$ 的一个元素（可能先把 $b$ 模 $N$ 约减）。相比之下，刚才给出的“平方-乘”算法只把 $\mathbb{Z}_N$ 当作一个抽象群。（当然，模 N 加法这一群运算仍依赖于 $\mathbb{Z}_N$ 的具体性质。）这段讨论只是想说明：有些群算法是通用的（即它们同样适用于所有群），而有些群算法则依赖于某个特定群或某类群的具体性质。我们在第 10 章看到过这种现象的一些例子。

### B.2.4 \*蒙哥马利乘法

虽然整数上的除法（从而模约减）可以在多项式时间内完成，但与整数乘法等算法相比，整数除法算法是缓慢的。蒙哥马利乘法提供了一种执行模乘法而无需任何昂贵的模约减的方法。由于需要预处理与后处理，该方法只有在连续执行多次模乘法时才有利，例如在计算模指数运算时。

固定一个奇模数 $N$，模运算都将在其上进行。设 $R > N$ 是 2 的幂，比如 $R = 2^w$，并注意 $\gcd(R, N) = 1$。我们将利用的关键性质是除以 $R$ 是很快的：$x$ 除以 $R$ 的商只需把 $x$ 右移 $w$ 位即可得到，而 $[x \bmod R]$ 就是 $x$ 的最低 $w$ 位。

定义 $x \in \mathbb{Z}_N^*$ 的蒙哥马利表示为 $\bar{x} \overset{\mathrm{def}}{=} [xR \bmod N]$。$\bar{x}, \bar{y} \in \mathbb{Z}_N^*$ 的蒙哥马利乘法定义为

$$Mont(\bar{x},\bar{y})\stackrel{\mathrm{def}}{=}[\bar{x}\bar{y}R^{-1}\bmod N].$$

（我们在下面说明如何在不做任何昂贵模约减的情况下计算它。）注意

$$Mont(\bar{x},\bar{y})=\bar{x}\bar{y}R^{-1}=(x R)(y R)R^{-1}=(x y)R=\overline{x y}\bmod N.$$

这意味着我们可以在 $\mathbb{Z}_N$ 中把多个值相乘，做法是：(1) 转换到蒙哥马利表示，(2) 用蒙哥马利乘法完成所有乘法得到最终结果，然后 (3) 把结果从蒙哥马利表示转换回标准表示。

设 $\alpha \stackrel{\mathrm{def}}{=} [-N^{-1} \bmod R]$，这个值可以预计算。（$\alpha$ 的计算，以及蒙哥马利表示与标准表示之间的相互转换，也都可以在不做任何昂贵模约减的情况下完成；细节超出本书范围。）要在不做任何昂贵模约减的情况下计算 $c \stackrel{\mathrm{def}}{=} \text{Mont}(x, y)$，按如下步骤进行：

1. 令 $z := x \cdot y$（在整数上）。

2. 令 $c^{\prime} := (z + [z\alpha \bmod R] \cdot N) / R$。

3. 若 $c^{\prime} < N$，则令 $c := c^{\prime}$；否则令 $c := c^{\prime} - N$。

为看清它为什么有效，我们首先需要验证第 2 步是良定义的，即分子能被 $R$ 整除。这是因为

$$z+[z\alpha\bmod R]\cdot N=z+z\alpha N=z-z N^{-1}N=0\bmod R.$$

接下来，注意第 2 步之后有 $c^{\prime} = z/R \bmod N$；此外，由于 $z < N^2 < RN$，有 ${0} < c^{\prime} < (z + RN)/R < 2RN/R = 2N$。于是，当 $c^{\prime} < N$ 时 $[c^{\prime} \bmod N] = c^{\prime}$，当 $c^{\prime} > N$ 时 $[c^{\prime} \bmod N] = c^{\prime} - N$。我们得出结论

$$c=[c^{\prime}\bmod N]=[z/R\bmod N]=[x y R^{-1}\bmod N],$$

正如所愿。

### B.2.5 均匀选取群元素

在密码学应用中，常常需要均匀选取一个群 $\mathbb{G}$ 的元素。我们首先在抽象框架下处理该问题，然后专门关注 $\mathbb{Z}_N$ 和 $\mathbb{Z}_N^*$ 的情形。

注意，若 $\mathbb{G}$ 是阶为 $q$ 的循环群，且已知一个生成元 $g \in \mathbb{G}$，那么均匀选取元素 $h \in \mathbb{G}$ 就归结为均匀选取整数 $x \in \mathbb{Z}_q$ 并令 $h := g^x$。在下面的讨论中，我们对 $\mathbb{G}$ 不作任何假设。

群 $\mathbb{G}$ 的元素必须通过某种将其表示为比特串的表示方式来指明，我们不失一般性地假定所有元素都用等长的串来表示。（每个群元素恰好对应一个唯一的串，这一点也至关重要。）例如，若 $\|N\| = n$，则 $\mathbb{Z}_N$ 的所有元素都可以表示为长度 $n$ 的串，当 $\|a\| < n$ 时，整数 $a \in \mathbb{Z}_N$ 需在左侧补 ${0}s$。

我们不会过多关注表示的问题，因为对本书考虑的所有群，表示只需取“自然”的那一种即可（如上面 $\mathbb{Z}_N$ 的情形）。但要注意，同一个群的不同表示会影响执行各种计算的复杂度，因此在实际中为给定群选择“正确”的表示往往很重要。由于我们的目标只是为所需的每种运算给出多项式时间算法（而不是给出已知最有效的算法），对我们而言，具体采用哪种表示并不那么重要。此外，我们给出的大多数“高层”算法都以“黑盒”方式使用群运算，因此只要群运算可以在（某个参数的多项式）时间内完成，所得算法也会在多项式时间内运行。

给定一个元素用长度为 $\ell$ 的串表示的群 $G$，可以通过反复选取均匀的 $\ell$ 比特串，直到找到第一个对应群元素的串，来选取一个均匀群元素。（注意这假定可以高效地测试群成员关系。）为了得到有界运行时间的算法，我们引入参数 $t$ 限制这个过程重复的最大次数；若全部 $t$ 次迭代都没有找到 G 中的元素，则算法输出 fail。（另一种选择是输出 $G$ 的任意一个元素。）即：

```
算法 B.14
均匀选取群元素

输入：群 G 的描述；长度参数 ℓ；参数 t
输出：$G$ 的一个均匀元素
for i = 1 to t:
    均匀选取 $x \in \{0,1\}^\ell$
    if $x \in G$ return $x$
return "fail"
```

显然，只要上述算法不输出 fail，它就输出 $\mathbb{G}$ 中一个均匀分布的元素。这仅仅是因为 $\mathbb{G}$ 的每个元素在任何一次迭代中被选中的可能性都相同。形式化地，若设 $\mathbb{F}_{all}$ 是算法输出 fail 这一事件，则对任意元素 $g \in \mathbb{G}$ 有

$$\Pr\left[\text{output of the algorithm equals}g\mid\overline{{\mathsf{Fail}}}\right]=\frac{1}{|\mathbb{G}|}.$$

算法输出 fail 的概率是多少？任何一次迭代中 $x \in \mathbb{G}$ 的概率恰好是 $|\mathbb{G}|/2^\ell$，因此在全部 $t$ 次迭代中 $x$ 都不属于 $\mathbb{G}$ 的概率为

$$\left(1-\frac{|\mathbb{G}|}{2^\ell}\right)^{t}.$$

算法 B.14 的运行时间与算法输出 fail 的概率之间存在权衡：增大 $t$ 会降低失败概率，但会增加最坏情形运行时间。对密码学应用，我们需要一个最坏情形运行时间是安全参数 $n$ 的多项式、而失败概率关于 $n$ 可忽略的算法。令 $K \stackrel{\mathrm{def}}{=} 2^{\ell}/|\mathbb{G}|$。若取 $t := K \cdot n$，则算法输出 fail 的概率为：

$$\left(1-\frac{1}{K}\right)^{K\cdot n}=\left(\left(1-\frac{1}{K}\right)^{K}\right)^{n}\leq\left(e^{-1}\right)^{n}=e^{-n},$$

这里用到了命题 A.2。因此，若 $K = \mathsf{poly}(n)$（我们假定存在某种依赖于安全参数 $n$ 的群生成算法，因此 $|\mathbb{G}|$ 和 $\ell$ 都是 $n$ 的函数），我们就得到具有所需性质的算法。

$\mathbb{Z}_N$ 的情形。考虑群 $\mathbb{Z}_N$，其中 $n = \|N\|$。检查一个 $n$ 比特串 $x$（解释为长度至多为 $n$ 的正整数）是否是 $\mathbb{Z}_N$ 的元素，只需检查 $x < N$ 是否成立。此外，

$$\frac{2^{n}}{\left|\mathbb{Z}_{N}\right|}=\frac{2^{n}}{N}\leq\frac{2^{n}}{2^{n-1}}=2,$$

因此我们可以在 $\mathsf{poly}(n)$ 时间内、以关于 $n$ 可忽略的失败概率，采样 $\mathbb{Z}_N$ 的一个均匀元素。

$\mathbb{Z}_N^*$ 的情形。接下来考虑群 $\mathbb{Z}_N^*$，仍取 $n = \|N\|$。判定一个 $n$ 比特串 $x$ 是否是 $\mathbb{Z}_N^*$ 的元素也是容易的（见习题）。此外，

$$\frac{2^{n}}{\left|\mathbb{Z}_{N}^{*}\right|}=\frac{2^{n}}{\phi(N)}=\frac{2^{n}}{N}\cdot\frac{N}{\phi(N)}\leq2\cdot\frac{N}{\phi(N)}.$$

$\mathsf{poly}(n)$ 上界是如下定理的一个推论。

**定理 B.15** 对长度为 $n$ 的 $N \geq 3$，有 $\frac{N}{\phi(N)} < 2n$。

（已知更强的界，但上述界对我们的目的已经足够。）该定理可以用伯特兰假设（定理 9.32）来证明，但我们满足于证明两个特殊情形：$N$ 为素数的情形，以及 $N$ 为两个等长（不同）素数之积的情形。

当 N 是奇素数时，分析是容易的。此时 $\phi(N) = N - 1$，故

$$\frac{N}{\phi(N)}\leq\frac{2^{n}}{\phi(N)}=\frac{2^{n}}{N-1}\leq\frac{2^{n}}{2^{n-1}}=2$$

（第二个不等式用到了 N 是奇数这一事实）。接下来考虑 $N = pq$ 的情形，其中 $p$ 和 $q$ 是不同的奇素数。则

$$\frac{N}{\phi(N)}=\frac{pq}{(p-1)(q-1)}=\frac{p}{p-1}\cdot\frac{q}{q-1}<\left(\frac{3}{2}\right)\cdot\left(\frac{5}{4}\right)<2.$$

我们得出结论：当 N 是素数或是两个不同奇素数之积时，存在一个生成 $\mathbb{Z}_N^*$ 均匀元素的算法，它在关于 $n = \|N\|$ 的多项式时间内运行，并以关于 $n$ 可忽略的概率输出 fail。

在本书中，当我们谈到采样 $\mathbb{Z}_N$ 或 $\mathbb{Z}_N^*$ 的均匀元素时，我们只是忽略输出 fail 的可忽略概率，理解到这对分析没有显著影响。

## B.3 \*寻找循环群的生成元

本节我们处理在任意阶为 $q$ 的循环群 $G$ 中寻找生成元的问题。这里 $q$ 未必表示素数；事实上，当 $q$ 是素数时，由推论 9.56 寻找生成元是平凡的。

我们实际上要说明如何采样一个均匀的生成元，其进行方式与 B.2.5 节非常相似。这里，我们反复采样 G 的均匀元素，直到找到一个生成元。与 B.2.5 节一样，分析这种方法需要理解两件事：

- 如何高效地测试给定元素是否是生成元；以及

- 群元素中生成元所占的比例。

为了理解这些问题，我们首先发展一点额外的群论背景。

### B.3.1 群论背景

我们先处理第二个问题。回忆元素 $h$ 的阶是满足 $h^{i} = 1$ 的最小正整数 $i$。设 $g$ 是阶为 $q > 1$ 的群 $\mathbb{G}$ 的一个生成元；这意味着 $g$ 的阶是 $q$。考虑一个不是单位元的元素 $h \in \mathbb{G}$（单位元不可能是 $\mathbb{G}$ 的生成元），并问 $h$ 是否也可能成为 $\mathbb{G}$ 的生成元。由于 $g$ 生成 $\mathbb{G}$，可以把 $h$ 写成 $h = g^x$，其中 $x \in \{1, \ldots, q-1\}$（注意 $x \neq 0$，因为 $h$ 不是单位元）。考虑两种情形：

情形 1：$\gcd(x,q) = r > 1$。把 $x$ 写成 $x = \alpha \cdot r$，把 $q$ 写成 $q = \beta \cdot r$，其中 $\alpha, \beta$ 是小于 $q$ 的非零整数。则：

$$h^{\beta}=\left(g^{x}\right)^{\beta}=g^{\alpha r\beta}=\left(g^{q}\right)^{\alpha}=1.$$

所以 $h$ 的阶至多为 $\beta < q$，$h$ 不可能是 $\mathbb{G}$ 的生成元。

情形 2：$\gcd(x, q) = 1$。设 $i \leq q$ 是 $h$ 的阶。则

$$g^{0}=1=h^{i}=\left(g^{x}\right)^{i}=g^{x i},$$

由命题 9.54，这蕴含 $xi = 0 \bmod q$。这意味着 $q \mid xi$。然而，由于 $\gcd(x, q) = 1$，命题 9.3 表明 $q \mid i$，从而 $i = q$。我们得出结论：$h$ 是 $\mathbb{G}$ 的生成元。

总结上述讨论，我们看到对 $x \in \{1, \ldots, q-1\}$，元素 $h = g^x$ 是 $\mathbb{G}$ 的生成元当且仅当 $\gcd(x, q) = 1$。我们因此证明了：

**定理 B.16** 设 $\mathbb{G}$ 是阶为 $q > 1$ 且生成元为 $g$ 的循环群。$\mathbb{G}$ 有 $\phi(q)$ 个生成元，它们恰好由 $\{g^x \mid x \in \mathbb{Z}_q^*\}$ 给出。

特别地，若 $\mathbb{G}$ 是素数阶 $q$ 的群，则它有 $\phi(q) = q - 1$ 个生成元——这与推论 9.56 完全一致。

接下来处理第一个问题，即判定给定元素 $h$ 是否是 $\mathbb{G}$ 的生成元。当然，检查 $h$ 是否生成 $\mathbb{G}$ 的一种方式是枚举 $\{h^0, h^1, \ldots, h^{q-1}\}$，看这张表是否包含 $\mathbb{G}$ 的每个元素。这需要关于 $q$ 的线性时间（即关于 $\|q\|$ 的指数时间），因此对我们的目的而言不可接受。另一种方法，如果我们已经知道一个生成元 $g$，是计算离散对数 $x = \log_g h$ 然后应用上一定理；但一般来说，我们可能没有这样的 $g$，而且无论如何，计算离散对数本身可能就是一个困难问题。

如果我们知道 $q$ 的因子分解，就可以做得更好。

**命题 B.17** 设 $\mathbb{G}$ 是阶为 $q$ 的群，设 $q = \prod_{i=1}^{k} p_{i}^{e_{i}}$ 是 $q$ 的素因子分解，其中 $\{p_{i}\}$ 是不同的素数且 $e_{i} \geq 1$。令 $q_{i} = q/p_{i}$。则 $h \in \mathbb{G}$ 是 $\mathbb{G}$ 的生成元，当且仅当

$$h^{q_{i}}\neq1\quad\text{ for }i=1,\ldots,k.$$

**证明** 一个方向是容易的。设对某个 $i$ 有 $h^{q_i} = 1$。则 $h$ 的阶至多为 $q_i < q$，故 $h$ 不可能是生成元。

反过来，设 $h$ 不是生成元，而是具有阶 $q^{\prime} < q$。由命题 9.55，我们知道 $q^{\prime} \mid q$。这意味着 $q^{\prime}$ 可以写成 $q^{\prime} = \prod_{i=1}^{k} p_i^{e_i^{\prime}}$，其中 $e_i^{\prime} \geq 0$，且至少存在一个下标 $j$ 使得 $e_j^{\prime} < e_j$。但于是 $q^{\prime}$ 整除 $q_j = p_j^{e_j - 1} \cdot \prod_{i \neq j} p_i^{e_i}$，从而（利用命题 9.54）$h^{q_j} = h^{[q_j \bmod q^{\prime}]} = h^0 = 1$。

该命题不要求 $\mathbb{G}$ 是循环的；若 $\mathbb{G}$ 不是循环群，则每个元素 $h \in \mathbb{G}$ 都会对某个 $i$ 满足 $h^{q_i} = 1$，因而没有生成元。

### B.3.2 高效算法

凭借上一节的结果，我们说明如何高效地测试给定元素是否是生成元，以及如何在任意群中高效地寻找生成元。

**测试一个元素是否是生成元。** 命题 B.17 立即提示了一个判定给定元素 $h$ 是否是生成元的高效算法。

**算法 B.18**

```
测试一个元素是否是生成元
输入：群阶 $q$；$q$ 的素因子 $\{p_i\}_{i=1}^k$；元素 $h \in G$
输出：关于 $h$ 是否是 $G$ 的生成元的判定
for i = 1 to k:
    if h^(q/p_i) = 1 return "h 不是生成元"
return "h 是生成元"
```

算法的正确性由命题 B.17 显然可见。下面证明算法在关于 $\|q\|$ 的多项式时间内终止。由于每次迭代中 $h^{q/p_i}$ 都可以在多项式时间内计算，我们只需证明迭代次数 $k$ 是多项式的。事实确实如此，因为整数 $q$ 的素因子个数不可能超过 $\log_2 q = \mathcal{O}(\|q\|)$；这是因为

$$q=\prod_{i=1}^{k}p_{i}^{e_{i}}\geq\prod_{i=1}^{k}p_{i}\geq\prod_{i=1}^{k}2=2^{k}$$

于是 $k \leq \log_{2} q$。

算法 B.18 要求把群阶 $q$ 的素因子作为输入提供。有趣的是，当群阶的因子未知时，不存在已知的高效算法来测试任意群的元素是否是生成元。

**生成元所占的比例。** 如定理 B.16 所示，阶为 $q$ 的群 $\mathbb{G}$ 中生成元所占的比例是 $\phi(q)/q$。定理 B.15 表明 $\phi(q)/q = \Omega(1/\|q\|)$。生成元所占的比例因此足够高，足以保证：从群中采样多项式个元素，除可忽略的概率外将得到一个生成元。（分析与 B.2.5 节相同。）

$\mathbb{Z}_p^*$ 中的具体例子。把所有这些放在一起，我们看到只要群阶的因子分解已知，就存在一个寻找群 $\mathbb{G}$ 生成元的高效概率算法。因此在为密码学应用选择群时，必须使所选的群满足这一点。这再次解释了 9.3.2 节大量讨论的偏好：在 $\mathbb{Z}_p^*$ 的某个适当的素数阶子群中工作。另一种可能是对强素数 $p$（即 $p = 2q + 1$ 且 $q$ 也是素数）使用 $\mathbb{G} = \mathbb{Z}_p^*$，此时群阶 $p - 1$ 的素因子分解已知。最后一种可能是以这样的方式生成素数 $p$，使 $p - 1$ 的因子分解已知。进一步的细节超出本书范围。
