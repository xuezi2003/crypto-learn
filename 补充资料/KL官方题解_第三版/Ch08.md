## 8.1

> **题目**　Prove that if there exists a one-way function, then there exists a one-way function $f$ such that $f(0^n) = 0^n$ for every $n$. Note that for infinitely many values $y$, it is easy to compute $f^{-1}(y)$. Why does this not contradict one-wayness?

**Solution.** Let $f$ be a one-way function (which exists by assumption) and define $g(x) = f(x)$ for every $x \neq 0^{|x|}$ and $g(0^n) = 0^n$ for every $n$. Clearly, $g$ fulfills the stated requirements. It remains to prove that $g$ is one-way. First, $g$ is efficiently computable. Second, assume by contradiction that there exists a probabilistic polynomial-time algorithm $\mathcal{A}$ and set

$$\varepsilon(n) \stackrel{\mathrm{def}}{=} \Pr[\mathsf{Invert}_{\mathcal{A},g}(n) = 1].$$

We analyze the probability that $\mathcal{A}$ succeeds in inverting $g$ on non-zero inputs (the value $x$ referred to below is the $x$ chosen in the Invert experiment):

$$\begin{aligned} \Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1] &= \Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1 \mid x \neq 0^n] \cdot \Pr[x \neq 0^n] \\ &\quad + \Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1 \mid x = 0^n] \cdot \Pr[x = 0^n] \\ &\leq \Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1 \mid x \neq 0^n] + \Pr[x = 0^n] \\ &= \Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1 \mid x \neq 0^n] + \frac{1}{2^n}. \end{aligned}$$

Therefore, $\Pr[\mathsf{Invert}_{\mathcal{A},g}(n)=1 \mid x \neq 0^n] \geq \varepsilon(n) - \frac{1}{2^n}$. We now construct $\mathcal{B}$ that inverts $f$ as follows. Upon receiving input $y$, algorithm $\mathcal{B}$ invokes $\mathcal{A}$ and returns whatever $\mathcal{A}$ outputs. We analyze $\mathcal{B}$'s success:

$$\begin{aligned} \Pr[\mathsf{Invert}_{\mathcal{B},f}(n)=1] &= \Pr[\mathsf{Invert}_{\mathcal{B},f}(n)=1 \mid x \neq 0^n] \cdot \Pr[x \neq 0^n] \\ &\quad + \Pr[\mathsf{Invert}_{\mathcal{B},f}(n)=1 \mid x = 0^n] \cdot \Pr[x = 0^n] \\ &\geq \Pr[\mathsf{Invert}_{\mathcal{B},f}(n)=1 \mid x \neq 0^n] \cdot \Pr[x \neq 0^n] \\ &= \Pr[\mathsf{Invert}_{\mathcal{B},f}(n)=1 \mid x \neq 0^n] \cdot \left(1 - \frac{1}{2^n}\right) \\ &= \Pr[\mathsf{Invert}_{\mathcal{B},g}(n)=1 \mid x \neq 0^n] \cdot \left(1 - \frac{1}{2^n}\right) \\ &\geq \left(\varepsilon(n) - \frac{1}{2^n}\right) \cdot \left(1 - \frac{1}{2^n}\right) = \varepsilon(n) - \mathsf{negl}(n) \end{aligned}$$

for some negligible function $\mathsf{negl}$. Since $f$ is one-way, $\varepsilon$ must be negligible. Since this holds for arbitrary PPT $\mathcal{A}$, we conclude that $g$ is one-way as well.

This does not contradict one-wayness since although there are infinitely many values that can be easily inverted, the probability of receiving such a value is negligible (specifically, ${2}^{-n}$).

## 8.2

> **题目**　Prove that if $f$ is a one-way function, then the function $g$ defined by $g(x_1, x_2) \stackrel{\mathrm{def}}{=} (f(x_1), x_2)$, where $|x_1| = |x_2|$, is also a one-way function. Observe that $g$ reveals half of its input but is nevertheless one-way.

**Solution.**

We assume $f$ is length preserving for simplicity. Let $\mathcal{A}$ be a probabilistic polynomial-time algorithm inverting $g$. We construct an algorithm $\mathcal{A}^{\prime}$ inverting $f$ as follows: on input $y$, algorithm $\mathcal{A}^{\prime}$ chooses $x_2 \leftarrow \{0,1\}^n$ and invokes $\mathcal{A}$ on input $y\|x_2$; then, $\mathcal{A}^{\prime}$ outputs the first half of whatever $\mathcal{A}$ outputs. It is not hard to see that

$$\Pr\left[\mathsf{Invert}_{\mathcal{A}^{\prime},f}(n) = 1\right] \ge \Pr\left[\mathsf{Invert}_{\mathcal{A},g}(n) = 1\right].$$

Since $f$ is one-way, $\Pr[\mathsf{Invert}_{\mathcal{A}^{\prime},f}(n) = 1]$ is negligible; it follows that $\Pr[\mathsf{Invert}_{\mathcal{A},g}(n) = 1]$ is negligible as well. Since $\mathcal{A}$ was arbitrary, this proves that $g$ is one-way.

## 8.3

> **题目**　Prove that if there exists a one-way function, then there exists a length-preserving one-way function.
>
> *Hint:* Let $f$ be a one-way function and let $p(\cdot)$ be a polynomial such that $|f(x)| \leq p(|x|)$. (Justify the existence of such a $p$.) Define $f^{\prime}(x) \stackrel{\mathrm{def}}{=} f(x)\|1\,0^{p(|x|)-|f(x)|}$. Further modify $f^{\prime}$ to get a length-preserving function that remains one-way.

**Solution.** We provide only a proof sketch. We first show how to construct a length-regular one-way function. (A function is length regular if $|x| = |y| \Rightarrow |f(x)| = |f(y)|$.) Let $f$ be a one-way function. Since $f$ is one-way, it is efficiently computable. Thus, there exists a polynomial $p(\cdot)$ such that for every $x$, $|f(x)| \leq p(|x|)$. Assume $p(n) \geq n$ (if not, just set $p(n) = n$). Define $f^{\prime}(x) = f(x)\|1\,0^{p(|x|) - |f(x)|}$. Clearly, $f^{\prime}$ is length-regular, since the output length of $f^{\prime}(x)$ for every $x$ of length $n$ is exactly $p(n)+1$. We now prove that $f^{\prime}$ is one-way.

Assume by contradiction that there exists a probabilistic polynomial-time adversary $\mathcal{A}^{\prime}$ and a non-negligible function $\varepsilon(\cdot)$ such that

$$\Pr[\mathsf{Invert}_{\mathcal{A}^{\prime},f^{\prime}}(n) = 1] = \varepsilon(n).$$

We construct an adversary $\mathcal{A}$ that inverts $f$ as follows: $\mathcal{A}$ receives ${1}^n$ and $y$ for input, invokes $\mathcal{A}^{\prime}$ on ${1}^n$ and $y\|1\,0^{p(|x|)-|f(x)|}$, and returns whatever $\mathcal{A}^{\prime}$ returns (we can assume that $\mathcal{A}$ knows the polynomial $p(\cdot)$). The important point is that since the "padding" includes a single 1 followed by zeroes, the output of $f^{\prime}(x)$ uniquely defines the length of the portion that is $f(x)$. Therefore, the set of preimages of $f^{\prime}(x)$ equals the set of preimages of $f(x)$. This implies that if $\mathcal{A}^{\prime}$ inverts $f^{\prime}$, then $\mathcal{A}$ will have inverted $f$. By our assumption, $\mathcal{A}^{\prime}$ inverts with success probability $\varepsilon(n)$; therefore the same is true of $\mathcal{A}$. This contradicts the assumed one-wayness of $f$.

We next construct a length-preserving one-way function $g$. Define $q(n) = |f^{\prime}(0^n)|$, where $f^{\prime}$ is as above; since $f^{\prime}$ is length-regular, the output length of $f^{\prime}$ on any $n$-bit input is exactly $q(n)$. Note also that by construction of $f^{\prime}$, we have $q(n) \geq n$ for all $n$. Now compute $g(x)$ as follows:

(a) Set $n := |x|$.

(b) Find the largest $n^{\prime}$ such that $q(n^{\prime}) < n$. (Note that $n^{\prime} \neq n$.) Let $x^{\prime}$ denote the $n^{\prime}$-bit prefix of $x$.

(c) Output $f^{\prime}(x^{\prime})\|1\,0^{n-q(n^{\prime})-1}$.

We omit the (tedious, but straightforward) proof that $g$ is one-way.

## 8.7

> **题目**　Prove that there exist one-way functions if and only if there exist one-way function families. Discuss why your proof does not carry over to the case of one-way permutations.

**Solution.** It is trivial to see that the existence of any one-way function $f$ implies the existence of a family of one-way functions: just take $\mathsf{Gen}$ to be the trivial algorithm that outputs $I = 1^n$ on input ${1}^n$, and let $\mathsf{Samp}$ be the trivial algorithm that returns a random $n$-bit string on input $I = 1^n$; the family $(\mathsf{Gen}, \mathsf{Samp}, f)$ is then one-way. We therefore focus on the more interesting direction.

Let $\Pi = (\mathsf{Gen}, \mathsf{Samp}, f)$ be a family of one-way functions. Let $p_G(\cdot)$ denote the (polynomial) running time of $\mathsf{Gen}$ and let $p_S(\cdot)$ denote the (polynomial) running time of $\mathsf{Samp}$. Note that $p_G(n)$ and $p_S(n)$ constitute an upper bound on the number of random coins used by $\mathsf{Gen}$ and $\mathsf{Samp}$, respectively, on security parameter ${1}^n$. Furthermore, $p_S(n)$ also constitutes an upper bound on the length of values in $\mathcal{D}_I$ for $I$ output by $\mathsf{Gen}(1^n)$.

We define a single one-way function $g$ as follows. Upon input $x$ of length $n$, let $k$ be maximal such that $p_G(k) + p_S(k) \leq n$; then divide $x$ into three parts $x_1, x_2, x_3$ such that $|x_1| = p_G(k)$ and $|x_2| = p_S(k)$. The function $g$ is defined as (we ignore $x_3$):

$$g(x) = g(x_1, x_2) = \left(\mathsf{Gen}(1^k;x_1),\; f\!\left(\mathsf{Gen}(1^k;x_1),\, \mathsf{Samp}(\mathsf{Gen}(1^k;x_1);x_2)\right)\right),$$

where $\mathsf{Gen}(1^k;x_1)$ denotes the output of algorithm $\mathsf{Gen}$ upon input ${1}^k$ and random tape $x_1$, and $\mathsf{Samp}(\mathsf{Gen}(1^k;x_1);x_2)$ denotes the output of $\mathsf{Samp}$ upon input $\mathsf{Gen}(1^k;x_1)$ and random tape $x_2$. Note that $\mathsf{Gen}(1^k;x_1)$ is included in the output to force any inverting algorithm to find a preimage of $f(\mathsf{Gen}(1^k;x_1), \mathsf{Samp}(\mathsf{Gen}(1^k;x_1);x_2))$ under $\mathsf{Gen}(1^k;x_1)$ and not under some other function in the family.

It remains to prove that $g$ is one-way. First, it is clearly an efficiently computable function. Second, assume by contradiction that it can be inverted with probability $\varepsilon(n)$ for some non-negligible function $\varepsilon(\cdot)$. By the construction, this implies that the family $(\mathsf{Gen}, \mathsf{Samp}, f)$ can be inverted with probability $\varepsilon(n)$. This holds because for every $n$ there exists a $k$ that results from the above derivation via $p_G$ and $p_S$, and $g$ can be inverted for these $k$'s with probability $\varepsilon(n)$. Now, let $c$ be a constant such that $n = k^c$ (such a constant exists because the lengths of $k$ and $n$ are polynomially related). Thus, the family $(\mathsf{Gen}, \mathsf{Samp}, f)$ can be inverted with probability $\varepsilon(k^c)$. If $\varepsilon$ is non-negligible in $k^c$ then it is also non-negligible in $k$. This contradicts the one-wayness of $(\mathsf{Gen}, \mathsf{Samp}, f)$.

For the case of permutations, any one-way permutation implies a family of one-way permutations using the same trivial construction given earlier. On the other hand, the transformation of a one-way function family to a one-way function given above does not work for permutations since the $g$ that results is not necessarily a permutation even if $f$ is.

## 8.8

> **题目**　Let $f$ be a one-way function. Is $g(x) \stackrel{\mathrm{def}}{=} f(f(x))$ necessarily one-way? What about $g^{\prime}(x) \stackrel{\mathrm{def}}{=} (f(x), f(f(x)))$?

**Solution.**

We give a counterexample showing that taking $g(x) = f(f(x))$ for an arbitrary one-way function $f$ does not necessarily make $g$ a one-way function. Let $h$ be a length-preserving one-way function and define $f$ as follows: If $x_{n/2+1} \cdots x_n = 0^{n/2}$, then $f(x) = 0^{|x|}$; else, $f(x) = h(x_1 \cdots x_{n/2})0^{n/2}$. It is not too difficult to show that $f$ is one-way. However, $g$ is not one-way. To see this, observe that $f(f(x)) = 0^{|x|}$ for every input $x$.

On the other hand, $g^{\prime}(x) = (f(x)\|f(f(x)))$ is one-way. Assume toward a contradiction that there is a probabilistic polynomial-time algorithm $\mathcal{A}$ and a non-negligible function $\varepsilon(\cdot)$ such that

$$\Pr\left[\mathsf{Invert}_{\mathcal{A},g}(n) = 1\right] = \varepsilon(n).$$

We construct a probabilistic polynomial-time $\mathcal{A}^{\prime}$ that inverts $f$ with probability $\varepsilon(n)$, as follows. $\mathcal{A}^{\prime}$ receives input ${1}^n$ and $y$, computes $z = f(y)$, and invokes $\mathcal{A}$ on input ${1}^n$ and $(y, z)$. Adversary $\mathcal{A}^{\prime}$ then outputs whatever $\mathcal{A}$ outputs. Clearly,

$$\Pr\left[\mathsf{Invert}_{\mathcal{A}^{\prime},f}(n) = 1\right] = \Pr\left[\mathsf{Invert}_{\mathcal{A},g}(n) = 1\right] = \varepsilon(n),$$

in contradiction to the one-wayness of $f$.

## 8.11

> **题目**　This exercise is for students who have taken a course in complexity theory or are otherwise familiar with $\mathcal{NP}$-completeness.
>
> (a) Show that the existence of one-way functions implies $\mathcal{P} \neq \mathcal{NP}$.
>
> (b) Assume that $\mathcal{P} \neq \mathcal{NP}$. Show that there exists a function $f$ that is: (1) computable in polynomial time, (2) hard to invert in the worst case (i.e., for all probabilistic polynomial-time $\mathcal{A}$, $\Pr_{x\leftarrow\{0,1\}^n}[f(\mathcal{A}(f(x))) = f(x)] \neq 1$), but (3) is not one-way.

**Solution.**

(a) Consider the language $L = \{(y, x^{\prime}) \mid \exists x^{\prime\prime} : f(x^{\prime}\|x^{\prime\prime}) = y\}$; that is, the language of all pairs $(y, x^{\prime})$ where $x^{\prime}$ is the prefix of some preimage of $y$. It is clear that $L \in \mathcal{NP}$ (one can non-deterministically guess $x^{\prime\prime}$ and then compute $f$). Now, if $\mathcal{P} = \mathcal{NP}$ then there exists a polynomial-time algorithm $A$ that decides $L$. We use $A$ to invert $f$. Specifically, given ${1}^n$ and $y$, we use $A$ to determine the bits of a preimage of $y$ one at a time as follows. Given the prefix $x^{\prime}$ of a preimage of $y$ (initially $x^{\prime}$ is of length zero), we extend it by one bit by using $A$ to determine whether $(y, x^{\prime}\|0) \in L$. If yes, then we set $x^{\prime} := x^{\prime}\|0$ and proceed; otherwise, we set $x^{\prime} := x^{\prime}\|1$ and proceed. After $n$ iterations, we obtain $x$ such that $f(x) = y$ and have thus successfully inverted $f$. The above holds for any function $f$. Therefore, if there exists a one-way function, $\mathcal{P}$ cannot equal $\mathcal{NP}$.

(b) Let $G$ be a graph and let $\phi$ be a 3-coloring of $G$. Consider the function $f(G, \phi) = (G,1)$ if $\phi$ is a valid coloring of $G$, and $f(G, \phi) = (G,0)$ if $\phi$ is not a valid coloring of $G$. (Note that $G$ can be represented as a string of length $\binom{n}{2}$ where each bit denotes the existence or nonexistence of the appropriate edge.)

$f$ is easy to compute, because the validity of a coloring can be checked in polynomial time. Further, $f$ is hard to invert in the worst case. This is due to the assumption that $\mathcal{P} \neq \mathcal{NP}$, and so given $(G,1)$ it is hard — in the worst case — to find a valid 3-coloring for $G$. Finally, $f$ is not a one-way function. This is due to the fact that a random 3-coloring of a random graph will be valid with very low probability. Thus, with high probability over a random input the output of $f$ will be some pair $(G,0)$ which is easily invertible (just compute any invalid coloring).

## 8.12

> **题目**　For $x \in \{0,1\}^n$ let $x = x_1 \cdots x_n$. Prove that if there exists a one-way function, then there exists a one-way function $f$ such that for every $i$ there exists an algorithm $A_i$ such that
>
> $$\Pr_{x \leftarrow \{0,1\}^n}\left[A_i(f(x)) = x_i\right] \ge \frac{1}{2} + \frac{1}{2n}$$
>
> (This exercise demonstrates that it is not possible to claim that every one-way function hides at least one *specific* bit of the input.)

**Solution.**

Let $g$ be a one-way function. We define a function $f$ that takes as input $(x, j)$, where $|x| = n$ and $|j| = \lceil \log n \rceil$ so $j$ can be viewed as an integer in the range $\{1, \ldots, n\}$ (we interpret any $j$ outside this range as $n$). The function $f$ is defined as follows:

$$f(x, j) = g(x), j, x_j,$$

where $x_j$ denotes the $j$th bit of $x$. Fix $i \le n$. We show an algorithm $A_i$ such that $A_i(f(x\|j))$ outputs $x_i$ with probability ${1}/2 + 1/2n \ge 1/2 + 1/2(n + \log n)$. (Note that outputting the $i$th bit of the input for $i > n$ is trivial since the last $\lceil \log n \rceil$ bits of the input are revealed in their entirety in the output of $f$.) Algorithm $A_i$ receives $y, j, b$. If $j = i$, then $A_i$ outputs $b$; otherwise, $A_i$ outputs a uniform bit. Now,

$$\begin{aligned} \Pr\left[A_i(f(x\|j)) = x_i\right] &= \frac{1}{2} \cdot \Pr[j \ne i] + \Pr[j = i] \\ &\ge \frac{1}{2}\left(1 - \frac{1}{n}\right) + \frac{1}{n} = \frac{1}{2} + \frac{1}{2n}. \end{aligned}$$

It remains to prove that $f$ is one-way. Assume toward a contradiction that it can be inverted with non-negligible probability by some probabilistic polynomial-time algorithm $\mathcal{A}$. Then we can invert $g$ with at least the same probability as follows. Upon receiving input $y = g(x)$, choose $\lceil \log n \rceil$ uniform bits to define an index $j$, and run $\mathcal{A}(y, j, 0)$ and $\mathcal{A}(y, j, 1)$. At least one of the tuples $(y, j, 0)$ or $(y, j, 1)$ is in the range of $f$, and $\mathcal{A}$ inverts that tuple with the same probability that it inverts $f$. Moreover, we can easily check the values that $\mathcal{A}$ outputs to see if either is a preimage of $y$ with respect to $g$. This inversion procedure inverts $g$ with probability at least as high as the probability that $\mathcal{A}$ inverts $f$, in contradiction to the assumption that $g$ is one-way.

## 8.13

> **题目**　Show that if an efficiently computable one-to-one function $f$ has a hardcore predicate, then $f$ is one-way.

**Solution.** Let $f$ be an efficiently computable one-to-one function and let $\mathsf{hc}$ be a hard-core predicate of $f$. We show that if $f$ is not one-way then $\mathsf{hc}$ cannot be a hard-core predicate. Assume by contradiction that there exists a probabilistic polynomial-time adversary $\mathcal{A}$ and a non-negligible function $\varepsilon(\cdot)$ such that

$$\Pr[\mathsf{Invert}_{\mathcal{A},f}(n) = 1] = \varepsilon(n).$$

We now construct an adversary $\mathcal{B}$ that contradicts the assumption that $\mathsf{hc}$ is a hard-core predicate of $f$. The adversary $\mathcal{B}$ receives as input some $y = f(x)$, with $x \leftarrow \{0,1\}^n$, and attempts to guess $\mathsf{hc}(x)$. In order to do this, $\mathcal{B}$ first invokes $\mathcal{A}$ on input ${1}^n$ and $y$; let $x^{\prime}$ be the output of $\mathcal{A}$. Next, $\mathcal{B}$ checks whether $f(x^{\prime}) = y$ (notice that $f$ is efficiently computable, so $\mathcal{B}$ can do this). If yes, then $\mathcal{B}$ outputs $\sigma = \mathsf{hc}(x^{\prime})$ and halts (in this case, $\mathcal{B}$ is correct with probability 1). Otherwise, $\mathcal{B}$ outputs a uniformly chosen bit $\sigma \leftarrow \{0,1\}$. It remains to analyze $\mathcal{B}$'s success. We denote the event of $\mathcal{A}$ successfully inverting $f$ by $\mathsf{Succ}_{\mathcal{A}}$. Then,

$$\begin{aligned} \Pr[\mathcal{B}(f(x)) = \mathsf{hc}(x)] &= \Pr[\mathcal{B}(f(x)) = \mathsf{hc}(x) \mid \mathsf{Succ}_{\mathcal{A}}] \cdot \Pr[\mathsf{Succ}_{\mathcal{A}}] \\ &\quad + \Pr[\mathcal{B}(f(x)) = \mathsf{hc}(x) \mid \overline{\mathsf{Succ}_{\mathcal{A}}}] \cdot \Pr[\overline{\mathsf{Succ}_{\mathcal{A}}}] \\ &= 1 \cdot \Pr[\mathsf{Invert}_{\mathcal{A},f}(n)=1] + \frac{1}{2} \cdot \Pr[\mathsf{Invert}_{\mathcal{A},f}(n)=0] \\ &= \frac{1}{2} + \frac{1}{2} \cdot \Pr[\mathsf{Invert}_{\mathcal{A},f}(n)=1] \;\geq\; \frac{1}{2} + \frac{\varepsilon(n)}{2}. \end{aligned}$$

Since $\mathsf{hc}$ is a hard-core predicate for $f$, we see that $\varepsilon$ must be negligible. We conclude that $f$ must be one-way.

Note that the condition that $f$ is one-to-one is necessary to ensure that whenever $\mathcal{A}$ succeeds in inverting $f(x)$, it follows that $\mathcal{B}$ succeeds in guessing $\mathsf{hc}(x)$. For example, consider the function $f(x) = 0^{|x|}$ and $\mathsf{hc}(x) = x_1$ where $x = x_1 \cdots x_n$. Then clearly $\mathsf{hc}$ is a hard-core predicate of $f$. However, $f$ is not one-way.

## 8.14

> **题目**　Show that if Construction 8.20 is modified in the natural way so that $F_k(x)$ is defined for every nonempty string $x$ of length at most $n$, then the construction is no longer a pseudorandom function.

**Solution.**

Let $D$ be a distinguisher who first queries its oracle on any $x \in \{0,1\}^{n-1}$; let $y$ be the response. Next, $D$ queries its oracle on $x^{\prime} = x\|0$ of length $n$; let $y^{\prime}$ be the response. Finally, $D$ checks if $y^{\prime} = G_0(y)$. If yes, then $D$ outputs 1; otherwise, it outputs 0. We have

$$\Pr\left[D^{F_k(\cdot)}(1^n) = 1\right] = 1$$

whereas for a random function $f$

$$\Pr\left[D^{f(\cdot)}(1^n) = 1\right] = \frac{1}{2^n}.$$

$D$ therefore distinguishes $F_k$ from random.

## 8.15

> **题目**　Prove that if there exists a pseudorandom function that, using a key of length $n$, maps $n$-bit inputs to single-bit outputs, then there exists a pseudorandom function that maps $n$-bit inputs to $n$-bit outputs.
>
> *Hint:* Use a key of length $n^2$, and prove your construction secure using a hybrid argument.

**Solution.** Let $F^{\prime}$ take a key of length $n^2$, and define its output as

$$F^{\prime}_{\langle k_1, \ldots, k_n\rangle}(x) = F_{k_1}(x), \ldots, F_{k_n}(x).$$

This has output length $n$, as requested.

To show that $F^{\prime}$ is pseudorandom, fix a PPT algorithm $\mathcal{A}$ distinguishing $F^{\prime}$ from a random function. We assume without loss of generality that $\mathcal{A}$ does not query its oracle on the same input more than once. Define an algorithm $D$ as follows:

*Algorithm $D$:* The algorithm is given access to an oracle that is either equal to $F_k(\cdot)$ for uniform $k \in \{0,1\}^n$, or is equal to $f(\cdot)$ for a random function $f$.

- Choose uniform $i \in \{1, \ldots, n\}$.
- For $j = i+1$ to $n$, choose uniform $k_j \in \{0,1\}^n$.
- Run $\mathcal{A}(1^n)$. When $\mathcal{A}$ queries its oracle on input $x$, do:
  - For $j = 1$ to $i-1$, choose uniform $y_j \in \{0,1\}$.
  - For $j = i$, query $x$ to the oracle and set $y_j$ equal to the answer received.
  - For $j = i+1$ to $n$, set $y_j := F_{k_j}(x)$.
- Output whatever $\mathcal{A}$ outputs.

For a fixed value of $n$ and $i \in \{0, \ldots, n\}$, let $\mathcal{O}_n^i$ be a distribution over functions mapping $n$-bit inputs to $n$-bit outputs defined as follows: choose (independent) random functions $f_1, \ldots, f_i$ mapping $n$-bit inputs to 1-bit outputs, along with uniform $k_{i+1}, \ldots, k_n \in \{0,1\}^n$. The function then maps input $x$ to the output

$$f_1(x), \ldots, f_i(x), F_{k_{i+1}}(x), \ldots, F_{k_n}(x).$$

By inspection of $D$ we have

$$\Pr[D^{f(\cdot)}(1^n) = 1] = \sum_{i=1}^{n} \frac{1}{n} \cdot \Pr[\mathcal{A}^{\mathcal{O}_n^i(\cdot)}(1^n) = 1]$$

(where $f$ denotes a random function mapping $n$-bit inputs to 1-bit outputs) and

$$\Pr[D^{F_k(\cdot)}(1^n) = 1] = \sum_{i=1}^{n} \frac{1}{n} \cdot \Pr[\mathcal{A}^{\mathcal{O}_n^{i-1}(\cdot)}(1^n) = 1].$$

Therefore

$$\begin{aligned} &\left|\Pr[D^{f(\cdot)}(1^n)=1] - \Pr[D^{F_k(\cdot)}(1^n)=1]\right| \\ &= \left|\sum_{i=1}^{n}\frac{1}{n}\cdot\Pr[\mathcal{A}^{\mathcal{O}_n^i(\cdot)}(1^n)=1] - \sum_{i=1}^{n}\frac{1}{n}\cdot\Pr[\mathcal{A}^{\mathcal{O}_n^{i-1}(\cdot)}(1^n)=1]\right| \\ &= \frac{1}{n}\cdot\left|\Pr[\mathcal{A}^{\mathcal{O}_n^n(\cdot)}(1^n)=1] - \Pr[\mathcal{A}^{\mathcal{O}_n^0(\cdot)}(1^n)=1]\right| \\ &= \frac{1}{n}\cdot\left|\Pr[\mathcal{A}^{\hat{f}(\cdot)}(1^n)=1] - \Pr[\mathcal{A}^{F^{\prime}_{\langle k_1,\ldots,k_n\rangle}(\cdot)}(1^n)=1]\right|, \end{aligned}$$

where $\hat{f}$ denotes a random function mapping $n$-bit inputs to $n$-bit outputs. Since $F$ is pseudorandom, there exists a negligible function $\mathsf{negl}$ such that

$$\left|\Pr[D^{f(\cdot)}(1^n)=1] - \Pr[D^{F_k(\cdot)}(1^n)=1]\right| \leq \mathsf{negl}(n);$$

therefore,

$$\left|\Pr[\mathcal{A}^{\hat{f}(\cdot)}(1^n)=1] - \Pr[\mathcal{A}^{F^{\prime}_{\langle k_1,\ldots,k_n\rangle}(\cdot)}(1^n)=1]\right| \leq n \cdot \mathsf{negl}(n),$$

which is still negligible. Since $\mathcal{A}$ was arbitrary, this completes the proof.

## 8.16

> **题目**　Prove that a two-round Feistel network using pseudorandom round functions is not pseudorandom.

**Solution.**

We show an attack that works (with high probability) regardless of what round functions are used. The attacker $\mathcal{A}$, given access to an oracle $\mathcal{O}: \{0,1\}^{2n} \rightarrow \{0,1\}^{2n}$ works as follows: choose arbitrary $L_0, L_0^{\prime}, R_0 \in \{0,1\}^n$ with $L_0 \ne L_0^{\prime}$. Query $\mathcal{O}(L_0, R_0)$ and obtain output $(L_2, R_2)$. Then query $\mathcal{O}(L_0^{\prime}, R_0)$ and obtain output $(L_2^{\prime}, R_2^{\prime})$. Output 1 iff $L_0 \oplus L_0^{\prime} \stackrel{?}{=} L_2 \oplus L_2^{\prime}$.

Observe that if $\mathcal{O}$ is a permutation chosen at random, then $(L_2, R_2)$ and $(L_2^{\prime}, R_2^{\prime})$ are uniform subject to the constraint that they are unequal; thus, the probability that $\mathcal{A}$ outputs 1 is roughly ${2}^{-n}$. On the other hand, if $\mathcal{O}$ is a 2-round Feistel network with round functions $f_1, f_2$ then

$$L_2 = R_1 = L_0 \oplus f_1(R_0)$$

and, similarly,

$$L_2^{\prime} = L_0^{\prime} \oplus f_1(R_0).$$

So,

$$L_2 \oplus L_2^{\prime} = L_0 \oplus f_1(R_0) \oplus L_0^{\prime} \oplus f_1(R_0) = L_0 \oplus L_0^{\prime},$$

and so $\mathcal{A}$ outputs 1 with probability 1 in this case. $\mathcal{A}$ thus has a significant advantage in distinguishing between a two-round Feistel network and a truly random permutation.

## 8.17

> **题目**　Prove that a three-round Feistel network using pseudorandom round functions (as in Equation (8.16)) is not a strong pseudorandom permutation.

**Solution.** We show an attack that works (with high probability) regardless of what round functions are used. The attack exploits the fact that we can introduce a known "shift" $\delta$ in the input to the second round-function of the Feistel network in two ways: by XORing $\delta$ into the left half of the input when querying the function in the forward direction (and keeping the right half fixed), or by XORing $\delta$ into the right half of the input when querying the function in the reverse direction (and keeping the left half fixed). It is easiest to see this by tracing through the effects of these modifications in Figure 8.3. We now give the details.

The attacker $\mathcal{A}$, given access to an oracle $\mathcal{O} : \{0,1\}^{2n} \to \{0,1\}^{2n}$ and its inverse $\mathcal{O}^{-1} : \{0,1\}^{2n} \to \{0,1\}^{2n}$, works as follows: choose arbitrary $L_0, R_0, \delta \in \{0,1\}^n$ with $\delta \neq 0^n$. Then:

(a) Query $\mathcal{O}(L_0, R_0)$ to obtain $(L_3, R_3)$.

(b) Query $\mathcal{O}^{-1}(L_3, R_3 \oplus \delta)$ to obtain $(L_0^{\prime}, R_0^{\prime})$.

(c) Query $\mathcal{O}(L_0 \oplus \delta, R_0)$ to obtain $(L_3^{\prime\prime}, R_3^{\prime\prime})$.

Output 1 iff $L_3 \oplus R_0^{\prime} \stackrel{?}{=} L_3^{\prime\prime} \oplus R_0$.

When $\mathcal{O}$ is a random permutation, $\mathcal{A}$ outputs 1 with only negligible probability. To see this, note that $(L_3, R_3 \oplus \delta) \neq (L_3, R_3)$ and so $(L_0^{\prime}, R_0^{\prime})$ is uniform subject to being unequal to $(L_0, R_0)$ (because $\mathcal{O}$ is a permutation). The probability that $(L_0^{\prime}, R_0^{\prime}) = (L_0 \oplus \delta, R_0)$ is, therefore, roughly ${2}^{-2n}$. Assuming $(L_0^{\prime}, R_0^{\prime}) \neq (L_0 \oplus \delta, R_0)$, the value $(L_3^{\prime\prime}, R_3^{\prime\prime})$ is uniform subject to being different from both $(L_3, R_3)$ and $(L_3, R_3 \oplus \delta)$, and so $L_3 \oplus R_0^{\prime} = L_3^{\prime\prime} \oplus R_0$ only with probability roughly ${2}^{-n}$.

On the other hand, if $\mathcal{O}$ is a 3-round Feistel network with round functions $f_1, f_2, f_3$ then

$$\begin{aligned} L_3 \oplus R_0^{\prime} &= L_3 \oplus \big(L_3 \oplus f_2(R_3 \oplus \delta \oplus f_3(L_3))\big) \\ &= f_2(R_3 \oplus \delta \oplus f_3(L_3)) \end{aligned} \qquad (8.1)$$

and

$$\begin{aligned} L_3^{\prime\prime} \oplus R_0 &= \big(R_0 \oplus f_2(L_0 \oplus \delta \oplus f_1(R_0))\big) \oplus R_0 \\ &= f_2(L_0 \oplus \delta \oplus f_1(R_0)). \end{aligned} \qquad (8.2)$$

Since $R_3 \oplus f_3(L_3) = L_0 \oplus f_1(R_0)$, we see that Equations (8.1) and (8.2) are equal, and so $\mathcal{A}$ outputs 1 with probability 1 in this case. $\mathcal{A}$ thus has a significant advantage in distinguishing between a three-round Feistel network and a truly random permutation.

## 8.18

> **题目**　Consider the keyed permutation $F^*$ defined by
>
> $$F_k^*(x) \stackrel{\mathrm{def}}{=} \mathsf{Feistel}_{F_k, F_k, F_k}(x).$$
>
> (Note that the same key is used in each round.) Show that $F^*$ is not a pseudorandom permutation.

**Solution.**

When the same key $k$ is used in each round, computing $F^*$ in the forward direction is essentially the same as inverting it. In particular, for every $L_0, R_0 \in \{0,1\}^{n/2}$ it holds that $F_k^*(L_0, R_0) = {F^*}_k^{-1}(R_0, L_0)$. In order to see this, observe that the only difference between computing $F^*$ in the forward or reverse direction is that in the forward direction the first input to $F_k$ in the first round is $R_0$, whereas in the reverse direction the first input to $F_k$ is $R_2 = L_3$ (see Figure 8.3 in the book).

This observation yields the following distinguisher $D$: set $x = 0^n$ and query the oracle to receive $y = (L_3, R_3)$. Then, query $x^{\prime} = (R_3, L_3)$ to the oracle. If the response equals ${0}^n$ then output 0; otherwise, output 1.【原文如此】 Based on what we have explained above

$$\Pr\left[D^{F_k^*(\cdot)}(1^n) = 1\right] = 1$$

whereas

$$\Pr\left[D^{f(\cdot)}(1^n) = 1\right] \approx 2^{-n}$$

since for a random permutation $f$, the probability that $f(f(0^n)) = 0^n$ is roughly ${2}^{-n}$.

## 8.19

> **题目**　Let $\mathcal{X}, \mathcal{Y}, \mathcal{Z}$ be probability ensembles. Prove that if $\mathcal{X} \overset{\mathrm{c}}{=} \mathcal{Y}$ and $\mathcal{Y} \overset{\mathrm{c}}{=} \mathcal{Z}$, then $\mathcal{X} \overset{\mathrm{c}}{=} \mathcal{Z}$.

**Solution.** Let $D$ be a probabilistic polynomial-time algorithm. We wish to show that there exists a negligible function $\mathsf{negl}(n)$ such that

$$\left|\Pr_{x \leftarrow X_n}[D(1^n, x) = 1] - \Pr_{z \leftarrow Z_n}[D(1^n, z) = 1]\right| \leq \mathsf{negl}(n). \qquad (8.1)$$

By the assumption, there exist negligible functions $\mathsf{negl}_1(n)$ and $\mathsf{negl}_2(n)$ such that

$$\left|\Pr_{x \leftarrow X_n}[D(1^n, x) = 1] - \Pr_{y \leftarrow Y_n}[D(1^n, y) = 1]\right| \leq \mathsf{negl}_1(n)$$

and

$$\left|\Pr_{y \leftarrow Y_n}[D(1^n, y) = 1] - \Pr_{z \leftarrow Z_n}[D(1^n, z) = 1]\right| \leq \mathsf{negl}_2(n).$$

Thus,

$$\begin{aligned} &\left|\Pr_{x \leftarrow X_n}[D(1^n,x)=1] - \Pr_{z \leftarrow Z_n}[D(1^n,z)=1]\right| \\ &= \Big|\Pr_{x \leftarrow X_n}[D(1^n,x)=1] - \Pr_{y \leftarrow Y_n}[D(1^n,y)=1] \\ &\qquad + \Pr_{y \leftarrow Y_n}[D(1^n,y)=1] - \Pr_{z \leftarrow Z_n}[D(1^n,z)=1]\Big| \\ &\leq \left|\Pr_{x \leftarrow X_n}[D(1^n,x)=1] - \Pr_{y \leftarrow Y_n}[D(1^n,y)=1]\right| \\ &\quad + \left|\Pr_{y \leftarrow Y_n}[D(1^n,y)=1] - \Pr_{z \leftarrow Z_n}[D(1^n,z)=1]\right| \\ &\leq \mathsf{negl}_1(n) + \mathsf{negl}_2(n), \end{aligned}$$

where the first inequality is by the triangle inequality. Since the sum of negligible functions is negligible, we conclude that Equation (8.1) holds.

## 8.20

> **题目**　Prove Theorem 8.31.

**Solution.**

The proof is by reduction. We show that if there exists a probabilistic polynomial-time distinguisher $D$ that distinguishes $\overline{\mathcal{X}}$ from $\overline{\mathcal{Y}}$, then there exists a probabilistic polynomial-time distinguisher $D^{\prime}$ that distinguishes a single sample of $X_n$ from a single sample of $Y_n$. Our proof uses a *hybrid argument*.

Let $D$ be a probabilistic polynomial-time distinguisher and let $\varepsilon(n)$ be a function such that

$$\left|\Pr\left[D\left(X_n^{(1)}, \ldots, X_n^{(p(n))}\right) = 1\right] - \Pr\left[D\left(Y_n^{(1)}, \ldots, Y_n^{(p(n))}\right) = 1\right]\right| = \varepsilon(n). \qquad (8.1)$$

For every $i$, we define a *hybrid* random variable $H_n^i$ as a sequence containing $i$ independent copies of $X_n$ followed by $p(n) - i$ independent copies of $Y_n$. That is:

$$H_n^i = \left(X_n^{(1)}, \ldots, X_n^{(i)}, Y_n^{(i+1)}, \ldots, Y_n^{(p(n))}\right)$$

Denote $\overline{X}_n = (X_n^{(1)}, \ldots, X_n^{(p(n))})$ and likewise for $\overline{Y}_n$. Then, $H_n^0 = \overline{Y}_n$ and $H_n^{p(n)} = \overline{X}_n$. Thus,

$$\begin{aligned} \left|\Pr[D(\overline{X}_n) = 1]\right. &- \left.\Pr[D(\overline{Y}_n) = 1]\right| \\ &= \left|\Pr[D(H_n^{p(n)}) = 1] - \Pr[D(H_n^0) = 1]\right| \\ &= \left|\sum_{i=0}^{p(n)-1} \Pr[D(H_n^i) = 1] - \sum_{i=0}^{p(n)-1} \Pr[D(H_n^{i+1}) = 1]\right| \end{aligned}$$

where the second equality follows from the fact that the only remaining terms in this telescopic sum are $\Pr[D(H_n^0) = 1]$ and $\Pr[D(H_n^{p(n)}) = 1]$.

We now construct a probabilistic polynomial-time distinguisher $D^{\prime}$ for a single sample of $X_n$ and $Y_n$. On input a sample $\alpha$ of $X_n$ or $Y_n$, $D^{\prime}$ chooses uniform $i \in \{0, \ldots, p(n) - 1\}$, generates the vector $\overline{H}_n = (X_n^{(1)}, \ldots, X_n^{(i)}, \alpha, Y_n^{(i+2)}, \ldots, Y_n^{(p(n))})$, invokes $D$ on the vector $\overline{H}_n$, and outputs whatever $D$ does. Now, if $\alpha$ is distributed according to $X_n$, then $\overline{H}_n$ is distributed exactly as $H_n^{i+1}$. In contrast, if $\alpha$ is distributed according to $Y_n$, then $\overline{H}_n$ is distributed exactly as $H_n^i$. (Note that we use the independence of the samples in making this argument.) Furthermore, each $i$ is chosen with probability exactly ${1}/p(n)$. Therefore,

$$\Pr\left[D^{\prime}(X_n) = 1\right] = \frac{1}{p(n)} \cdot \sum_{i=0}^{p(n)-1} \Pr\left[D(H_n^{i+1}) = 1\right]$$

and

$$\Pr\left[D^{\prime}(Y_n) = 1\right] = \frac{1}{p(n)} \cdot \sum_{i=0}^{p(n)-1} \Pr\left[D(H_n^i) = 1\right]$$

It follows that:

$$\begin{aligned} \left|\Pr[D^{\prime}(X_n) = 1]\right. &- \left.\Pr[D^{\prime}(Y_n) = 1]\right| \\ &= \frac{1}{p(n)} \cdot \left|\sum_{i=0}^{p(n)-1} \Pr[D(H_n^{i+1}) = 1] - \sum_{i=0}^{p(n)-1} \Pr[D(H_n^i) = 1]\right| \\ &= \frac{1}{p(n)} \cdot \left|\Pr[D(H_n^{p(n)}) = 1] - \Pr[D(H_n^0) = 1]\right| \\ &= \frac{1}{p(n)} \cdot \left|\Pr[D(\overline{X}_n) = 1] - \Pr[D(\overline{Y}_n) = 1]\right| = \frac{\varepsilon(n)}{p(n)}. \end{aligned}$$

By the assumption that $\mathcal{X}$ and $\mathcal{Y}$ are indistinguishable, we conclude that $\frac{\varepsilon(n)}{p(n)}$ is negligible, implying that $\varepsilon(n)$ itself is negligible. By Equation (8.1), this implies that $\overline{\mathcal{X}}$ is indistinguishable from $\overline{\mathcal{Y}}$, completing the proof of the theorem.

## 8.21

> **题目**　Let $\mathcal{X} = \{X_n\}_{n \in \mathbb{N}}$ and $\mathcal{Y} = \{Y_n\}_{n \in \mathbb{N}}$ be computationally indistinguishable probability ensembles. Prove that for any probabilistic polynomial-time algorithm $\mathcal{A}$, the ensembles $\{\mathcal{A}(X_n)\}_{n \in \mathbb{N}}$ and $\{\mathcal{A}(Y_n)\}_{n \in \mathbb{N}}$ are computationally indistinguishable.

**Solution.** Assume there is a probabilistic polynomial-time $\mathcal{A}$, a distinguisher $D$, and a non-negligible function $\varepsilon(\cdot)$ such that

$$\left|\Pr[D(1^n, \mathcal{A}(X_n)) = 1] - \Pr[D(1^n, \mathcal{A}(Y_n)) = 1]\right| = \varepsilon(n).$$

We construct a distinguisher $D^{\prime}$ that receives a sample $z$ (from $X_n$ or $Y_n$), runs $\mathcal{A}$ on the input (i.e., $z$, but not the ${1}^n$ part), and then runs $D$ on ${1}^n$ together with the result from $\mathcal{A}$. Finally, $D^{\prime}$ outputs whatever $D$ does. Clearly, for every $z$, $D^{\prime}(1^n, z) = 1$ if and only if $D(1^n, \mathcal{A}(z)) = 1$. Therefore,

$$\left|\Pr[D^{\prime}(1^n, X_n) = 1] - \Pr[D^{\prime}(1^n, Y_n) = 1]\right| = \varepsilon(n),$$

a contradiction.
