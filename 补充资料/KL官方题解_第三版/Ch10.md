## 10.1

> **题目**　In order to speed up the key-generation algorithm for RSA, it has been suggested to generate a large prime number by generating many small random primes, multiplying them together, and adding one (of course, then checking that the result is prime). What do you think of the security implications of this method?

**Solution.** This is not a good idea, since if a prime $p$ is generated using this method then $p-1$ will have small prime factors and so Pollard's $p-1$ algorithm can be applied.

## 10.2

> **题目**　In an execution of Algorithm 10.2, define $x^{(i)} \stackrel{\mathrm{def}}{=} F^{(i)}(x)$. Show that if, in a given execution of the algorithm, there exist $i, j \le 2^{n/2}$ such that $x^{(i)} \ne x^{(j)}$ but $x^{(i)} = x^{(j)} \bmod p$, then that execution of the algorithm outputs $p$ with overwhelming probability.

In addition (as noted already in Section 10.1.2), $x^{(i)} \ne x^{(2i)}$ with overwhelming probability if we model $F$ as a random function

In iteration $i$ of Algorithm 10.2, $x$ is set equal to $x^{(i)}$ and $x^{\prime}$ is set equal to $x^{(2i)}$. Thus, iteration $i$ of the algorithm will output $p$ with overwhelming probability.

## 10.3

> **题目**　(a) Show that if $ab = c \bmod N$ and $\gcd(b, N) = d$, then: (i) $d \mid c$; (ii) $a \cdot (b/d) = (c/d) \bmod (N/d)$; and (iii) $\gcd(b/d, N/d) = 1$.
>
> (b) Describe how to use the above to compute $\log_g h$ in $\mathbb{Z}_N$ even when $g$ is not a generator of $\mathbb{Z}_N$ (but $h \in \langle g \rangle$).

**Solution.**

(a) Since $ab = c \bmod N$, we have $ab - \alpha N = c$ for some integer $\alpha$. Since $d \mid b$ and $d \mid N$, it follows immediately that $d \mid c$, proving (i). Furthermore, $a(b/d) - \alpha(N/d) = c/d$, proving (ii). To prove (iii), let $d^{\prime}$ be a positive integer dividing both $b/d$ and $N/d$. Then $dd^{\prime}$ divides both $b$ and $N$. Since $d = \gcd(b, N)$, this implies $d^{\prime} = 1$.

(b) Given $N$ along with $g, h \in \mathbb{Z}_N$, we want $x \in \{0, \ldots, N-1\}$ with $x \cdot g = h \bmod N$. If $g$ is a generator then, as discussed in Section 9.1.2, we may compute $x = [h \cdot g^{-1} \bmod N]$. If $g$ is not a generator then $d := \gcd(g, N) > 1$. If $d \nmid h$ then, by (i), no solution exists. (Here $h \in \langle g \rangle$ is guaranteed, so a solution does exist.) If $d \mid h$, then by (ii) we need only solve $x \cdot (g/d) = (h/d) \bmod (N/d)$. By (iii), $\gcd(g/d, N/d) = 1$, and so $x = [(h/d) \cdot (g/d)^{-1} \bmod (N/d)]$.

## 10.4

> **题目**　Here we consider how to solve the discrete-logarithm problem in a cyclic group $\mathbb{G}$ of order $q = p^e$ using $\mathcal{O}(e\sqrt{p})$ group operations. We are given as input a generator $g$ and an element $h$ and want to compute $x = \log_g h$.
>
> (a) Show how to compute $[x \bmod p]$ using $\mathcal{O}(\sqrt{p})$ group operations.
>
> (b) Say $x = x_0 + x_1 \cdot p + \cdots + x_{e-1} \cdot p^{e-1}$ with ${0} \le x_i < p$, i.e., write $x$ in base $p$. In the previous step we determined $x_0$. Show how to compute a value $h_1$ such that $(g^p)^{x_1 + x_2 \cdot p + \cdots + x_{e-1} \cdot p^{e-2}} = h_1$.
>
> (c) Show a recursive algorithm computing the discrete logarithm $x$ in the claimed running time.

**Solution.**

(a) As suggested by the hint, set $g_0 := g^{p^{e-1}}$ and $h_0 := h^{p^{e-1}}$. Note that $g_0^x = h_0$, and so there must exist an $x_0 \in \{0, \ldots, \mathsf{ord}(g_0) - 1\}$ such that $g_0^{x_0} = h_0$. Since $\mathsf{ord}(g_0) = p^e/p^{e-1} = p$, it follows that $x_0 = [x \bmod p]$. Working in the group of order $p$ generated by $g_0$, we can compute $x_0$ in time $\sqrt{p}$ using, e.g, the baby-step/giant-step algorithm.

(b) Setting $h_1 := h \cdot g^{-x_0}$ works. This is so since

$$
\begin{aligned}
h \cdot g^{-x_0} &= g^{x_0 + x_1 \cdot p + \cdots + x_{e-1} \cdot p^{e-1}} \cdot g^{-x_0} \\
&= (g^p)^{x_1 + x_2 \cdot p + \cdots + x_{e-1} \cdot p^{e-2}}.
\end{aligned}
$$

(c) Note that $\mathsf{ord}(g^p) = p^{e-1}$, and so the group $\mathbb{G}_1$ generated by $g^p$ has order $p^{e-1}$. Letting $x^{\prime} \stackrel{\mathrm{def}}{=} x_1 + x_2 \cdot p + \cdots + x_{e-1} \cdot p^{e-2}$, we can apply the result from part (a) in the group $\mathbb{G}_1$ to compute $[x^{\prime} \bmod p] = x_1$. Repeatedly applying parts (b) and (a) thus allows us to compute $x_2, \ldots, x_{e-1}$ and hence all of $x$. The computation requires a total of $\mathcal{O}(e) = \mathcal{O}(\log q)$ computations, each requiring $\mathcal{O}(\sqrt{p})$ group operations.

## 10.5

> **题目**　Let $q$ have prime factorization $q = \prod_{i=1}^{k} p_{i}^{e_{i}}$. Using the result from the previous problem, show a modification of the Pohlig-Hellman algorithm that solves the discrete-logarithm problem in a group of order $q$ using $\mathcal{O}\left(\sum_{i=1}^{k} e_{i} \sqrt{p_{i}}\right)$ group operations.

**Solution.** Using the Pohlig-Hellman algorithm, a discrete-logarithm computation in a group of order $q$ reduces to $k$ discrete-logarithm computations in groups of order $p_1^{e_1}, \ldots, p_k^{e_k}$. The previous exercise shows that discrete logarithms in a group of order $p^e$ can be computed using $\mathcal{O}(e\sqrt{p})$ group operations. The total computation is thus $\mathcal{O}\left(\sum_{i=1}^{k} e_i \sqrt{p_i}\right)$ group operations.

## 10.6

> **题目**　Let $\mathbb{G}$ be a cyclic group of order $q$, with generator $g$. Let $h \in \mathbb{G}$ be given, where it is known that $h = g^x$ for $x \in [a, b]$ (and $a$,$b$ are known). Show how to modify the baby-step/giant-step algorithm to compute $\log_g h$ using $\mathcal{O}(\sqrt{b-a})$ group operations.

**Solution.** Let $t = \sqrt{b-a}$. Compute $g_i := g^{a + i \cdot t}$ for $i = 1, \ldots, t$. Then compute $h_i := h \cdot g^i$ for $i = 1, \ldots, t$. For some $i$,$k$ it will hold that $h_i = g_k$; return $\log_g h = a + kt - i$.

## 10.7

> **题目**　Based on the ideas described in Section 10.2.3, give pseudocode for a generic algorithm that computes discrete logarithms in a group of order $q$ using $\mathcal{O}(\sqrt{q})$ group operations and $O(1)$ memory. Also give a heuristic analysis of the probability with which your algorithm succeeds.

**Solution.** Let $g, h \in \mathbb{G}$ be given; we want to compute $\log_g h$. To do this, define $F : \mathbb{G} \to \mathbb{Z}_q \times \mathbb{Z}_q$ (modeled as a random function), $H_{g,h} : \mathbb{Z}_q \times \mathbb{Z}_q \to \mathbb{G}$, and $H = H_{g,h} \circ F : \mathbb{G} \to \mathbb{G}$ as in Section 10.2.3. Use Algorithm 6.9 to find a collision $k, k^{\prime}$ in $H$ using $\sqrt{q}$ invocations of $H$, and hence $\sqrt{q}$ invocations of $F$. With overwhelming probability, $F(k) \ne F(k^{\prime})$; this follows from Lemma A.15 because the range of $F$ has size $q^2$. Thus, $F(k), F(k^{\prime})$ are a collision in $H_{g,h}$, and as discussed in Theorem 9.79 allow computation of $\log_g h$.
