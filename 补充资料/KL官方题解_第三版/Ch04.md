## 4.1

> **题目**　Consider an extension of the definition of secure message authentication where the adversary is provided with both a $\mathsf{Mac}$ and a $\mathsf{Vrfy}$ oracle.
>
> (a) Provide a formal definition of security for this case.
>
> (b) Assume $\Pi$ is a deterministic MAC using canonical verification that satisfies Definition 4.2. Prove that $\Pi$ also satisfies your definition from part (a).

**Solution.**

(a) Consider the following modified experiment:

The message authentication experiment $\mathsf{Mac\text{-}forge}^{\prime}_{\mathcal{A},\Pi}(n)$:

1. Compute $k \leftarrow \mathsf{Gen}(1^n)$.
2. The adversary $\mathcal{A}$ is given input ${1}^n$ and oracle access to $\mathsf{Mac}_k(\cdot)$ and $\mathsf{Vrfy}_k(\cdot,\cdot)$. The adversary eventually outputs a pair $(m, t)$. Let $\mathcal{Q}$ denote the set of all queries that $\mathcal{A}$ asked to its $\mathsf{Mac}_k(\cdot)$ oracle.
3. The output of the experiment is defined to be 1 if and only if (1) $\mathsf{Vrfy}_k(m,t) = 1$ and (2) $m \notin \mathcal{Q}$.

The definition of security is the same as Definition 4.2, except that it relates to $\mathsf{Mac\text{-}forge}^{\prime}$ instead of $\mathsf{Mac\text{-}forge}$.

(b) When $\Pi$ is deterministic and has canonical verification, each message has only a single valid tag. Thus, if the scheme is secure according to Definition 4.2, then access to a $\mathsf{Vrfy}$ oracle does not help (and so $\Pi$ is secure in the sense of the definition given in part (a)). To see this, note that for any query $(m, t)$ to the $\mathsf{Vrfy}$ oracle there are 3 possibilities:

1. $m$ was previously queried to the $\mathsf{Mac}$ oracle, and response $t$ was received. Here the adversary already knows that $\mathsf{Vrfy}_k(m,t) = 1$.
2. $m$ was previously queried to the $\mathsf{Mac}$ oracle, and response $t^{\prime} \ne t$ was received. Since $\Pi$ is deterministic, here the adversary already knows that $\mathsf{Vrfy}_k(m,t) = 0$.
3. $m$ was not previously queried to the $\mathsf{Mac}$ oracle. By security of $\Pi$, we can argue that $\mathsf{Vrfy}_k(m,t) = 0$ with all but negligible probability.

This can be turned into a formal proof.

## 4.2

> **题目**　Assume secure MACs exist. Give a construction of a MAC that is secure with respect to Definition 4.2 but that is not secure when the adversary is additionally given access to a $\mathsf{Vrfy}$ oracle (cf. the previous exercise).

**Solution.** Let $\Pi = (\mathsf{Gen}, \mathsf{Mac}, \mathsf{Vrfy})$ be any secure MAC. Define the scheme $\Pi^{\prime} = (\mathsf{Gen}, \mathsf{Mac}^{\prime}, \mathsf{Vrfy}^{\prime})$ as follows:

(a) $\mathsf{Mac}^{\prime}_k(m)$ computes $t = \mathsf{Mac}_k(m)$ and outputs $\langle 0, t, 0, 0\rangle$.

(b) $\mathsf{Vrfy}^{\prime}_k(m, \langle c, t, i, b\rangle)$ works as follows: if $c = 0$ then it outputs 1 if and only if $\mathsf{Vrfy}_k(m, t) = 1$; if $c = 1$ then it outputs 1 if and only if $\mathsf{Vrfy}_k(m, t) = 1$ and the $i$th bit of the key $k$ is equal to $b$.

First observe that $\Pi^{\prime}$ is secure in the sense of Definition 4.2 because the tags returned in scheme $\Pi^{\prime}$ can be generated from the tags returned from scheme $\Pi$. Furthermore, a forgery in $\Pi^{\prime}$ requires, in particular, a forgery in $\Pi$. This can be turned into a formal proof.

On the other hand, $\Pi^{\prime}$ is insecure when an adversary $\mathcal{A}$ is given access to both a $\mathsf{Mac}$ and a $\mathsf{Vrfy}$ oracle. The attack is to query an arbitrary message $m$ to the $\mathsf{Mac}$ oracle to obtain the tag $\langle 0, t, 0, 0\rangle$. Then query the $\mathsf{Vrfy}$ oracle with $(m, \langle 1, t, i, 0\rangle)$ for $i = 1, \ldots, n$. By doing so, $\mathcal{A}$ learns the entire key $k$ and can then forge a valid tag for any message of its choice.

## 4.3

> **题目**　Prove Proposition 4.4.

**Solution.** In experiment $\mathsf{Mac-sforge}$ the attacker succeeds if it outputs $(m, t)$ with $\mathsf{Vrfy}_k(m, t) = 1$ and either (1) $m$ was never queried to the $\mathsf{Mac}$ oracle or (2) $m$ was queried to the $\mathsf{Mac}$ oracle, but the response was not equal to $t$. If $\Pi$ uses canonical verification, then condition (2) cannot occur. Condition (1) is ruled out (except with negligible probability) because $\Pi$ is a secure MAC.

## 4.4

> **题目**　Assume secure MACs exist. Prove that there exists a MAC that is secure (Definition 4.2) but is *not* strongly secure (Definition 4.3).

**Solution.** Let $\Pi = (\mathsf{Gen}, \mathsf{Mac}, \mathsf{Vrfy})$ be a secure MAC. Construct $\Pi^{\prime} = (\mathsf{Gen}, \mathsf{Mac}^{\prime}, \mathsf{Vrfy}^{\prime})$ such that $\mathsf{Mac}^{\prime}_k(m)$ outputs $\mathsf{Mac}_k(m)\|0$ and such that $\mathsf{Vrfy}^{\prime}_k(m, t\|b) = \mathsf{Vrfy}_k(m, t)$. (That is, $\mathsf{Mac}^{\prime}$ appends a 0-bit to the original tag, and $\mathsf{Vrfy}^{\prime}$ ignores this extra bit.) It is immediate that the scheme is not strongly secure (since the attacker can simply flip the final bit of a tag on some message), but one can show that the scheme is still secure in the sense of Definition 4.2.

## 4.5

> **题目**　Consider the following MAC for messages of length $\ell(n) = 2n - 2$ using a pseudorandom function $F$: On input a message $m_0\|m_1$ (with $|m_0| = |m_1| = n - 1$) and key $k \in \{0,1\}^n$, algorithm $\mathsf{Mac}$ outputs $t = F_k(0\|m_0)\|F_k(1\|m_1)$. Algorithm $\mathsf{Vrfy}$ is defined in the natural way. Is this MAC secure? Prove your answer.

**Solution.** This scheme is not secure. Let $\mathcal{A}$ be an adversary that queries its oracle with two messages $m = m_0\|m_1$ and $m^{\prime} = m^{\prime}_0\|m^{\prime}_1$, where $m_0 \ne m^{\prime}_0$ and $m_1 \ne m^{\prime}_1$. Let $t = t_0\|t_1$ and $t^{\prime} = t^{\prime}_0\|t^{\prime}_1$ be the respective responses from its oracle. $\mathcal{A}$ then outputs the message $\tilde{m} = m_0\|m^{\prime}_1$ and tag $\tilde{t} = t_0\|t^{\prime}_1$. By the definition of $\mathsf{Mac}$, it follows that $\tilde{t}$ is a correct tag for $\tilde{m}$ and thus $\mathsf{Vrfy}_k(\tilde{m}, \tilde{t}) = 1$ always. Furthermore, since $m_0 \ne m^{\prime}_0$ and $m_1 \ne m^{\prime}_1$ we have that $\tilde{m} \notin \mathcal{Q}$. Thus $\mathcal{A}$ succeeds with probability 1 and the scheme is not secure.

## 4.6

> **题目**　Let $F$ be a pseudorandom function. Show that each of the following MACs is insecure, even if used to authenticate fixed-length messages. (In each case $\mathsf{Gen}$ outputs a uniform $k \in \{0,1\}^n$; we let $\langle i\rangle$ denote an $n/2$-bit encoding of the integer $i$.)
>
> (a) To authenticate a message $m = m_1, \ldots, m_\ell$, where $m_i \in \{0,1\}^n$, compute $t := F_k(m_1) \oplus \cdots \oplus F_k(m_\ell)$.
>
> (b) To authenticate a message $m = m_1, \ldots, m_\ell$, where $m_i \in \{0,1\}^{n/2}$, compute $t := F_k(\langle 1\rangle\|m_1) \oplus \cdots \oplus F_k(\langle \ell\rangle\|m_\ell)$.
>
> (c) To authenticate a message $m = m_1, \ldots, m_\ell$, where $m_i \in \{0,1\}^{n/2}$, choose uniform $r \leftarrow \{0,1\}^n$, compute
>
> $$t := F_k(r) \oplus F_k(\langle 1\rangle\|m_1) \oplus \cdots \oplus F_k(\langle \ell\rangle\|m_\ell),$$
>
> and let the tag be $\langle r, t\rangle$.

**Solution.**

(a) Let $m_1$, $m_2 \in \{0,1\}^n$ be distinct. Then, the tag on the message $m_1$, $m_2$ is identical to the tag on $m_2$, $m_1$. Thus, an adversary $\mathcal{A}$ can ask for a tag on $m_1$, $m_2$ and output the message $m_2$, $m_1$ together with the tag it received.

(b) Let $m_1$, $m^{\prime}_1$, $m_2$, $m^{\prime}_2 \in \{0,1\}^{n/2}$ with $m_1 \ne m^{\prime}_1$ and $m_2 \ne m^{\prime}_2$. The attacker obtains tag $t_1$ on the message $m_1$, $m_2$; tag $t_2$ on the message $m_1$, $m^{\prime}_2$; and tag $t_3$ on the message $m^{\prime}_1$, $m_2$. One can then verify that $t_1 \oplus t_2 \oplus t_3$ is a valid tag on $m^{\prime}_1$, $m^{\prime}_2$.

(c) Let $m_1 \in \{0,1\}^{n/2}$ be arbitrary. The attacker can set $r := \langle 1\rangle\|m_1$ and output the forgery $\langle r, 0^n\rangle$ on the message $m_1$.

## 4.8

> **题目**　Given any *deterministic* MAC $(\mathsf{Mac}, \mathsf{Vrfy})$, we may view $\mathsf{Mac}$ as a keyed function. In both Constructions 4.5 and 4.9, $\mathsf{Mac}$ is a pseudorandom function. Give a construction of a secure, deterministic MAC in which $\mathsf{Mac}$ is *not* a pseudorandom function.

**Solution.** There are many possible answers; we give one. Let $F$ be a pseudorandom function and define $\mathsf{Mac}_k(m) = \langle F_k(m), F_k(m)\rangle$ (verification is done in the obvious way). This is not pseudorandom, but is still a secure MAC.

## 4.9

> **题目**　Is Construction 4.5 necessarily secure when instantiated using a weak pseudorandom function (cf. Exercise 3.28)? Explain.

**Solution.** No, it is not necessarily secure in this case. For concreteness, consider the weak pseudorandom function $F^{\prime}$ from Exercise 3.28, part (b). In this case for an odd $x$ it holds that $F^{\prime}_k(x) = F^{\prime}_k(x+1)$. Thus, an adversary can query its oracle to obtain a tag on an odd message $m$ and output a valid forgery for the even message $m+1$.

## 4.10

> **题目**　Prove that Construction 4.7 is a secure MAC even when the adversary is additionally given access to a $\mathsf{Vrfy}$ oracle (cf. Exercise 4.1), assuming $\Pi^{\prime}$ is a secure MAC that uses canonical verification.

**Solution.** As in the proof of Theorem 4.8, a forgery in $\Pi$ yields a forgery in $\Pi^{\prime}$. Moreover, a verification oracle for $\Pi$ can be simulated using a verification oracle for $\Pi^{\prime}$. Since $\Pi^{\prime}$ is secure even when given access to a verification oracle (since it uses canonical verification), it follows that $\Pi$ is secure in that case as well.

## 4.11

> **题目**　Prove that Construction 4.7 is strongly secure if $\Pi^{\prime}$ is strongly secure.

**Solution.** (Note that the stated result assumes $\Pi^{\prime}$ is strongly secure.) Note that we only need to consider the case where the attacker outputs $(m, t)$ for which $m$ was previously authenticated (possibly multiple times), but never using tag $t$ (since the case where $m$ is a message that was never previously authenticated is already handled by Theorem 4.8). We show how to modify the proof of Theorem 4.8 for this case, and borrow notation from there. $\mathsf{Repeat}$ is defined identically, and $\Pr[\mathsf{Repeat}]$ is still negligible. We now let $\mathsf{NewBlock}$ be the event that either one of the blocks $r\|\ell\|i\|m_i$ was never previously authenticated, or it was previously authenticated but not using tag $t_i$. As before, $\Pr[\mathsf{NewBlock}]$ is negligible, now based on strong security of $\Pi^{\prime}$. Using a case analysis, one can show that if neither $\mathsf{Repeat}$ nor $\mathsf{NewBlock}$ occur, then the attacker cannot succeed.

## 4.12

> **题目**　Prove that Construction 4.7 is secure if it is changed as follows: Set $t_i := F_k(r\|b\|i\|m_i)$, where $b$ is a single bit such that $b = 0$ in all blocks but the last one, and $b = 1$ in the last block. (Assume for simplicity that the length of all messages being authenticated is always an integer multiple of $n/2 - 1$.) What is the advantage of this modification?

**Solution.** Intuitively, the scheme is still secure because the length of the message is only included to prevent a “truncation” attack where some number of blocks at the end of the message are dropped.

The formal proof is largely the same as the proof of Theorem 4.8, and we use the same notation as there. Recall that the adversary outputs $(m, t)$ with $m = m_1, \ldots, m_d$ and $t = \langle r, t_1, \ldots, t_d\rangle$; now it is required that $m_i \in \{0,1\}^{n/2-1}$ and no padding is applied. $\Pr[\mathsf{Repeat}]$ is still negligible. When $\mathsf{Repeat}$ does not occur, if $r \notin \{r_1, \ldots, r_q\}$ then clearly $\mathsf{NewBlock}$ occurs. Otherwise $r = r_j$ for some unique $j$, and then:

(a) If $\ell \ne \ell_j$ then the block $r\|1\|d\|m_d$ was never authenticated before by the MAC oracle, and so $\mathsf{NewBlock}$ occurs in this case.

(b) If $\ell = \ell_j$ then $m^{\prime} = m^{\prime}_1, \ldots, m^{\prime}_d$ but there must be an $i$ such that $m^{\prime}_i \ne m_i$. Then the block $r\|b\|i\|m_i$ was never previously authenticated by the MAC oracle (where $b$ is 1 or 0 depending on whether $i = d$ or not).

The advantage is that computation is reduced and the tag is shorter since more bits of the message are processed with each invocation of $F$.

## 4.13

> **题目**　We explore what happens when the basic CBC-MAC construction is used with messages of different lengths.
>
> (a) Say the sender and receiver do not agree on the message length in advance (and so $\mathsf{Vrfy}_k(m, t) = 1$ iff $t \stackrel{?}{=} \mathsf{Mac}_k(m)$, regardless of the length of $m$), but the sender is careful to only authenticate messages of length ${2}n$. Show that an adversary can forge a valid tag on a message of length ${4}n$.
>
> (b) Say the receiver only accepts 3-block messages (so $\mathsf{Vrfy}_k(m, t) = 1$ only if $m$ has length ${3}n$ and $t \stackrel{?}{=} \mathsf{Mac}_k(m)$), but the sender authenticates messages of any length a multiple of $n$. Show that an adversary can forge a valid tag on a new message.

**Solution.** There are multiple solutions; we provide one in each case.

(a) Let $m_1$, $m_2 \in \{0,1\}^n$ be arbitrary. The attacker requests a tag on the message $m_1$, $m_2$, and obtains in return a tag $t$. One can check that $t$ is also a valid tag on the message $m_1$, $m_2$, $m_1 \oplus t$, $m_2$.

(b) Let $m_1$, $m_2$, $m_3 \in \{0,1\}^n$ be arbitrary. Obtain tag $t_1$ on the message $m_1$, tag $t_2$ on the message $t_1 \oplus m_2$, and tag $t_3$ on the message $t_2 \oplus m_3$. Then $t_3$ is a valid tag for the 3-block message $m_1$, $m_2$, $m_3$.

## 4.14

> **题目**　Prove that the following modifications of basic CBC-MAC do not yield a secure MAC (even for fixed-length messages):
>
> (a) $\mathsf{Mac}$ outputs all blocks $t_1, \ldots, t_\ell$, rather than just $t_\ell$. (Verification only checks whether $t_\ell$ is correct.)
>
> (b) A random initial block is used each time a message is authenticated. That is, change Construction 4.9 by choosing uniform $t_0 \in \{0,1\}^n$, computing $t_\ell$ as before, and then outputting the tag $\langle t_0, t_\ell\rangle$; verification is done in the natural way.

**Solution.**

(a) Consider the following attack: Adversary $\mathcal{A}$ queries its oracle with arbitrary $m_1$, $m_2$. It receives back the tag $t_1, t_2$, where $t_1 = F_k(m_1)$ and $t_2 = F_k(t_1 \oplus m_2)$. Next, $\mathcal{A}$ outputs the message $t_1 \oplus m_2\|t_2 \oplus m_1$ and the tag $t_2, t_1$. This is a valid forgery (unless $t_1 \oplus m_2 = m_1$ and $t_2 \oplus m_1 = m_2$, which occurs with only negligible probability) since $t_2 = F_k(t_1 \oplus m_2)$ and

$$t_1 = F_k(t_2 \oplus t_2 \oplus m_1) = F_k(m_1).$$

(b) Consider the following attack: obtain tag $(t_0, t)$ on the one-block message $m$. Then output $(m, t)$ as a valid tag for the message $t_0$.

## 4.15

> **题目**　Show that appending the message length to the end of the message before applying basic CBC-MAC does not result in a secure MAC for arbitrary-length messages.

**Solution.** (We provide the solution, but it will help to draw a diagram to confirm that the solution is correct.) One attack is as follows: obtain tag $t$ on the 1-block message $m$; the tag $s$ on the 3-block message $m$, $\langle n\rangle$, $t$ (where $\langle n\rangle$ denotes the integer $n$ encoded as an $n$-bit string); and the tag $t^{\prime}$ on the 1-block message $m^{\prime}$ (with $m^{\prime} \ne m$). Then one can verify that $s$ is a valid tag on the 3-block message $m^{\prime}$, $\langle n\rangle$, $t^{\prime}$.

## 4.16

> **题目**　Define a version of CBC-MAC for messages of length at most $\ell \cdot 2^n$ as follows: given a message $m$, pad it with 0s so that it has length exactly $\ell \cdot 2^n$; apply basic CBC-MAC to the result. Is this secure?

**Solution.** This is not secure, since the tag on the 1-block message $m$ is the same as the tag on the 2-block message $m, 0^n$.

## 4.17

> **题目**　Consider the following encoding that handles messages whose length is less than $n \cdot 2^n$: We encode a string $m \in \{0,1\}^*$ by first appending as many 0s as needed to make the length of the resulting string $\hat{m}$ a nonzero multiple of $n$. Then we prepend the number of blocks in $\hat{m}$ (equivalently, prepend the integer $|\hat{m}|/n$), encoded as an $n$-bit string. Show that this encoding is not prefix-free.

**Solution.** The encoding of $m = 1$ is the string $\langle 1\rangle\|1\|0^{n-1}$. The encoding of $m = 10$ is $\langle 1\rangle\|10\|0^{n-2}$. These are identical!

## 4.18

> **题目**　Show that the encoding for arbitrary-length messages described in Section 4.4.2 is prefix-free.

**Solution.** Let $X$ and $X^{\prime}$ be encodings of two different messages $m$, $m^{\prime}$. Note that $X$ can be parsed as $X = \langle i\rangle\|m\|0^t$ where $i$ is the length of $m$, the notation $\langle i\rangle$ denotes the $n$-bit encoding of $i$, and $t \in \{0, \ldots, n-1\}$ is such that $n + i + t$ is a multiple of $n$. We can similarly parse $X^{\prime}$ as $X^{\prime} = \langle j\rangle\|m^{\prime}\|0^{t^{\prime}}$. If $i \ne j$, then neither $X$ nor $X^{\prime}$ is a prefix of the other. If $i = j$, then $t = t^{\prime}$ and $m$ and $m^{\prime}$ have the same length. But since $m \ne m^{\prime}$ neither $X$ nor $X^{\prime}$ is a prefix of the other.

## 4.19

> **题目**　Prove that the following modification of basic CBC-MAC gives a secure MAC for arbitrary-length messages if $F$ is a pseudorandom function. (Assume all messages have length a multiple of the block length.) $\mathsf{Mac}_k(m)$ first computes $k_\ell := F_k(\ell)$, where $\ell$ is the length of $m$. The tag is then computed using basic CBC-MAC with key $k_\ell$.

**Solution.** Assume $F$ is a pseudorandom function. Roughly speaking, this construction reduces to fixed-length CBC-MAC where an independent key $k_\ell$ is used for messages of length $\ell$. Since fixed-length CBC-MAC is secure, the overall construction is secure. A full solution would require a formal proof.

## 4.20

> **题目**　Let $F$ be a keyed function that is a secure (deterministic) MAC for messages of length $n$. (Note that $F$ need not be a pseudorandom function.) Show that basic CBC-MAC is not necessarily a secure MAC (even for fixed-length messages) when instantiated with $F$.

**Solution.** Several solutions are possible; we present one. Let $F^{\prime}$ be a pseudorandom function with $n$-bit input length and $n/2$-bit output length. Define $F_k(m) = F^{\prime}_k(m)\|\langle i\rangle$, where $\langle i\rangle$ is an $n/2$-bit encoding of the number of initial 0s in $m$. This $F$ is still a secure MAC. But now consider basic CBC-MAC instantiated with $F$, for simplicity for messages of length ${2}n$. By requesting tags on messages of the form $m_1$, $m_2$ with $m_1$ fixed and $m_2$ varying bit-by-bit starting from the left, the value of the intermediate result $t = F_k(m_1)$ can be learned. It is then easy to forge a tag on the message $m_1$, $m_1 \oplus t$.

## 4.22

> **题目**　Prove or disprove whether the following functions are $\ell/|\mathbb{F}|$-difference universal. In each case assume $\mathcal{K} = \mathbb{F}$ and $\mathcal{M} = \mathbb{F}^{<\ell}$, and for a message $m = (m_1, \ldots, m_{\ell^{\prime}-1})$ let $m_{\ell^{\prime}} \in \mathbb{F}$ be an encoding of $\ell^{\prime} - 1$.
>
> (a) $h^{\prime}_k(m) = m^{\prime}(k)$, where
>
> $$m^{\prime}(X) \stackrel{\mathrm{def}}{=} m_1 \cdot X^\ell + m_2 \cdot X^{\ell-1} + \cdots + m_{\ell^{\prime}} \cdot X^{\ell-\ell^{\prime}+1}.$$
>
> (b) $h^{\prime\prime}_k(m) = m^{\prime\prime}(k)$, where
>
> $$m^{\prime\prime}(X) \stackrel{\mathrm{def}}{=} m_1 \cdot X^{\ell^{\prime}-1} + m_2 \cdot X^{\ell^{\prime}-2} + \cdots + m_{\ell^{\prime}}.$$
>
> (c) $h^{\prime\prime\prime}_k(m) = m^{\prime\prime\prime}(k)$, where
>
> $$m^{\prime\prime\prime}(X) \stackrel{\mathrm{def}}{=} m_1 \cdot X + m_2 \cdot X^2 + \cdots + m_{\ell^{\prime}} \cdot X^{\ell^{\prime}}.$$

**Solution.** As in the proof of Theorem 4.17, we fix distinct $a, b \in \mathbb{F}^{<\ell}$ and $\Delta \in \mathbb{F}$ and look at a certain polynomial of degree at most $\ell$ that depends on the function under consideration. The function is $\ell/|\mathbb{F}|$-difference universal iff the resulting polynomial is always nonzero.

(a) Here we consider the polynomial $P^{\prime}(X) = a^{\prime}(X) - b^{\prime}(X) - \Delta$. This is always a nonzero polynomial: if $a$, $b$ have the same length this is immediate; if they have different lengths (say, $\ell^{\prime}_a > \ell^{\prime}_b \ge 1$) then the coefficient of $X^{\ell-\ell^{\prime}_a+1}$ in $P^{\prime}(X)$ is nonzero. Hence the function is $\ell/|\mathbb{F}|$-difference universal.

(b) Let $a = (0, 0)$ and $b = (0)$ and $\Delta = 1$. Then $a^{\prime\prime}(X) = 2$ and $b^{\prime\prime}(X) = 1$, and the polynomial $P^{\prime\prime}(X) = a^{\prime\prime}(X) - b^{\prime\prime}(X) - \Delta$ is the zero polynomial. So the function is not $\ell/|\mathbb{F}|$-difference universal.

(c) Here we consider the polynomial $P^{\prime\prime\prime}(X) = a^{\prime\prime\prime}(X) - b^{\prime\prime\prime}(X) - \Delta$. This is always a nonzero polynomial: if $a$, $b$ have the same length this is immediate; if they have different lengths (say, $\ell^{\prime}_a > \ell^{\prime}_b \ge 1$) then the coefficient of $X^{\ell^{\prime}_a}$ in $P^{\prime\prime\prime}(X)$ is nonzero. Hence the function is $\ell/|\mathbb{F}|$-difference universal.

## 4.24

> **题目**　Fix $\ell > 0$ and a prime $p$. Let $\mathcal{K} = \mathbb{Z}_p^{\ell+1}$, $\mathcal{M} = \mathbb{Z}_p^\ell$, and $\mathcal{T} = \mathbb{Z}_p$. Define $h : \mathcal{K} \times \mathcal{M} \rightarrow \mathcal{T}$ as
>
> $$h_{k_0, k_1, \ldots, k_\ell}(m_1, \ldots, m_\ell) = [k_0 + \sum_i k_i m_i \bmod p].$$
>
> Prove that $h$ is strongly universal.

**Solution.** Fix distinct $m = (m_1, \ldots, m_\ell)$ and $m^{\prime} = (m^{\prime}_1, \ldots, m^{\prime}_\ell)$ and arbitrary $t, t^{\prime} \in \mathbb{Z}_p$. Then $h_{k_0, k_1, \ldots, k_\ell}(m) = t$ and $h_{k_0, k_1, \ldots, k_\ell}(m^{\prime}) = t^{\prime}$ if and only if

$$
t = k_0 + \sum_i k_i m_i \qquad \text{and} \qquad t^{\prime} = k_0 + \sum_i k_i m^{\prime}_i\tag{4.1}
$$

where everything is modulo $p$. We count the number of keys satisfying the above. Let $i^*$ be maximal such that $m_{i^*} \ne m^{\prime}_{i^*}$. Let $k_1, \ldots, k_{i^*-1}$ and $k_{i^*+1}, \ldots, k_\ell$ be arbitrary. We then obtain the equations

$$t - \sum_{i \ne i^*} k_i m_i - k_0 = k_{i^*} m_{i^*} \qquad \text{and} \qquad t^{\prime} - \sum_{i \ne i^*} k_i m^{\prime}_i - k_0 = k_{i^*} m^{\prime}_{i^*}.$$

Subtracting, we obtain

$$t - t^{\prime} - \sum_{i \ne i^*} k_i m_i + \sum_{i \ne i^*} k_i m^{\prime}_i = k_{i^*}(m_{i^*} - m^{\prime}_{i^*}),$$

which uniquely determines $k_{i^*}$ since $m_{i^*} - m^{\prime}_{i^*} \ne 0$ and $p$ is prime. The original equations then uniquely determine $k_0$. We conclude that exactly $p^{\ell-1}$ keys satisfy (4.1), and so the probability that a uniform key satisfies those equations is $p^{\ell-1}/p^{\ell+1} = 1/|\mathcal{T}|^2$, as required.

## 4.25

> **题目**　Fix $\ell, n > 0$. Let $\mathcal{K} = \{0,1\}^{\ell \times n} \times \{0,1\}^{\ell}$ (interpreted as a boolean $\ell \times n$ matrix and an $\ell$-dimensional vector), let $\mathcal{M} = \{0,1\}^{n}$, and let $\mathcal{T} = \{0,1\}^{\ell}$. Define $h : \mathcal{K} \times \mathcal{M} \to \mathcal{T}$ as $h_{K,v}(m) = K \cdot m \oplus v$, where all operations are performed modulo 2. Prove that $h$ is strongly universal.

**Solution.** Fix distinct $m, m^{\prime}$ and arbitrary $t, t^{\prime}$. Then $h_{K,v}(m) = t$ and $h_{K,v}(m^{\prime}) = t^{\prime}$ if and only if

$$
K m \oplus v = t \qquad \text{and} \qquad K m^{\prime} \oplus v = t^{\prime}.\tag{4.2}
$$

Subtracting, we see the above hold only if $K \cdot (m - m^{\prime}) = t - t^{\prime}$. Let $i$ be the largest index for which the $i$th coordinate of $m - m^{\prime}$ is nonzero. Then we may set all columns of $K$ other than the $i$th column arbitrarily to any of ${2}^{\ell \cdot (n-1)}$ possibilities; there is then a unique value of the $i$th column for which $K \cdot (m - m^{\prime}) = t - t^{\prime}$. Having fixed $K$, there is a unique $v$ such that (4.2) hold. We conclude that the number of keys satisfying (4.2) is ${2}^{\ell \cdot (n-1)}$, and so the probability that a uniform key satisfies those equations is ${2}^{\ell \cdot (n-1)} / 2^{\ell \cdot (n+1)} = 1 / 2^{2\ell} = 1 / |\mathcal{T}|^2$, as required.

## 4.26

> **题目**　A *Toeplitz matrix* $K$ is a matrix in which $K_{i,j} = K_{i-1,j-1}$ when $i, j > 1$; that is, the values along any diagonal are equal. So an $\ell \times n$ Toeplitz matrix (for $\ell > n$) has the form
>
> $$\begin{bmatrix} K_{1,1} & K_{1,2} & K_{1,3} & \cdots & K_{1,n} \\ K_{2,1} & K_{1,1} & K_{1,2} & \cdots & K_{1,n-1} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ K_{\ell,1} & K_{\ell-1,1} & K_{\ell-2,1} & \cdots & K_{\ell-n+1,1} \end{bmatrix}.$$
>
> Let $\mathcal{K} = T^{\ell \times n} \times \{0,1\}^\ell$ (where $T^{\ell \times n}$ denotes the set of $\ell \times n$ Toeplitz matrices), let $\mathcal{M} = \{0,1\}^n$, and let $\mathcal{T} = \{0,1\}^\ell$. Define $h : \mathcal{K} \times \mathcal{M} \rightarrow \mathcal{T}$ as $h_{K,v}(m) = K \cdot m \oplus v$, where all operations are performed modulo 2. Prove that $h$ is strongly universal. What is the advantage here as compared to the construction in the previous exercise?

**Solution.** We first count the number of Toeplitz matrices. In the first row there are $n$ values that may be chosen. In each of the successive $(\ell-1)$ rows, the final $n-1$ elements are determined by the previous row so there is only one new value to choose. Thus, the total number of Toeplitz matrices is ${2}^{n+\ell-1}$, and the size of the key space is ${2}^{n+2\ell-1}$.

As in the previous exercise, we now count the number of keys for which $h_{K,v}(m) = t$ and $h_{K,v}(m^{\prime}) = t^{\prime}$. These equations hold only if $K(m - m^{\prime}) = t - t^{\prime}$. Let $i$ again be the largest index for which the $i$th coordinate of $m - m^{\prime}$ is nonzero. We fill in the entries of $K$ starting from the last row. The first $i-1$ entries of that row can be set arbitrarily; there is then a unique value for the $i$th entry such that the equation $K(m - m^{\prime}) = t - t^{\prime}$ can possibly be satisfied. Proceeding to the second-to-last row (we do not yet set the final $n-i$ entries of the last row), we see that the first $i-1$ entries are already fixed and there is a unique value for the $i$th entry such that the equation $K(m - m^{\prime}) = t - t^{\prime}$ can possibly be satisfied; note that this determines also the $(i+1)$st entry of the bottom row. Continuing in this manner to the top row, we see that all entries of the matrix are uniquely determined except for the final $n-i$ elements of the top row (which in turn determine the final $n-i-1$ elements of the second-to-top row, etc.). These can be set arbitrarily. Having fixed $K$, the original pair of equations then uniquely determine $v$. We conclude that the number of keys for which $h_{K,v}(m) = t$ and $h_{K,v}(m^{\prime}) = t^{\prime}$ is ${2}^{(i-1)+(n-i)} = 2^{n-1}$, and so the probability that a uniform key satisfies those equations is ${2}^{n-1}/2^{n+2\ell-1} = 1/2^{2\ell} = 1/|\mathcal{T}|^2$, as required.

The advantage of this construction is that it has shorter keys.

## 4.27

> **题目**　Define an appropriate notion of a $\varepsilon$-secure two-time MAC, and give a construction that meets your definition.

**Solution.** A definition is obtained by a straightforward modification of Definition 4.18, where the experiment now allows the attacker to (adaptively) request tags on any two messages of its choice.

The natural primitive for constructing a two-time $\varepsilon$-secure MAC is a *three-wise independent* function, i.e., a keyed function $h: \mathcal{K} \times \mathcal{M} \to \mathcal{T}$ such that for all distinct $m, m^{\prime}, m^{\prime\prime} \in \mathcal{M}$ and all $t, t^{\prime}, t^{\prime\prime} \in \mathcal{T}$,

$$\Pr[h_k(m) = t \wedge h_k(m^{\prime}) = t^{\prime} \wedge h_k(m^{\prime\prime}) = t^{\prime\prime}] = 1/|\mathcal{T}|^3$$

(where the probability is over choice of $k$). An example of such a function is given by quadratic polynomials over a field: let $\mathcal{M} = \mathcal{T} = \mathbb{Z}_p$ and $\mathcal{K} = \mathbb{Z}_p^3$, and define $h_{k_1, k_2, k_3}(m) = k_1 m^2 + k_2 m + k_3$. One can check that this satisfies the requirement.
