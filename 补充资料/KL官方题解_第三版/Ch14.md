## 14.2

> **题目**　Prove that the existence of a one-time signature scheme for one-bit messages implies the existence of one-way functions.

**Solution.** Let $(\mathsf{Gen}, \mathsf{Sign}, \mathsf{Vrfy})$ be a one-time signature scheme for one-bit messages. Since $\mathsf{Gen}$ runs in polynomial time, there exists a polynomial $p$ such that the number of random bits the algorithm uses on input ${1}^n$ is at most $p(n)$. For simplicity, assume that $\mathsf{Gen}$ always uses exactly $p(n)$ random bits on input ${1}^n$ and further than $p(n)$ is strictly increasing.【原文如此】 Define the following function $f$: on input a string $x$, compute $n$ such that $p(n) \le |x| \le p(n + 1)$. Then compute $(pk, sk) := \mathsf{Gen}(1^n; x)$ and output $pk$. It is not hard to see that $f$ must be one-way.

## 14.4

> **题目**　A *strong* one-time signature scheme satisfies the following (informally): given a signature $\sigma^{\prime}$ on a message $m^{\prime}$, it is infeasible to output $(m, \sigma) \ne (m^{\prime}, \sigma^{\prime})$ for which $\sigma$ is a valid signature on $m$ (note that $m = m^{\prime}$ is allowed).
>
> (a) Give a formal definition of strong one-time signatures.
>
> (b) Assuming the existence of one-way functions, show a one-way function for which Lamport's scheme is *not* a strong one-time signature scheme.
>
> (c) Construct a strong one-time signature scheme based on any assumption used in this book.

**Solution.**

(a) Let $\Pi = (\mathsf{Gen}, \mathsf{Sign}, \mathsf{Vrfy})$ be a signature scheme, and consider the following experiment for an adversary $\mathcal{A}$ and parameter $n$:

**The strong 1-time signature experiment** $\mathsf{Sig\text{-}forge}^{1\text{-}\mathsf{strong}}_{\mathcal{A},\Pi}(n)$:

i. $\mathsf{Gen}(1^n)$ *is run to obtain keys* $(pk, sk)$.

ii. *Adversary* $\mathcal{A}$ *is given* $pk$ *and asks a* **single** *query* $m^{\prime}$ *to oracle* $\mathsf{Sign}_{sk}(\cdot)$. *Let* $\sigma^{\prime}$ *be the signature that was returned.* $\mathcal{A}$ *then outputs* $(m, \sigma) \ne (m^{\prime}, \sigma^{\prime})$.

iii. *The output of the experiment is defined to be 1 if and only if* $\mathsf{Vrfy}_{pk}(m, \sigma) = 1$.

**Definition** *A signature scheme $\Pi = (\mathsf{Gen}, \mathsf{Sign}, \mathsf{Vrfy})$ is a **strong one-time signature scheme**, if for all probabilistic polynomial-time (PPT) adversaries $\mathcal{A}$, there exists a negligible function negl such that:*

$$\Pr\left[\mathsf{Sig\text{-}forge}^{1\text{-}\mathsf{strong}}_{\mathcal{A},\Pi}(n) = 1\right] \le \mathsf{negl}(n).$$

(b) Let $f$ be a one-way function and define $f^{\prime}$ as follows: $f^{\prime}(x \| b) = f(x)$ (where $b \in \{0, 1\}$). It is not hard to see that $f^{\prime}$ is a one-way function, but given an inverse of any point $y$ it is easy to come up with a different inverse of $y$. (Namely, given $x^{\prime} = x \| b$ such that $f^{\prime}(x^{\prime}) = y$ we know that $x^{\prime\prime} = x \| \bar{b}$ also satisfies $f^{\prime}(x^{\prime\prime}) = y$.)

When $f^{\prime}$ is used in Lamport's scheme, the resulting signature scheme is clearly not a strong one-time signature scheme. For example, take $\ell = 1$ and note that if $x^{\prime} = x \| b$ is a signature on the message 0, then so is $x^{\prime\prime} = x \| \bar{b}$.

(c) Take $f$ to be a collision-resistant hash function mapping, say, ${2}n$-bit strings to $n$-bit outputs. (See Exercise 6.1 for a proof that such a collision-resistant hash function is one-way.) This scheme is certainly a (regular) one-time signature scheme. But any two signatures $\sigma, \sigma^{\prime}$ on the same message $m$ yield a collision in the hash function. A formal proof that this scheme is a strong one-time signature scheme is immediate.

## 14.6

> **题目**　The Lamport scheme uses ${2}\ell$ values in the public key to sign messages of length $\ell$. Consider the variant in which the private key contains ${2}\ell$ values $x_1, \ldots, x_{2\ell}$ and the public key contains the values $y_1, \ldots, y_{2\ell}$ with $y_i := f(x_i)$. A message $m \in \{0, 1\}^{\ell^{\prime}}$ is mapped in a one-to-one fashion to a subset $S_m \subset \{1, \ldots, 2\ell\}$ of size $\ell$. To sign $m$, the signer reveals $\{x_i\}_{i \in S_m}$. Prove that this gives a one-time signature scheme. What is the maximum message length $\ell^{\prime}$ that this scheme supports?

**Solution.** A proof that this gives a one-time signature scheme is very similar to the proof of Theorem 14.10. Let $\Pi$ denote the scheme, and let $\mathcal{A}$ be a probabilistic polynomial-time adversary. Consider the following PPT algorithm $\mathcal{I}$ attempting to invert the one-way function $f$:

**Algorithm $\mathcal{I}$:**

The algorithm is given $y$ and ${1}^n$ as input.

- Choose $i^* \leftarrow \{1, \ldots, 2\ell\}$, and set $y_{i^*} := y$.
- For $i \in \{1, \ldots, 2\ell\} \setminus \{i^*\}$, do:
  - Choose $x_i \leftarrow \{0, 1\}^n$.
  - Set $y_i := f(x_i)$.
- Set $pk = (y_1, \ldots, y_{2\ell})$ and run $\mathcal{A}(pk)$.
- When $\mathcal{A}$ requests a signature of the message $m^{\prime}$, map $m^{\prime}$ to a subset $S_{m^{\prime}}$ of size $\ell$. If $i^* \in S_{m^{\prime}}$, then abort. Otherwise, give $\{x_i\}_{i \in S_{m^{\prime}}}$ to $\mathcal{A}$.
- When $\mathcal{A}$ outputs $(m, \sigma^{\prime} = (x_{i_1}, \ldots, x_{i_\ell}))$, map $m$ to a subset $S_m$ of size $\ell$. If $i^*$ is the first index for which $i^* \in S_m$ but $i^* \notin S_{m^{\prime}}$, then output $x_{i^*}$. Otherwise, abort.

In an execution of $\mathcal{A}$, let $m^{\prime}$ denote the message whose signature is requested by $\mathcal{A}$, and let $m \ne m^{\prime}$ denote the message whose signature is (purportedly) forged by $\mathcal{A}$. Let $S_{m^{\prime}}$ and $S_m$ be defined in the natural way, and let $j \in \{1, \ldots, 2\ell\}$ denote the first index such that $j \in S_m$ but $j \notin S_{m^{\prime}}$. (Note that such $j$ must always exist.)

In the execution of $\mathcal{I}$, above, observe that the public key given to $\mathcal{A}$ is distributed identically to the public key in a real execution of $\Pi$. Furthermore, if $\mathcal{I}$ correctly guesses $i^* = j$, then the signature given by $\mathcal{I}$ to $\mathcal{A}$ is correct. Finally, conditioned on $i^* = j$, whenever $\mathcal{A}$ outputs a valid forgery it is the case that $\mathcal{I}$ correctly inverts the given value $y$. Since $i^* = j$ with probability at least ${1}/2\ell$, we have

$$\Pr\left[\mathsf{Invert}_{\mathcal{I},f}(n) = 1\right] = \frac{1}{2\ell} \cdot \Pr\left[\mathsf{Sig\text{-}forge}^{1\text{-}\mathsf{time}}_{\mathcal{A},\Pi}(n) = 1\right].$$

Since $f$ is one-way, this implies the existence of a negligible function $\mathsf{negl}$ such that $\Pr\left[\mathsf{Sig\text{-}forge}^{1\text{-}\mathsf{time}}_{\mathcal{A},\Pi}(n) = 1\right] < \mathsf{negl}(n)$.

The number of subsets of size $\ell$ is $\binom{2\ell}{\ell}$, and so this is the number of messages that can be signed. So the maximum message length is given by $\ell^{\prime} = \lfloor \log_2 \binom{2\ell}{\ell} \rfloor$.

## 14.8

> **题目**　Prove Theorem 14.16.

**Solution.** Let $\Pi^*$ denote Construction 14.14 and let $\Pi$ denote the stateless variant, instantiated with a pseudorandom function $F$ as discussed in the book. We assume that the signing algorithm of the underlying one-time signature scheme used in Construction 14.14 is deterministic. Fix a PPT adversary $\mathcal{A}$. We now construct an algorithm $D$ that is given access to an oracle $\mathcal{O}(\cdot)$ and must decide whether $\mathcal{O}(\cdot)$ is a function chosen truly at random, or whether $\mathcal{O}(\cdot) = F_k(\cdot)$ for a uniform key $k$.

**Algorithm $D$:**

The algorithm is given ${1}^n$ and access to an oracle $\mathcal{O}(\cdot)$.

- Implement Construction 14.14 for $\mathcal{A}$. In the course of this experiment, every time randomness $r_w$ is needed to generate $(pk_w, sk_w)$ the algorithm obtains $r_w$ by querying $\mathcal{O}(w)$.
- Eventually, $\mathcal{A}$ outputs a message/signature pair $(m, \sigma)$. If this is a valid forgery then $\mathcal{A}$ outputs 1; otherwise, it outputs 0.【原文如此】

It is easy to see that if $\mathcal{O}(\cdot)$ is a function chosen at random, then $D$ exactly implements scheme $\Pi^*$ for $\mathcal{A}$; on the other hand, if $\mathcal{O}(\cdot) = F_k(\cdot)$ for a uniform key $k$ then $D$ implements $\Pi$ for $\mathcal{A}$. Therefore,

$$\begin{aligned}\left|\Pr\left[D^{F_k(\cdot)}(1^n) = 1\right] - \Pr\left[D^{f(\cdot)}(1^n) = 1\right]\right| \\ = \left|\Pr\left[\mathsf{Sig\text{-}forge}_{\mathcal{A},\Pi}(n) = 1\right] - \Pr\left[\mathsf{Sig\text{-}forge}_{\mathcal{A},\Pi^*}(n) = 1\right]\right|\end{aligned}$$

Theorem 14.14 says that there exists a negligible function $\mathsf{negl}$ for which $\Pr\left[\mathsf{Sig\text{-}forge}_{\mathcal{A},\Pi^*}(n) = 1\right] \le \mathsf{negl}(n)$. The fact that $F$ is a pseudorandom function means that there is a negligible function $\mathsf{negl}^{\prime}$ such that $\left|\Pr\left[D^{F_k(\cdot)}(1^n) = 1\right] - \Pr\left[D^{f(\cdot)}(1^n) = 1\right]\right| \le \mathsf{negl}^{\prime}(n)$. Thus,

$$\Pr\left[\mathsf{Sig\text{-}forge}_{\mathcal{A},\Pi}(n) = 1\right] \le \mathsf{negl}(n) + \mathsf{negl}^{\prime}(n).$$

Since $\mathcal{A}$ was arbitrary, this proves the theorem.
