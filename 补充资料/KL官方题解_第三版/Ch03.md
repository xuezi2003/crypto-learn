## 3.1

> **题目**　Prove Proposition 3.6.

**Solution.** Let $\mathsf{negl}_1$ and $\mathsf{negl}_2$ be negligible functions. We prove that:

1. The function $\mathsf{negl}_3$ defined by $\mathsf{negl}_3(n) = \mathsf{negl}_1(n) + \mathsf{negl}_2(n)$ is negligible.
2. For any (positive) polynomial $p$, the function $\mathsf{negl}_4$ defined by $\mathsf{negl}_4(n) = p(n) \cdot \mathsf{negl}_1(n)$ is negligible.

We begin with item (1). We show that for every polynomial $q(\cdot)$ there exists an integer $N$ such that for every $n > N$ it holds that $\mathsf{negl}_3(n) < \frac{1}{q(n)}$.

Fix $q(\cdot)$. Since $\mathsf{negl}_1$ and $\mathsf{negl}_2$ are negligible, we know that there exist integers $N_1$ and $N_2$, respectively, such that for every $n > N_1$, $\mathsf{negl}_1(n) < \frac{1}{2q(n)}$, and for every $n > N_2$, $\mathsf{negl}_2(n) < \frac{1}{2q(n)}$ (note that ${2}q(n)$ is also a polynomial, so the above holds). Take $N = \max\{N_1, N_2\}$. It follows that for every $n > N$,

$$\mathsf{negl}_3(n) = \mathsf{negl}_1(n) + \mathsf{negl}_2(n) < \frac{1}{2q(n)} + \frac{1}{2q(n)} = \frac{1}{q(n)}.$$

We conclude that for every polynomial $q(\cdot)$ there exists an integer $N$ such that for every $n > N$, $\mathsf{negl}_3(n) < \frac{1}{q(n)}$.

We now prove item (2); the proof is very similar, so we are brief. Fix $q(\cdot)$; let $N$ be an integer such that for all $n > N$ it holds that $\mathsf{negl}_1(n) < \frac{1}{p(n) \cdot q(n)}$. This implies that for every $n > N$,

$$\mathsf{negl}_4(n) = p(n) \cdot \mathsf{negl}_1(n) < \frac{p(n)}{p(n) \cdot q(n)} = \frac{1}{q(n)},$$

as required.

## 3.2

> **题目**　Prove that Definition 3.8 cannot be satisfied if $\Pi$ can encrypt arbitrary-length messages and the adversary is *not* restricted to output equal-length messages in experiment $\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}$.

**Solution.** Let $p(\cdot)$ be the polynomial (in the security parameter $n$) that bounds the running time of $\mathsf{Enc}$ when encrypting a single bit. (Thus, $\mathsf{Enc}$ runs for at most $p(n)$ steps to encrypt a single bit when the security parameter is ${1}^n$.) In particular, the length of the ciphertext generated by $\mathsf{Enc}$ when encrypting a single bit is at most $p(n)$ because an algorithm cannot output a string that is longer than its running time. The ciphertext generated by encrypting a random string of length $p(n) + n$ has length greater than $p(n)$ with all but negligible probability. (Here we assume, as usual, that decryption is always correct.)

Given the above, we can take $\mathcal{A}$ to be an adversary that, on input ${1}^n$, outputs a pair of plaintexts $m_0$, $m_1$ in experiment $\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n)$, where $m_0$ is a single bit and $m_1$ is a uniform string of length $p(n) + n$. If $b = 0$ then $|c| \le p(n)$, while if $b = 1$ then $|c| > p(n)$ with all but negligible probability, where $c$ is the challenge ciphertext. Thus, $\mathcal{A}$ succeeds with all but negligible probability by outputting $b^{\prime} = 0$ if and only if $|c| \le p(n)$. The above holds for any encryption scheme and thus such a definition can never be satisfied.

## 3.3

> **题目**　Say $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ is such that for $k \in \{0,1\}^n$, algorithm $\mathsf{Enc}_k$ is only defined for messages of length at most $\ell(n)$ (for some polynomial $\ell$). Construct a scheme satisfying Definition 3.8 even when the adversary is not restricted to outputting equal-length messages in $\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}$.

**Solution.** To be clear, we are considering a modification of experiment $\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}$ where the adversary $\mathcal{A}$ is not required to output $m_0$ and $m_1$ of the same length, but instead it is only required that $m_0$ and $m_1$ each have length at most $\ell(n)$.

Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be a scheme that is secure with respect to the original Definition 3.8 (for messages of equal length). Construct a scheme $\Pi^{\prime} = (\mathsf{Gen}^{\prime}, \mathsf{Enc}^{\prime}, \mathsf{Dec}^{\prime})$ as follows:

(a) $\mathsf{Gen}^{\prime}$ is identical to $\mathsf{Gen}$.

(b) Upon input a plaintext message $m$ of length at most $\ell = \ell(n)$ (where $n$ is the length of the key), $\mathsf{Enc}^{\prime}$ first sets $m^{\prime} := 0^{\ell-|m|}1 \| m$ and then encrypts $m^{\prime}$ using $\mathsf{Enc}$. Note that $m^{\prime}$ is always exactly $\ell(n) + 1$ bits long.

(c) $\mathsf{Dec}^{\prime}$ applies $\mathsf{Dec}$ to the ciphertext, and parses the result as ${0}^t 1 \| m$ for $t \ge 0$. It outputs $m$.

It is clear that if $\Pi$ satisfies Definition 3.8 then $\Pi^{\prime}$ satisfies the modified definition. A complete answer to this exercise requires a proof showing that the existence of an adversary breaking $\Pi^{\prime}$ with respect to the modified definition implies the existence of an adversary breaking $\Pi$ with respect to Definition 3.8. We describe the reduction informally. Given an adversary $\mathcal{A}^{\prime}$ who breaks $\Pi^{\prime}$, we construct an adversary $\mathcal{A}$ who takes the pair of plaintexts $m_0, m_1$ output by $\mathcal{A}^{\prime}$ and pads them in the same way as $\mathsf{Enc}^{\prime}$ would. Then, it outputs the padded messages to be encrypted. Observe that $\mathcal{A}$ outputs equal-length messages, as required. Furthermore, if $\mathcal{A}^{\prime}$ can correctly guess $b$ with probability non-negligibly greater than ${1}/{2}$, then $\mathcal{A}$ guesses correctly with the same probability.

## 3.4

> **题目**　Prove the equivalence of Definition 3.8 and Definition 3.9.

**Solution.** Let $\Pi$ be an encryption scheme. We have:

$$\begin{aligned}
\Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n) = 1] &= \Pr_{b \leftarrow \{0,1\}}[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, b)) = b] \\
&= \frac{1}{2} \cdot \Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 0] \\
&\quad + \frac{1}{2} \cdot \Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1] \\
&= \frac{1}{2} \cdot \left(1 - \Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right) \\
&\quad + \frac{1}{2} \cdot \Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1] \\
&= \frac{1}{2} + \frac{1}{2} \cdot \left(\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right). \tag{3.1}
\end{aligned}$$

If $\Pi$ satisfies Definition 3.9, then there exists a negligible function $\mathsf{negl}$ for which

$$\begin{aligned}
\Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n) = 1] &= \frac{1}{2} + \frac{1}{2} \cdot \left(\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right) \\
&\le \frac{1}{2} + \frac{1}{2} \cdot \left|\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right| \\
&\le \frac{1}{2} + \mathsf{negl}(n);
\end{aligned}$$

thus, $\Pi$ satisfies Definition 3.8 also.

For the other direction, assume $\Pi$ satisfies Definition 3.8. By Equation (3.1) we see that there exists a negligible function $\mathsf{negl}$ such that

$$\begin{aligned}
\mathsf{negl}(n) &\ge \Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n) = 1] - \frac{1}{2} \\
&= \frac{1}{2} \cdot \left(\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right). \tag{3.2}
\end{aligned}$$

Let $\hat{\mathcal{A}}$ denote an adversary that runs identically to $\mathcal{A}$ except that it outputs the complement of whatever $\mathcal{A}$ outputs. Then

$$\begin{aligned}
\Pr[\mathsf{PrivK}_{\hat{\mathcal{A}},\Pi}^{\mathsf{eav}}(n) = 1] &= 1 - \Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n) = 1] \\
&= \frac{1}{2} + \frac{1}{2} \cdot \left(\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right)
\end{aligned}$$

and, arguing as above, there exists a negligible function $\mathsf{negl}^{\prime}$ such that

$$\begin{aligned}
\mathsf{negl}^{\prime}(n) &\ge \Pr[\mathsf{PrivK}_{\hat{\mathcal{A}},\Pi}^{\mathsf{eav}}(n) = 1] - \frac{1}{2} \\
&= \frac{1}{2} \cdot \left(\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 0)) = 1]\right. \\
&\qquad\qquad - \left.\Pr[\mathsf{output}(\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n, 1)) = 1]\right). \tag{3.3}
\end{aligned}$$

Combining Equations (3.2) and (3.3), we see that $\Pi$ satisfies Definition 3.9 as well.

## 3.6

> **题目**　Let $G$ be a pseudorandom generator. In each of the following cases, say whether $G^{\prime}$ is necessarily a pseudorandom generator. If yes, give a proof; if not, show a counterexample.
>
> (a) Define $G^{\prime}(s) \overset{\mathrm{def}}{=} G(\bar{s})$, where $\bar{s}$ is the complement of $s$.
>
> (b) Define $G^{\prime}(s) \overset{\mathrm{def}}{=} \overline{G(s)}$.
>
> (c) Define $G^{\prime}(s) \overset{\mathrm{def}}{=} G(0^{|s|} \| s)$.
>
> (d) Define $G^{\prime}(s) \overset{\mathrm{def}}{=} G(s) \| G(s+1)$.

**Solution.**

(a) $G^{\prime}$ is a pseudorandom generator. This follows from the fact that $\bar{s}$ is uniformly distributed when $s$ is. (Thus, the distributions $\{G(s)\}$ and $\{G^{\prime}(s)\} = \{G(\bar{s})\}$ are identical when $s$ is uniform.)

(b) $G^{\prime}$ is a pseudorandom generator. In contrast to the last problem, $\{G(s)\}$ and $\{\overline{G(s)}\}$ do not have the same distribution; nevertheless, they are both indistinguishable from uniform. We prove that $G^{\prime}$ is a pseudorandom generator by reduction. Let $|G(s)| = \ell(|s|)$. Given a distinguisher $D^{\prime}$, define a distinguisher $D$ as follows: on input $y$, output $D^{\prime}(\bar{y})$. Note that $D$ is efficient if $D^{\prime}$ is. Moreover,

$$\begin{aligned}
\Pr_{y \leftarrow \{0,1\}^{\ell(n)}}[D(y) = 1] &= \Pr_{y \leftarrow \{0,1\}^{\ell(n)}}[D^{\prime}(\bar{y}) = 1] \\
&= \Pr_{y \leftarrow \{0,1\}^{\ell(n)}}[D^{\prime}(y) = 1]
\end{aligned}$$

and

$$\begin{aligned}
\Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 1] &= \Pr_{s \leftarrow \{0,1\}^n}[D^{\prime}(\overline{G(s)}) = 1] \\
&= \Pr_{s \leftarrow \{0,1\}^n}[D^{\prime}(G^{\prime}(s)) = 1].
\end{aligned}$$

Since $G$ is a pseudorandom generator, it follows that $G^{\prime}$ is as well.

(c) $G^{\prime}$ is not necessarily a pseudorandom generator. To see this, let $H: \{0,1\}^n \rightarrow \{0,1\}^{4n}$ be a pseudorandom generator, and define $G(s) = H(s_1 \cdots s_{n/2})$. It is not hard to show that $G$ is a pseudorandom generator. But then

$$G^{\prime}(s) = G(0^{|s|} \| s) = H(0^{|s|}),$$

and clearly $G^{\prime}$ is not a pseudorandom generator.

Fundamentally, the problem here is that $G^{\prime}$ runs $G$ on an input seed that is not uniformly distributed.

(d) $G^{\prime}$ is not necessarily a pseudorandom generator. To see this, let $H: \{0,1\}^n \rightarrow \{0,1\}^{2n}$ be a pseudorandom generator and define $G(s) = H(s_1 \cdots s_{n-1})$. It is not hard to show that $G$ is a pseudorandom generator. But then if the last bit of $s$ is 0 we have

$$G^{\prime}(s) = G(s) \| G(s+1) = H(s_1 \cdots s_{n-1}) \| H(s_1 \cdots s_{n-1})$$

(because then $s$ and $s+1$ differ only in their final bit), and so with probability at least 1/2 the two halves of the output of $G^{\prime}$ are the same. Thus, $G^{\prime}$ is clearly not a pseudorandom generator.

Fundamentally, the problem here is that $G^{\prime}$ runs $G$ on two correlated (rather than independent) inputs.

## 3.7

> **题目**　Let $|G(s)| = \ell(|s|)$ for some $\ell$. Consider the following experiment:
>
> The PRG indistinguishability experiment $\mathsf{PRG}_{\mathcal{A},G}(n)$:
>
> (a) A uniform bit $b \in \{0,1\}$ is chosen. If $b = 0$ then choose a uniform $r \in \{0,1\}^{\ell(n)}$; if $b = 1$ then choose a uniform $s \in \{0,1\}^{n}$ and set $r := G(s)$.
>
> (b) The adversary $\mathcal{A}$ is given $r$, and outputs a bit $b^{\prime}$.
>
> (c) The output of the experiment is defined to be 1 if $b^{\prime} = b$, and 0 otherwise.
>
> Provide a definition of a pseudorandom generator based on this experiment, and prove that your definition is equivalent to Definition 3.14. (That is, show that $G$ satisfies your definition if and only if it satisfies Definition 3.14.)

**Solution.** The required definition is that $G$ is a pseudorandom generator if for any PPT algorithm $\mathcal{A}$ we have

$$\Pr[\mathsf{PRG}_{\mathcal{A},G}(n) = 1] \le \frac{1}{2} + \mathsf{negl}(n).$$

To see that these definitions are equivalent, note that

$$\begin{aligned}
\Pr[\mathsf{PRG}_{\mathcal{A},G}(n) = 1] &= \frac{1}{2} \cdot \Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[\mathcal{A}(r) = 0] + \frac{1}{2} \cdot \Pr_{s \leftarrow \{0,1\}^{n}}[\mathcal{A}(G(s)) = 1] \\
&= \frac{1}{2} + \frac{1}{2} \cdot \left(\Pr_{s \leftarrow \{0,1\}^{n}}[\mathcal{A}(G(s)) = 1] - \Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[\mathcal{A}(r) = 1]\right).
\end{aligned}$$

Thus, if there is an efficient $\mathcal{A}$ for which the new definition fails to hold, then Definition 3.14 fails to hold for this $\mathcal{A}$ as well. And if there is an efficient attacker $\mathcal{A}$ for which Definition 3.14 does not hold, we obtain an efficient attacker for which the new definition does not hold either (possibly by flipping the output of $\mathcal{A}$).

## 3.8

> **题目**　Prove the converse of Theorem 3.16. Namely, show that if $G$ is not a pseudorandom generator, then Construction 3.17 does not have indistinguishable encryptions in the presence of an eavesdropper.

**Solution.** Let $D$ be an efficient algorithm such that

$$\Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[D(r) = 1] - \Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 1]$$

is not negligible. Construct an attacker $\mathcal{A}$ that, on input ${1}^n$, outputs $(m_0$, $m_1)$ where $m_0 = 0^{\ell(n)}$ and $m_1$ is uniform. Upon receiving ciphertext $c$, attacker $\mathcal{A}$ runs $D(c)$ and outputs the result. Note that when $m_0$ is encrypted, the ciphertext is equal to $G(s)$ for a uniform $s$, whereas when $m_1$ is encrypted, the ciphertext is a uniform $\ell$-bit string (since $m_1$ is uniform). Thus,

$$\begin{aligned}
&\Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{eav}}(n) = 1] \\
&= \frac{1}{2} \cdot \left(\Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 0] + \Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[D(r) = 1]\right) \\
&= \frac{1}{2} + \frac{1}{2} \cdot \left(\Pr_{r \leftarrow \{0,1\}^{\ell(n)}}[D(r) = 1] - \Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 1]\right),
\end{aligned}$$

which (by assumption) is non-negligibly greater than 1/2.

## 3.9

> **题目**　Consider a notion of indistinguishable encryption for multiple distinct messages, i.e., where a scheme need not hide whether the same message is encrypted twice.
>
> (a) Modify Definition 3.18 to obtain a suitable definition of the above.
>
> (b) Show that Construction 3.17 does not satisfy your definition.
>
> (c) Give a construction of a deterministic (stateless) encryption scheme that satisfies your definition.

**Solution.**

(a) The definition is a straightforward modification of Definition 3.18, where experiment $\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{mult}}(n)$ is modified so that all the messages in $\vec{M}_0$ are distinct, and similarly for $\vec{M}_1$ (but a message may appear in both $\vec{M}_0$ and $\vec{M}_1$).

(b) It is easy to see that Construction 3.17 does not satisfy the definition since, for example, when two messages that are identical except for their last bit are encrypted, the result is two ciphertexts that are identical except for their last bit.

(c) Let $F$ be a block cipher. Then setting $\mathsf{Enc}_k(m) = F_k(m)$ satisfies the definition even though it is deterministic.

## 3.10

> **题目**　Prove *unconditionally* the existence of a pseudorandom function $F: \{0,1\}^{*} \times \{0,1\}^{*} \rightarrow \{0,1\}^{*}$ with $\ell_{key}(n) = n$ and $\ell_{in}(n) = O(\log n)$.

**Solution.** Define keyed function $F: \{0,1\}^n \times \{0,1\}^{\log n} \rightarrow \{0,1\}$ as follows: $F_k(i)$ outputs the $i$th bit of $k$, where the input $i$ is interpreted as an integer in the range $\{0, \ldots, n-1\}$ and the bits of $k$ are numbered starting at 0. Note that $F$ is implementing a lookup table using the bits of the key $k$, and so $F_k$ for uniform $k$ is exactly a random function mapping $\log n$-bit inputs to 1-bit outputs. That is, $F$ is a random function, which is stronger than being pseudorandom.

## 3.11

> **题目**　Let $F$ be a length-preserving pseudorandom function. For the following constructions of a keyed function $F^{\prime}: \{0,1\}^n \times \{0,1\}^{n-1} \to \{0,1\}^{2n}$, state whether $F^{\prime}$ is a pseudorandom function. If yes, prove it; if not, show an attack.
>
> (a) $F^{\prime}_k(x) \stackrel{\mathrm{def}}{=} F_k(0\|x) \| F_k(0\|x)$.
>
> (b) $F^{\prime}_k(x) \stackrel{\mathrm{def}}{=} F_k(0\|x) \| F_k(1\|x)$.
>
> (c) $F^{\prime}_k(x) \stackrel{\mathrm{def}}{=} F_k(0\|x) \| F_k(x\|0)$.
>
> (d) $F^{\prime}_k(x) \stackrel{\mathrm{def}}{=} F_k(0\|x) \| F_k(x\|1)$.

**Solution.**

(b) $F^{\prime}$ is a pseudorandom function. A formal proof is omitted, but relies on the observation that distinct queries to $F^{\prime}_k$ result in distinct queries to $F_k$.

(d) $F^{\prime}$ is not a pseudorandom function. Consider querying on the two inputs ${0}^{n-1}$ and ${0}^{n-2}1$. We have

$$F^{\prime}_k(0^{n-1}) = F_k(0^n) \| F_k(0^{n-1}1)$$

and

$$F^{\prime}_k(0^{n-2}1) = F_k(0^{n-1}1) \| F_k(0^{n-2}1^2);$$

note that the second half of $F^{\prime}_k(0^{n-1})$ is equal to the first half of $F^{\prime}_k(0^{n-2}1)$. Formally, define the following distinguisher $\mathcal{D}$ given ${1}^n$ and oracle access to a function $g$: query $y_0 = g(0^{n-1})$ and $y_1 = g(0^{n-2}1)$, and output 1 iff the second half of $y_0$ equals the first half of $y_1$. Then $\Pr_{k \leftarrow \{0,1\}^n}[\mathcal{D}^{F^{\prime}_k(\cdot)}(1^n) = 1] = 1$, whereas for a uniform function $f$, $y_0$ and $y_1$ are independent uniform ${2}n$-bit strings and so this event occurs with probability exactly ${2}^{-n}$. The distinguishing advantage is thus not negligible.

## 3.12

> **题目**　Assuming the existence of a pseudorandom function, prove that there exists an encryption scheme that has indistinguishable multiple encryptions in the presence of an eavesdropper (i.e., is secure with respect to Definition 3.18) but is not CPA-secure (i.e., is not secure with respect to Definition 3.21).

**Solution.** Let $F$ be a pseudorandom function, and define scheme $\Pi = (\mathsf{Gen}, \mathsf{Enc}$, $\mathsf{Dec})$ as follows:

(a) $\mathsf{Gen}$: On input ${1}^n$, choose $k, s \leftarrow \{0,1\}^n$.

(b) $\mathsf{Enc}$: On input a key $\langle k, s \rangle$ and a message $m \in \{0,1\}^n$, do:

- i. If $m = s$ output the ciphertext $\langle 0, k, s, s \rangle$.
- ii. If $m \ne s$ then choose random $r \leftarrow \{0,1\}^n$ and output the ciphertext $\langle 1, s, r, F_k(r) \oplus m \rangle$.

(c) $\mathsf{Dec}$: On input a key $\langle k, s \rangle$ and ciphertext $c = \langle b, c_1, c_2, c_3 \rangle$ do:

- i. If $b = 0$ output $s$.
- ii. If $b = 1$ output $m := F_k(c_2) \oplus c_3$.

One can check that decryption always succeeds.

It is clear that $\Pi$ is not secure under a chosen-plaintext attack. This is because an adversary $\mathcal{A}$ can query its encryption oracle with input ${0}^n$ and receive (except with negligible probability) the ciphertext $c = \langle 1, s, r, F_k(r) \rangle$, where $s$ is the second component of the secret key. Then, $\mathcal{A}$ can query its encryption oracle again with $s$ and receive back a ciphertext containing $k$. Given $k$, of course, $\mathcal{A}$ can distinguish encryptions easily. Despite the above, we argue that $\Pi$ is still secure with respect to Definition 3.18. Intuitively, this is due to the fact that unless one of the plaintexts output by the adversary is equal to $s$ – which occurs with only negligible probability since $s$ is uniform – the scheme is essentially equivalent to Construction 3.30. We omit the formal proof, which is tedious but straightforward.

## 3.14

> **题目**　Define the keyed function $F$ as $F_k(x) \overset{\mathrm{def}}{=} k \;\&\; x$, where “ & ” denotes bitwise AND. Describe and analyze an attack showing that $F$ is not a pseudorandom function.

**Solution.** Consider the following attacker $\mathcal{A}$ given access to a function $g$:

$\mathcal{A}^g(1^n)$:

- Query $y = g(0^n)$.
- Output 1 iff $y$ is equal to ${0}^n$.

Clearly $\Pr_{k \leftarrow \{0,1\}^n}[\mathcal{A}^{F_k(\cdot)}(1^n) = 1] = 1$. But when $g$ is a random function then $y$ is a uniform string so $\Pr_{f \leftarrow \mathsf{Func}}[\mathcal{A}^{f(\cdot)}(1^n) = 1] = 2^{-n}$. Thus, $\left|\Pr_{k \leftarrow \{0,1\}^n}[\mathcal{A}^{F_k(\cdot)}(1^n) = 1] - \Pr_{f \leftarrow \mathsf{Func}}[\mathcal{A}^{f(\cdot)}(1^n) = 1]\right|$ is not negligible.

## 3.15

> **题目**　Consider the following keyed function $F$: For security parameter $n$, the key is an $n \times n$ boolean matrix $A$ and an $n$-bit boolean vector $b$. Define $F_{A,b} : \{0,1\}^{n} \to \{0,1\}^{n}$ by $F_{A,b}(x) \overset{\mathrm{def}}{=} Ax + b$, where all operations are done modulo 2. Show that $F$ is not a pseudorandom function.

**Solution.** Querying $F_{A,b}(0^n)$ yields $b$. Let $e_i$ denote the $n$-bit string with a 1 in position $i$ (and 0s elsewhere). Querying $F_{A,b}(e_i)$ yields $a_i + b$, where $a_i$ is the $i$th column of $A$. This can be easily extended to a full-fledged attack.

## 3.16

> **题目**　Prove that if $F$ is a length preserving pseudorandom function, then $G(s) \overset{\mathrm{def}}{=} F_s(\langle 1 \rangle) \| F_s(\langle 2 \rangle) \| \cdots \| F_s(\langle \ell \rangle)$, where $\langle i \rangle$ is the $n$-bit encoding of $i$, is a pseudorandom generator with expansion factor $\ell \cdot n$.

**Solution.** Fix an efficient distinguisher $D$, and let

$$\varepsilon(n) \overset{\mathrm{def}}{=} \left|\Pr_{r \leftarrow \{0,1\}^{\ell n}}[D(r) = 1] - \Pr_{s \leftarrow \{0,1\}^n}[D(G(s)) = 1]\right|.$$

Construct $\mathcal{A}(1^n)$ as follows: given access to a function $g$, let $y_i = g(i)$ for $i = 1, \ldots, \ell$. Output $D(y_1 \| \cdots \| y_\ell)$. Clearly

$$\left|\Pr[\mathcal{A}^{f(\cdot)}(1^n) = 1] - \Pr[\mathcal{A}^{F_k(\cdot)}(1^n) = 1]\right| = \varepsilon(n),$$

and so $\varepsilon(n)$ must be negligible.

## 3.17

> **题目**　Assume pseudorandom permutations exist. Show that there exists a keyed function $F$ that is a pseudorandom permutation but is not a strong pseudorandom permutation.
>
> Hint: Construct $F$ such that $F_k(k) = 0^{|k|}$.

**Solution.** Let $F$ be a length-preserving pseudorandom permutation. Define $F^{\prime}$ as follows:

$$F^{\prime}_k(x) = \begin{cases} 0^n & x = k \\ F_k(k) & x = F_k^{-1}(0^n) \\ F_k(x) & \text{otherwise.} \end{cases}$$

$F^{\prime}_k$ is a permutation for all $k$, and can be efficiently inverted. We do not prove that $F^{\prime}$ is still a pseudorandom permutation, but intuitively this holds since the only difference between $F^{\prime}_k$ and $F_k$ (when an adversary can query in the "forward" direction only) occurs if the adversary queries $F^{\prime}_k$ either on the key $k$ or on the point $F_k^{-1}(0^n)$. But the fact that $F$ is pseudorandom means that it is infeasible for an adversary to find either of those two inputs when interacting with $F^{\prime}_k(\cdot)$.

On the other hand, $F^{\prime}$ is not strongly pseudorandom: since $F^{\prime}^{-1}_k(0^n) = k$, an adversary can learn the key by querying ${0}^n$ in the reverse direction. Formally, consider the attacker $\mathcal{A}$ given access to an oracle $g$ and its inverse $g^{-1}$ that acts as follows: query $g^{-1}(0^n)$ and obtain a value $k$. Then choose any $x \notin \{k, F_k(k)\}$ and query $g(x)$ to obtain $y$. Output 1 iff $y = F_k(x)$. It is immediate that

$$\Pr[\mathcal{A}^{F^{\prime}_k(\cdot), F_k^{\prime -1}(\cdot)}(1^n) = 1] = 1.$$

On the other hand, it is easy to see that

$$\Pr[\mathcal{A}^{f(\cdot), f^{-1}(\cdot)}(1^n) = 1] = 2^{-n}.$$

Thus, $F^{\prime}$ is not strongly pseudorandom.

## 3.18

> **题目**　Define a notion of perfect secrecy under a chosen-plaintext attack by adapting Definition 3.22. Show that the definition cannot be achieved.

**Solution.** Here we would simply require that for all $\mathcal{A}$ (i.e., even unbounded), it holds that $\Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{cpa}}(n) = 1] = 1/2$. This definition cannot be achieved. To see this, fix an arbitrary scheme $\Pi$ and let $\mathcal{A}$ be the following attacker: request an encryption of ${0}^n$, obtaining in return ciphertext $c_0$. Then output the messages $(m_0 = 0^n$, $m_1 = 1^n)$, and receive in return a ciphertext $c$. If $c = c_0$ output 0; otherwise, output 1. Note that when $m_0$ is encrypted, there is a nonzero probability that $c = c_0$, whereas when $m_1$ is encrypted we must have $c \ne c_0$. Thus,

$$\begin{aligned}
\Pr[\mathsf{PrivK}_{\mathcal{A},\Pi}^{\mathsf{cpa}}(n) = 1] &= \frac{1}{2} \cdot \left(\Pr[\mathsf{Enc}_k(m_0) = c_0] + \Pr[\mathsf{Enc}_k(m_1) \ne c_0]\right) \\
&> 1/2.
\end{aligned}$$

## 3.19

> **题目**　Let $F$ be a pseudorandom permutation, and define a fixed-length encryption scheme $(\mathsf{Enc}, \mathsf{Dec})$ as follows: On input a key $k \in \{0,1\}^n$ and message $m \in \{0,1\}^{n/2}$, algorithm $\mathsf{Enc}$ chooses a uniform string $r \in \{0,1\}^{n/2}$ and computes $c := F_k(r\|m)$.
>
> Show how to decrypt, and prove that this scheme is CPA-secure for messages of length $n/2$.

**Solution.** Decryption is computed by first computing $F_k^{-1}(c)$ and then outputting the $n/2$ least significant bits of the result. We now show that this scheme is CPA-secure. In order to show this, we first consider an encryption scheme $\tilde{\Pi}$ that is identical to the above encryption scheme, except that a truly random permutation is used instead of a pseudorandom one. Let $\mathcal{A}$ be an adversary and let $q(\cdot)$ be a polynomial upper-bounding the running-time of $\mathcal{A}$. We claim that:

$$\Pr[\mathsf{PrivK}_{\mathcal{A},\tilde{\Pi}}^{\mathsf{cpa}}(n) = 1] \le \frac{1}{2} + \frac{q(n)}{2^{n/2}}.$$

Let $r_c$ denote the random string used to generate the challenge ciphertext $c = F_k(r\|m)$. There are two cases:

(a) The value $r_c$ is used by the encryption oracle to answer at least one of $\mathcal{A}$'s queries: In this case, $\mathcal{A}$ can know which message was encrypted, but the probability of this event occurring is upper-bounded by $q(n)/2^{n/2}$ (this is obtained by applying the union bound).

(b) The value $r_c$ is not used by the encryption oracle to answer any of $\mathcal{A}$'s queries: In this case, $\mathcal{A}$ learns nothing about the plaintext because the challenge ciphertext is a uniform string (subject to being distinct from all other ciphertexts).

Using a similar argument as in the proof of Theorem 3.29 the above equation follows. The rest of the proof follows as in the proof of Theorem 3.29 by showing that the difference when using a pseudorandom permutation instead is at most negligible.

## 3.28

> **题目**　For any function $g: \{0,1\}^n \rightarrow \{0,1\}^n$, define $g^{\$}(\cdot)$ to be a *probabilistic* oracle that, on input ${1}^n$, chooses uniform $r \in \{0,1\}^n$ and returns $\langle r, g(r) \rangle$. A keyed function $F$ is a *weak pseudorandom function* if for all ppt algorithms $D$, there exists a negligible function $\mathsf{negl}$ such that:
>
> $$\left|\Pr[D^{F_k^{\$}(\cdot)}(1^n) = 1] - \Pr[D^{f^{\$}(\cdot)}(1^n) = 1]\right| \le \mathsf{negl}(n),$$
>
> where $k \in \{0,1\}^n$ and $f \in \mathsf{Func}_n$ are chosen uniformly.
>
> (a) Prove that if $F$ is pseudorandom then it is weakly pseudorandom.
>
> (b) Let $F^{\prime}$ be a pseudorandom function, and define
>
> $$F_k(x) \overset{\mathrm{def}}{=} \begin{cases} F_k^{\prime}(x) & \text{if } x \text{ is even} \\ F_k^{\prime}(x+1) & \text{if } x \text{ is odd.} \end{cases}$$
>
> Prove that $F$ is weakly pseudorandom, but *not* pseudorandom.
>
> (c) Is CTR-mode encryption using a weak pseudorandom function necessarily CPA-secure? Does it necessarily have indistinguishable encryptions in the presence of an eavesdropper? Prove your answers.
>
> (d) Prove that Construction 3.28 is CPA-secure if $F$ is a weak pseudorandom function.

**Solution.**

(a) Intuitively, if $F$ cannot be distinguished from a random function even when a distinguisher is allowed to *choose* the evaluation points, then $F$ cannot be distinguished from a random function when $F$ is evaluated on random points. A formal reduction is straightforward.

(b) It is clear that $F^{\prime}$ is not pseudorandom.【原文如此】 Specifically, a distinguisher $D$ can query its oracle with an odd $x$ and then with $x+1$. If its oracle is $F^{\prime}$ then $D$ will receive back the same value twice. Otherwise, if its oracle is random, it will receive back different values (except with probability ${2}^{-n}$).

On the other hand, $F^{\prime}$ is weakly pseudorandom. Intuitively, this is because the *only* way to distinguish $F^{\prime}$ from a random function is to query it on two consecutive points (as above), but if $F^{\prime}$ is evaluated on random inputs, then the probability that any two such points happen to be consecutive is negligible. (We omit the formal proof.)

(c) Counter mode instantiated with a weak pseudorandom function does not necessarily have indistinguishable encryptions in the presence of an eavesdropper. To see this, take $F^{\prime}$ from part (b). When encrypting a message that is at least three blocks long, there will be two consecutive plaintext blocks that are XORed with the same value $F_k^{\prime}(\mathsf{ctr}) = F_k^{\prime}(\mathsf{ctr} + 1)$.

(d) In Construction 3.28, a uniform $r$ is always used as input to $F$. Thus, the proof that this construction is CPA-secure when $F$ is weakly pseudorandom is very similar to the proof given in the text.

## 3.29

> **题目**　What is the effect of a single bit flip in the ciphertext when using the CBC, OFB, and CTR modes of operation?

**Solution.** Say a message $m_1, m_2, \ldots$ is encrypted to give a ciphertext $c_0, c_1, c_2, \ldots$, and then a single bit is flipped somewhere in the ciphertext. We look at the effect of decrypting the resulting (modified) ciphertext using each of the stated modes to obtain a message $m^{\prime}_1, m^{\prime}_2, \ldots$.

**CBC mode.** Say a bit is flipped in $c_i$ to give modified block $c^{\prime}_i$. When decrypting, $m^{\prime}_i$ is computed as $m^{\prime}_i = F_k^{-1}(c^{\prime}_i) \oplus c_{i-1}$ and $F_k^{-1}(c^{\prime}_i)$ will, in general, be completely unrelated to $F_k^{-1}(c_i)$. Thus, $m^{\prime}_i$ will have no relation to $m_i$. The next message block, $m^{\prime}_{i+1}$, is computed as $m^{\prime}_{i+1} = F_k^{-1}(c_{i+1}) \oplus c^{\prime}_i$ and so $m^{\prime}_{i+1}$ will be equal to $m_{i+1}$ but with a single bit flipped. The rest of the message blocks will be unchanged.

**OFB mode and CTR mode.** In these modes, a bit flip in $c_i$ for $i > 0$ only causes a bit flip in message block $m_i$. However, a bit flip in $c_0$ will (in general) result in all the plaintext blocks being recovered incorrectly.

## 3.30

> **题目**　What is the effect of a dropped ciphertext block (e.g., if the transmitted ciphertext $c_1, c_2, c_3, \ldots$ is received as $c_1, c_3, \ldots$) when using the CBC, OFB, and CTR modes of operation?

**Solution.** Say a message $m_1, m_2, \ldots$ is encrypted to give a ciphertext $c_0, c_1, c_2, \ldots$, and then a single block is dropped. We look at the effect of decrypting the resulting (modified) ciphertext using each of the stated modes to obtain a message $m_1^{\prime}$, $m_2^{\prime}, \ldots$.

**CBC mode.** Say block $c_i$ is dropped. The result of decrypting the modified ciphertext is $m_1, \ldots, m_{i-1}, m_{i+1}^{\prime}, m_{i+2}, \ldots$. That is, message blocks before position $i$ are recovered correctly, message block $i$ is lost entirely, message block $i+1$ is garbled, and message blocks after position $i+1$ are recovered correctly (though shifted over by one block).

**OFB and CTR mode.** If $c_i$ is dropped then all plaintext blocks before position $i$ are recovered correctly, but from position $i$ and on the remaining plaintext blocks will be incorrect.
