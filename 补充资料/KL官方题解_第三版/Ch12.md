## 12.1

> **题目**　Assume a public-key encryption scheme for single-bit messages with no decryption error. Show that, given $pk$ and a ciphertext $c$ computed via $c \leftarrow \mathsf{Enc}_{pk}(m)$, it is possible for an unbounded adversary to determine $m$ with probability 1.

**Solution.** This is just a trivial brute-force search. Let $\ell = \ell(n)$ denote the length of the random coins used by $\mathsf{Enc}$. Given $pk$ and $c$, compute $c_r := \mathsf{Enc}_{pk}(0; r)$ for all $r \in \{0,1\}^\ell$. If $c = c_r$ for some $r$, output "$m = 0$"; otherwise output "$m = 1$". This adversary is clearly inefficient, but that is acceptable since here the adversary may be unbounded.

If $c$ is an encryption of 0 then $c = \mathsf{Enc}_{pk}(0; r)$ for some $r$, so the adversary always (correctly) outputs "$m = 0$". If $c$ is an encryption of 1 then $c \ne c_r$ for all $r$ (by correctness), so the adversary always (correctly) outputs "$m = 1$".

## 12.2

> **题目**　Show that for any CPA-secure public-key encryption scheme for single-bit messages, the length of the ciphertext must be superlogarithmic in the security parameter.

**Solution.** We aim for simplicity rather than trying to optimize parameters. Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}$, $\mathsf{Dec})$ be an encryption scheme. For a given public key *pk* generated using $\mathsf{Gen}$ and a bit *b*, let $\mathcal{C}_{pk}(b)$ denote the set of ciphertexts corresponding to possible encryptions of *b* with respect to *pk*. Say that for some fixed bit *b* and every public key the length of the ciphertext after encrypting *b* is at most $c\log n$ for some constant *c*. Then for any public key *pk*, the set $\mathcal{C}_{pk}(b)$ has size $p(n) \le n^c$ for some polynomial *p*. We exploit this in the following attack:

**Adversary $\mathcal{A}$:**

(a) $\mathcal{A}$ is given *pk* and computes $c_b \leftarrow \mathsf{Enc}_{pk}(b)$.

(b) $\mathcal{A}$ outputs the two messages $(0, 1)$ and is given in return a ciphertext *c*.

(c) If $c = c_b$, then $\mathcal{A}$ outputs b; else $\mathcal{A}$ outputs a uniform bit.

Let $c_b^* \in \mathcal{C}_{pk}(b)$ be the ciphertext that occurs most frequently when encrypting *b*, and note that $\Pr[\mathsf{Enc}_{pk}(b) = c_b^*] \ge 1/|\mathcal{C}_{pk}(b)| = 1/p(n)$. We now analyze the behavior of $\mathcal{A}$.

$$\begin{aligned}
\Pr[\mathcal{A} \text{ outputs } b \mid c \text{ is an encryption of } b] &= \Pr[c = c_b] + \frac{1}{2} \cdot \Pr[c \ne c_b] \\
&= \frac{1}{2} + \frac{1}{2} \cdot \Pr[c = c_b] \\
&\ge \frac{1}{2} + \frac{1}{2} \cdot \Pr[c = c_b^* \wedge c_b = c_b^*] \\
&\ge \frac{1}{2} + \frac{1}{2p^2(n)}.
\end{aligned}$$

(In fact, one can show that $\Pr[c = c_b] \ge 1/|\mathcal{C}_{pk}(b)| = 1/p(n)$ but this is not needed for the proof.) We also have

$$\Pr\left[\mathcal{A} \text{ outputs } \bar{b} \,\middle|\, c \text{ is an encryption of } \bar{b}\right] = \Pr[c = c_{\bar{b}}] + \frac{1}{2} \cdot \Pr[c \ne c_{\bar{b}}] = \frac{1}{2}$$

assuming perfect correctness. From the above, we have

$$\begin{aligned}
\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] &= \frac{1}{2} \cdot \Pr[\mathcal{A} \text{ outputs } b \mid c \text{ is an encryption of } b] \\
&\quad + \frac{1}{2} \cdot \Pr[\mathcal{A} \text{ outputs } \bar{b} \mid c \text{ is an encryption of } \bar{b}] \\
&\ge \frac{1}{2} \cdot \left(\frac{1}{2} + \frac{1}{2p^2(n)}\right) + \frac{1}{2} \cdot \frac{1}{2} = \frac{1}{2} + \frac{1}{4p^2(n)}.
\end{aligned}$$

Since ${1}/4p^2(n)$ is not negligible, Π is not CPA-secure.

## 12.3

> **题目**　Say a public-key encryption scheme $(\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ is one-way if any PPT adversary $\mathcal{A}$ has negligible probability of success in the following experiment: $\mathsf{Gen}(1^n)$ is run to obtain keys $(pk, sk)$; a uniform message $m$ in the message space is chosen and $c \leftarrow \mathsf{Enc}_{pk}(m)$ is computed; $\mathcal{A}$ is given $pk$ and $c$, and outputs $m^{\prime}$. $\mathcal{A}$ succeeds if $m^{\prime} = m$.
>
> (a) Construct a CPA-secure KEM in the random-oracle model based on a one-way public-key encryption scheme with message space $\{0,1\}^n$.
>
> (b) Can a deterministic public-key encryption scheme be one-way? If not, prove impossibility; if so, give a construction based on any of the assumptions introduced in this book.

**Solution.**

(a) See Construction 12.1-S.

**Construction 12.1-S.** Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be a public-key encryption scheme, and let $\ell(n)$ be an arbitrary polynomial. Let $H$ be a function whose domain is $\{0,1\}^*$ and whose range can be set to $\{0,1\}^{\ell(n)}$ for any $n$. Construct a public-key encryption scheme $\Pi^{\prime}$ as follows:

- $\mathsf{Gen}^{\prime}$: on input ${1}^n$, run $\mathsf{Gen}(1^n)$ to obtain $(pk, sk)$. The public key is $pk$ and the private key is $sk$.
- $\mathsf{Enc}^{\prime}$: on input a public key $pk$ and a message $m \in \{0,1\}^{\ell(n)}$, choose a uniform $r \leftarrow \{0,1\}^n$ and output the ciphertext $\langle \mathsf{Enc}_{pk}(r), H(r) \oplus m \rangle$.
- $\mathsf{Dec}^{\prime}$: on input a private key $sk$ and a ciphertext $\langle c_1, c_2 \rangle$, compute $r := \mathsf{Dec}_{sk}(c_1)$ and output $H(r) \oplus c_2$.

A proof of security is similar in spirit to the proof of Theorem 12.38, though simpler because only CPA-security is being shown.

(b) A public-key encryption scheme where encryption is deterministic can be one-way. Textbook RSA encryption (Construction 12.26) serves as one example: this scheme is one-way as long as the RSA problem is hard relative to $\mathsf{GenRSA}$.

## 12.4

> **题目**　Show that any two-round key-exchange protocol (i.e., where each party sends a single message) satisfying Definition 11.1 can be converted into a CPA-secure public-key encryption scheme.

**Solution.** Let Π be a two-round key-exchange protocol where Alice goes first. A public-key encryption scheme can be constructed as in Construction 12.1-S. Correctness follows from the fact that $\mathsf{msg}_1$, $\mathsf{msg}_2$ jointly form an execution of Π, and so the sender and receiver generate the same key *k*. Thus, the receiver obtains the sender's intended message *m*.

**Construction 12.1-S.**

Let Π be as in the text. Define a public-key encryption scheme as follows:

- $\mathsf{Gen}$: on input ${1}^n$ run Alice's side of Π to obtain $\mathsf{msg}_1$ along with some state information *s*. The public key is $\mathsf{msg}_1$ and the private key is *s*.
- $\mathsf{Enc}$: on input public key $pk = \mathsf{msg}_1$ and message $m \in \{0,1\}^n$, the sender runs Bob's side of Π to obtain $\mathsf{msg}_2$ and a key $k \in \{0,1\}^n$. Output the ciphertext $\langle \mathsf{msg}_2, \ k \oplus m \rangle$.
- $\mathsf{Dec}$: on input a private key $sk = s$ and a ciphertext $\langle \mathsf{msg}_2, c \rangle$, run Alice's side of Π (using state *s* and incoming message $\mathsf{msg}_2$) to obtain a key *k*. Then output the message $m := c \oplus k$.

Public-key encryption from key exchange.

Let $\Pi_{\mathsf{enc}}$ denote Construction 12.1-S. We prove that $\Pi_{\mathsf{enc}}$ has indistinguishable encryptions in the presence of an eavesdropper.

Let $\mathcal{A}$ be a probabilistic, polynomial-time adversary, and define

$$\varepsilon(n) \stackrel{\mathrm{def}}{=} \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi_{\mathsf{enc}}}(n) = 1].$$

Consider the modified "encryption scheme" $\widetilde{\Pi}$ where $\mathsf{Gen}$ is the same as in $\Pi_{\mathsf{enc}}$, but encryption of a message *m* with respect to the public key $\mathsf{msg}_1$ is done by running Bob's side of Π to obtain $\mathsf{msg}_2$ and then choosing a uniform $\hat{k} \in \{0,1\}^n$ and outputting the ciphertext $\langle \mathsf{msg}_2, \ \hat{k} \oplus m \rangle$. Although $\widetilde{\Pi}$ is not actually an encryption scheme (as there is no way for the receiver to decrypt), the experiment $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\widetilde{\Pi}}(n)$ is still well-defined since that experiment depends only on the key-generation and encryption algorithms.

As in the case of the one-time pad, the second component of the ciphertext in scheme $\widetilde{\Pi}$ is a uniform string and, in particular, is independent of the message *m* being encrypted. The first component of the ciphertext is also independent of *m*. It follows that

$$\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\widetilde{\Pi}}(n) = 1] = \frac{1}{2}.$$

Now consider the following PPT algorithm *D* attacking Π:

**Algorithm $D$:**

The algorithm is given $\mathsf{trans} = (\mathsf{msg}_1$, $\mathsf{msg}_2), k$ as input.

- Set $pk = \mathsf{msg}_1$ and run $\mathcal{A}(pk)$ to obtain two messages $m_0$, $m_1$.
- Choose a uniform bit *b*, and give $\langle \mathsf{msg}_2, \ k \oplus m_b \rangle$ to $\mathcal{A}$.
- When $\mathcal{A}$ outputs $b^{\prime}$, output 1 if $b^{\prime} = b$ and 0 otherwise.

Let us analyze the behavior of *D*. There are two cases to consider:

**Case 1:** Say the input to *D* is generated by running Π to obtain a transcript $\mathsf{trans}$ and a key *k*. In this case the view of $\mathcal{A}$ when run as a subroutine by *D* is distributed identically to $\mathcal{A}$'s view in experiment $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi_{\mathsf{enc}}}(n)$, and so *D* outputs 1 in this case with probability $\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi_{\mathsf{enc}}}(n) = 1]$.

**Case 2:** Say the input to *D* is generated by running Π to obtain a transcript $\mathsf{trans}$ and a key *k*, but then choosing uniform $\hat{k} \in \{0,1\}^n$ and giving *D* the pair $(\mathsf{trans}, \hat{k})$. In this case the view of $\mathcal{A}$ when run as a subroutine by *D* is distributed identically to $\mathcal{A}$'s view in experiment $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\widetilde{\Pi}}(n)$. Since *D* outputs 1 exactly when the output $b^{\prime}$ of $\mathcal{A}$ is equal to *b*, the probability that *D* outputs 1 in this case is exactly $\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\widetilde{\Pi}}(n) = 1] = \frac{1}{2}$.

We then have

$$\begin{aligned}
\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] &= \frac{1}{2} \cdot \Pr[D \text{ outputs } 1 \mid k \text{ is output by } \Pi] \\
&\quad + \frac{1}{2} \cdot \Pr[D \text{ outputs } 0 \mid \hat{k} \text{ is uniform}] \\
&= \frac{1}{2} \cdot \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi_{\mathsf{enc}}}(n) = 1] + \frac{1}{2} \cdot \frac{1}{2}.
\end{aligned}$$

Since Π is a secure key-exchange protocol, there exists a negligible function $\mathsf{negl}$ such that $\Pr[\mathsf{KE}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] \le \frac{1}{2} + \mathsf{negl}(n)$. Hence we must have $\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi_{\mathsf{enc}}}(n) = 1] \le \frac{1}{2} + 2\mathsf{negl}(n)$. Since $\mathcal{A}$ was arbitrary, this proves that $\Pi_{\mathsf{enc}}$ has indistinguishable encryptions in the presence of an eavesdropper.

## 12.5

> **题目**　Show that Claim 12.7 does not hold in the setting of CCA-security.

**Solution.** Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$ be a CCA-secure encryption scheme for 1-bit messages, and let $\Pi^{\prime} = (\mathsf{Gen}, \mathsf{Enc}^{\prime}, \mathsf{Dec}^{\prime})$ denote the encryption scheme for arbitrary-length messages where

$$\mathsf{Enc}^{\prime}_{pk}(m_1 \cdots m_t) = \mathsf{Enc}_{pk}(m_1), \ldots, \mathsf{Enc}_{pk}(m_t).$$

We show that $\Pi^{\prime}$ is not CCA-secure. Consider the following adversary:

**Adversary $\mathcal{A}$:**

(a) Given $pk$, output messages $m_0 = 00$ and $m_1 = 11$.

(b) Receive in return a ciphertext $c = c_1, c_2$.

(c) Compute $c_2^{\prime} \leftarrow \mathsf{Enc}_{pk}(0)$. Submit the ciphertext $c^{\prime} = c_1, c_2^{\prime}$ to the decryption oracle, and receive in return a bit $b^{\prime}$.

(d) Output $b^{\prime}$.

This is a legal attack: $m_0$ and $m_1$ have the same length, and the ciphertext $c^{\prime}$ submitted to the decryption oracle satisfies $c^{\prime} \ne c$. The attacker succeeds in guessing the bit $b$ with probability 1; thus $\Pi^{\prime}$ is not CCA-secure.

## 12.6

> **题目**　Consider the following public-key encryption scheme. The public key is $(\mathbb{G}, q, g, h)$ and the private key is *x*, generated exactly as in the El Gamal encryption scheme. In order to encrypt a bit *b*, the sender does the following:
>
> (a) If $b = 0$, then choose a uniform $y \in \mathbb{Z}_q$ and compute $c_1 := g^y$ and $c_2 := h^y$. The ciphertext is $\langle c_1, c_2 \rangle$.
>
> (b) If $b = 1$, then choose independent uniform $y, z \in \mathbb{Z}_q$, compute $c_1 := g^y$ and $c_2 := g^z$, and set the ciphertext equal to $\langle c_1, c_2 \rangle$.
>
> Show that it is possible to decrypt efficiently given knowledge of *x*. Prove that this encryption scheme is CPA-secure if the decisional Diffie-Hellman problem is hard relative to $\mathcal{G}$.

**Solution.** Decryption is easy. Given a ciphertext $\langle c_1, c_2 \rangle$ and secret key *x*, output 0 iff $c_1^x = c_2$. When the ciphertext is an encryption of 0 then decryption is always correct since

$$c_1^x = (g^y)^x = (g^x)^y = h^y = c_2.$$

When the ciphertext is an encryption of 1, then $c_1^x = g^{yx}$. Unless it happens that $z = xy$, decryption will correctly output 1. But $z = xy$ only with probability ${1}/q$, which is negligible.

Let Π denote the encryption scheme of the exercise. Security of Π follows fairly immediately from the observation that when $\langle c_1, c_2 \rangle$ is an encryption of 0 then $c_2 = \mathsf{DH}_g(h, c_1)$, whereas if $\langle c_1, c_2 \rangle$ is an encryption of 1 then $c_1$ and $c_2$ are independent, uniform elements of $\mathbb{G}$. Formally, given an adversary $\mathcal{A}$ attacking the encryption scheme we can construct an algorithm $\mathcal{A}^{\prime}$ solving the DDH problem as follows:

**Algorithm $\mathcal{A}^{\prime}$:**

The algorithm is given $\mathbb{G}, q, g, h, c_1, c_2$ as input.

(a) Run $\mathcal{A}$ on the public key $pk = \langle \mathbb{G}, q, g, h \rangle$. Assume for simplicity that $\mathcal{A}$ outputs $(m_0 = 0$, $m_1 = 1)$.

(b) Give to $\mathcal{A}$ the ciphertext $\langle c_1, c_2 \rangle$. Output whatever bit $b^{\prime}$ is output by $\mathcal{A}$.

Consider the case when the input to $\mathcal{A}^{\prime}$ is generated by running $\mathcal{G}(1^n)$ to obtain $(\mathbb{G}, q, g)$, then choosing uniform $x, y, z \in \mathbb{Z}_q$, and finally setting $h := g^x$, $c_1 := g^y$, and $c_2 := g^z$. Then, from the point of view of $\mathcal{A}$ (run as a sub-routine by $\mathcal{A}^{\prime}$), the experiment is equivalent to $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n)$ conditioned on $b = 1$ (i.e., conditioned on the ciphertext $\langle c_1, c_2 \rangle$ being an encryption of 1). Furthermore, $\mathcal{A}^{\prime}$ outputs 1 in this case exactly when $\mathcal{A}$ outputs 1, i.e., when $\mathcal{A}$ succeeds. Thus:

$$\Pr[\mathcal{A}^{\prime}(\mathbb{G}, q, g, g^x, g^y, g^z) = 1] = \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1 \mid b = 1].$$

When the input to $\mathcal{A}^{\prime}$ is generated by running $\mathcal{G}(1^n)$ to obtain $(\mathbb{G}, q, g)$, then choosing uniform $x, y \in \mathbb{Z}_q$, and finally setting $h := g^x$, $c_1 := g^y$, and $c_2 := g^{xy}$ then, from the point of view of $\mathcal{A}$, the experiment is equivalent to $\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n)$ conditioned on $b = 0$. Again, $\mathcal{A}^{\prime}$ outputs 1 when $\mathcal{A}$ does; now, however, this means that $\mathcal{A}$ did *not* succeed. So,

$$\Pr[\mathcal{A}^{\prime}(\mathbb{G}, q, g, g^x, g^y, g^{xy}) = 1] = 1 - \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1 \mid b = 0].$$

Putting this together and assuming the DDH problem is hard relative to $\mathcal{G}$, there exists a negligible function $\mathsf{negl}$ such that

$$\begin{aligned}
\mathsf{negl}(n) &\ge \left|\Pr[\mathcal{A}^{\prime}(\mathbb{G}, q, g, g^x, g^y, g^z) = 1] - \Pr[\mathcal{A}^{\prime}(\mathbb{G}, q, g, g^x, g^y, g^{xy}) = 1]\right| \\
&= \left|\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1 \mid b = 1] + \Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1 \mid b = 0] - 1\right| \\
&= 2 \cdot \left|\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] - \frac{1}{2}\right|.
\end{aligned}$$

Since $\mathcal{A}$ was arbitrary, it follows that Π is CPA-secure.

## 12.7

> **题目**　Consider the following variant of El Gamal encryption. Let $p = 2q + 1$, let $\mathbb{G}$ be the group of squares modulo $p$ (so $\mathbb{G}$ is a subgroup of $\mathbb{Z}_p^*$ of order $q$), and let $g$ be a generator of $\mathbb{G}$. The private key is $(\mathbb{G}, g, q, x)$ and the public key is $(\mathbb{G}, g, q, h)$, where $h = g^x$ and $x \in \mathbb{Z}_q$ is chosen uniformly. To encrypt a message $m \in \mathbb{Z}_p$, choose a uniform $r \in \mathbb{Z}_q$, compute $c_1 := g^r \bmod p$ and $c_2 := h^r + m \bmod p$, and let the ciphertext be $\langle c_1, c_2 \rangle$. Is this scheme CPA-secure? Prove your answer.

**Solution.** This scheme is not secure. Consider an adversary $\mathcal{A}$ that chooses uniform $m_0, m_1 \in \mathbb{Z}_p$ and then receives the challenge ciphertext $\langle c_1, c_2 \rangle$. Since $c_2 = h^r + m \bmod p$, it is not necessarily the case that $c_2 \in \mathbb{G}$ (addition is not the group operation). However, $[c_2 - m_b \bmod p] \in \mathbb{G}$, where $m_b$ is the encrypted value. As shown in the text, membership in $\mathbb{G}$ can be tested efficiently. Now, $\mathbb{G}$ contains exactly half the elements of $\mathbb{Z}_p^*$, so since $m_{1-b}$ is random, $[c_2 - m_{1-b} \bmod p] \in \mathbb{G}$ with probability only ${1}/2$. The adversary checks whether $[c_2 - m_0 \bmod p] \in \mathbb{G}$ and whether $[c_2 - m_1 \bmod p] \in \mathbb{G}$. If both are in the group, it outputs a uniform bit; otherwise it outputs the bit $b$ for which $[c_2 - m_b \bmod p] \in \mathbb{G}$. A simple calculation shows that $\mathcal{A}$ succeeds with probability ${3}/4$.

## 12.8

> **题目**　Consider the following protocol for two parties *A* and *B* to flip a fair coin (more complicated versions of this might be used for Internet gambling): (1) a trusted party *T* publishes her public key *pk*; (2) then *A* chooses a uniform bit $b_A$, encrypts it using *pk*, and announces the ciphertext $c_A$ to *B* and *T*; (3) next, *B* acts symmetrically and announces a ciphertext $c_B \ne c_A$; (4) *T* decrypts both $c_A$ and $c_B$, and the parties XOR the results to obtain the value of the coin.
>
> (a) Argue that even if *A* is dishonest (but *B* is honest), the final value of the coin is uniformly distributed.
>
> (b) Assume the parties use El Gamal encryption (where the bit *b* is encoded as the group element $g^b$ before being encrypted – note that efficient decryption is still possible). Show how a dishonest *B* can bias the coin to any value he likes.
>
> (c) Suggest what type of encryption scheme would be appropriate to use here. Can you define an appropriate notion of security and prove that your suggestion achieves this definition?

**Solution.**

(a) The ciphertext $c_A$ output by *A* corresponds to *some* bit $b_A$. (It could also be an invalid ciphertext that does not decrypt at all, though this cannot occur [without being detected] when using El Gamal encryption. If *T* detects an invalid ciphertext upon decryption, then it can just take $b_A := 0$.) If *B* is honest, then $b_B$ is uniform and independent of $b_A$, and so the coin $b_A \oplus b_B$ is uniform.

(b) The problem when trying to apply the argument in part (a) to the case when *B* is dishonest is that *B* might choose $c_B$ in a way that *depends* on $c_A$ (and hence $b_B$ depends on $b_A$); this was not possible when the dishonest party went first. We show that when El Gamal encryption is used, *B* can bias the coin any way it likes.

*B* can bias the coin toward 0 as follows. Given the ciphertext $c_A = \langle c_1, c_2 \rangle$ announced by *A*, player *B* chooses uniform $r \leftarrow \mathbb{Z}_q$ and outputs $c_B = \langle c_1^{\prime}, c_2^{\prime} \rangle$ with

$$c_1^{\prime} := c_1 \cdot g^r \qquad \text{and} \qquad c_2^{\prime} := c_2 \cdot h^r.$$

One can check that $c_B$ always decrypts to $b_A$, and so the coin is always 0 if *B* follows this strategy. Furthermore, it holds that $c_B$ is distributed exactly like a *random* encryption of $b_A$ (this is not too much more difficult to show), and so this kind of cheating by *B* is undetectable (since it is indistinguishable whether *B* is cheating or whether it just happened that *B* chose $b_B = b_A$).

To bias toward 1, player *B* can do the following. Given $c_A$ as above, choose uniform $r \leftarrow \mathbb{Z}_q$ and output $c_B = \langle c_1^{\prime}, c_2^{\prime} \rangle$ with

$$c_1^{\prime} := (c_1)^{-1} \cdot g^r \qquad \text{and} \qquad c_2^{\prime} := (c_2)^{-1} \cdot g \cdot h^r.$$

One can check that now $b_B = 1 - b_A$, and so the coin always comes out to be 1. Once again, $c_B$ is in fact a random encryption of ${1} - b_A$ and so this form of cheating is undetectable.

(c) A CCA-secure encryption scheme should be used to prevent the attack described in part (b).

We define security informally since security of two-party protocols is not covered in the book. Say a coin-tossing protocol Π is secure if, for any PPT adversary corrupting either one of the parties, the probability $p = p(n)$ that the resulting coin is 0 is negligibly close to $\frac{1}{2}$. (I.e., there is a negligible function $\mathsf{negl}$ such that $|p(n) - \frac{1}{2}| \le \mathsf{negl}(n)$.) Note that we use absolute value here since we don't want the coin to be biased toward either 0 or 1. We claim that the protocol in this exercise, when instantiated with a CCA-secure public-key encryption scheme, is a secure coin-tossing protocol. (We add one point of clarification for the protocol: if either party's ciphertext is invalid [including the case when it does not decrypt to 0/1] or a party fails to announce any ciphertext, then *T* treats their bit as a 0.)

We have seen already in part (a) that an adversary corrupting *A* cannot bias the coin. So consider the case when *B* is corrupted. Let Π denote the CCA-secure encryption scheme used in the protocol. Define the following adversary $\mathcal{A}$ attacking Π:

**Adversary $\mathcal{A}$:**

i. $\mathcal{A}$ is given *pk* and outputs $m_0 = 0$ and $m_1 = 1$.

ii. $\mathcal{A}$ is given in return a ciphertext $c_A$. It then runs $B(c_A)$ to obtain a ciphertext $c_B \ne c_A$. $\mathcal{A}$ submits $c_B$ to its decryption oracle and receives in return a bit $b^{\prime}$. Then:
    - If *B* fails to output any ciphertext, or decryption of $c_B$ returns an error (including $b^{\prime} \notin \{0,1\}$), or $b^{\prime} = 0$, then $\mathcal{A}$ outputs 0.
    - If $b^{\prime} = 1$, then $\mathcal{A}$ outputs 1.

We have

$$\begin{aligned}
\Pr[\mathsf{PubK}^{\mathsf{cca}}_{\mathcal{A},\Pi}(n) = 1] &= \frac{1}{2} \cdot \Pr[\mathcal{A} \text{ outputs } 0 \mid c_A \text{ is an encryption of } 0] \\
&\quad + \frac{1}{2} \cdot \Pr[\mathcal{A} \text{ outputs } 1 \mid c_A \text{ is an encryption of } 1] \\
&= \frac{1}{2} \cdot \Pr[\text{coin} = 0 \mid c_A \text{ is an encryption of } 0] \\
&\quad + \frac{1}{2} \cdot \Pr[\text{coin} = 0 \mid c_A \text{ is an encryption of } 1] \\
&= \Pr[\text{coin} = 0] \stackrel{\mathrm{def}}{=} p(n).
\end{aligned}$$

CCA-security of Π implies that $p(n) \le \frac{1}{2} + \mathsf{negl}(n)$ for some negligible function $\mathsf{negl}$. A similar argument, flipping the output of $\mathcal{A}$, shows that ${1} - p(n) \le \frac{1}{2} + \mathsf{negl}(n)$ as well. Together, these complete the proof of security for the protocol.

## 12.9

> **题目**　Prove formally that the El Gamal encryption scheme is not CCA-secure.

**Solution.** Consider the following attacker $\mathcal{A}$: given public key $(\mathbb{G}, q, g, h)$, choose arbitrary (distinct) $h_0, h_1 \in \mathbb{G}$ as the challenge messages. Upon receiving the challenge ciphertext $\langle c_1, c_2 \rangle$, compute $c_2^{\prime} := h \cdot c_2$ and request decryption of $\langle c_1, c_2^{\prime} \rangle$, receiving some $u$ in return. Finally, output 0 if $u/h = h_0$, and output 1 if $u/h = h_1$.

This succeeds in the CCA-experiment with probability 1. Observe that $\langle c_1, c_2 \rangle = \langle g^y, h^y \cdot h_b \rangle$, so $\langle c_1, c_2^{\prime} \rangle = \langle g^y, h^y \cdot h_b \cdot h \rangle$. The decryption oracle thus returns $u = h_b \cdot h$, and $u/h = h_b$, as required.

(a) $\mathsf{Gen}(1^n)$ *is run to obtain keys* $(pk, sk)$.

## 12.14

> **题目**　Consider the following modified version of padded RSA encryption: Assume messages to be encrypted have length exactly $\|N\|/2$. To encrypt, first compute $\hat{m} := \mathtt{0x00} \,\|\, r \,\|\, \mathtt{0x00} \,\|\, m$ where *r* is a uniform string of length $\|N\|/2 - 16$. Then compute the ciphertext $c := [\hat{m}^e \bmod N]$. When decrypting a ciphertext *c*, the receiver computes $\hat{m} := [c^d \bmod N]$ and returns an error if $\hat{m}$ does not consist of `0x00` followed by $\|N\|/2 - 16$ arbitrary bits followed by `0x00`. Show that this scheme is not CCA-secure. Why is it easier to construct a chosen-ciphertext attack on this scheme than on PKCS #1 v1.5?

**Solution.** Consider the following adversary:

**Algorithm $\mathcal{A}$:**

(a) Given the public key $N$, $e$, output $m_0 = 00\cdots0$ and $m_1 = 01\cdots1$. Receive in return a ciphertext *c*.

(b) Set $c^{\prime} := [2^e \cdot c \bmod N]$ and submit $c^{\prime}$ to the decryption oracle.

(c) If the decryption oracle returns an error, then output a uniform bit. Otherwise, let $m^{\prime}$ denote the message returned by the decryption oracle.

(d) Output the most significant bit of $m^{\prime}$.

Why does this attack succeed (with high probability)? Let *b* denote the bit such that *c* is an encryption of $m_b$, and let $k = \|N\|/2 - 16$. Then

$$c = \left[(\mathtt{0x00} \,\|\, r_1 \cdots r_k \,\|\, \mathtt{0x00} \,\|\, 0b \cdots b)^e \bmod N\right]$$

and

$$\begin{aligned}
c^{\prime} = 2^e \cdot c &= \left[\left(2 \cdot (\mathtt{0x00} \,\|\, r_1 \cdots r_k \,\|\, \mathtt{0x00} \,\|\, 0b \cdots b)\right)^e \bmod N\right] \\
&= \left[(0^7 r_1 \,\|\, r_2 \cdots r_k 0 \,\|\, \mathtt{0x00} \,\|\, b \cdots b0)^e \bmod N\right].
\end{aligned}$$

(Multiplication by 2 corresponds to a left-wise bit shift; there is no reduction modulo *N* since the leading bit of the multiplicand is 0.) Decryption of $c^{\prime}$ results in an error only if $r_1 = 1$, which occurs with probability ${1}/2$; if no error occurs, then the most significant bit of the decrypted message is *b*. Thus the above attack correctly determines *b* with probability ${3}/4$.

This simple attack does not work on PKCS #1 v1.5. In that scheme, encryption of a message *m* is done by computing

$$c := \left[(00000000 \,\|\, 00000010 \,\|\, r_1 r_2 \cdots \,\|\, 00000000 \,\|\, m_1 m_2 \cdots)^e \bmod N\right],$$

where *r* is uniform. Thus, setting $c^{\prime} := [2^e \cdot c \bmod N]$ would give

$$c^{\prime} = \left[(00000000 \,\|\, 0000010 r_1 \,\|\, r_2 \cdots 0 \,\|\, 0000000 m_1 \,\|\, m_2 \cdots)^e \bmod N\right],$$

which will never decrypt correctly (since the second byte is formatted incorrectly, regardless of the value of $r_1$).

> **题目**　Let $\Pi = (\mathsf{Gen}, \mathsf{Enc}$, $\mathsf{Dec})$ be a CPA-secure public-key encryption scheme, and let $\Pi^{\prime} = (\mathsf{Gen}^{\prime}, \mathsf{Enc}^{\prime}$, $\mathsf{Dec}^{\prime})$ be a CCA-secure private-key encryption scheme. Does Construction 12-S have indistinguishable encryptions under a chosen-*ciphertext* attack, if *H* is modeled as a random oracle? If yes, provide a proof. If not, where does the approach used to prove Theorem 12.38 break down? 【原文如此】
>
> **Construction 12.2-S**.
>
> Let $H : \{0,1\}^n \rightarrow \{0,1\}^n$ be a function. Construct a public-key encryption scheme as follows:
>
> - $\mathsf{Gen}^*$: on input ${1}^n$, run $\mathsf{Gen}(1^n)$ to obtain $(pk, sk)$. Output these as the public and private keys, respectively.
> - $\mathsf{Enc}^*$: on input a public key *pk* and a message $m \in \{0,1\}^n$, choose a uniform $r \in \{0,1\}^n$ and output the ciphertext

**Solution.** $\Pi^*$ does *not*, in general, have indistinguishable encryptions under a chosen-ciphertext attack. The issue is that it might be easy to take a ciphertext $c_1$ encrypted using Π and generate a *different* ciphertext $c_1^{\prime}$ that decrypts to the same value as $c_1$. ## 12.19

> **题目**　Consider the following variant of Construction 12.32: Let $\mathsf{GenRSA}$ be as usual, and define a public-key encryption scheme as follows. $\mathsf{Gen}$: on input ${1}^n$, run $\mathsf{GenRSA}(1^n)$ to obtain $(N, e, d)$; output the public key $pk = \langle N, e \rangle$ and the private key $sk = \langle N, d \rangle$. $\mathsf{Enc}$: on input $pk = \langle N, e \rangle$ and a message $m \in \{0,1\}$, choose a uniform $r \in \mathbb{Z}_N^*$ and output the ciphertext $\langle [r^e \bmod N], \mathsf{lsb}(r) \oplus m \rangle$. $\mathsf{Dec}$: on input $sk = \langle N, d \rangle$ and a ciphertext $\langle c, b \rangle$, compute $r := [c^d \bmod N]$ and output $\mathsf{lsb}(r) \oplus b$. Prove that this scheme is CPA-secure.

**Solution.** The proof is (conceptually) very similar to the proof of Theorem 12.33. Let $\Pi$ denote the above scheme, and let $\mathcal{A}$ be an adversary attacking it. Assume for simplicity (and without loss of generality) that $\mathcal{A}$ always outputs $m_0 = 0$ and $m_1 = 1$. Construct an algorithm $\mathcal{A}^{\prime}$ for experiment $\mathsf{RSA\text{-}lsb}$ as follows: $\mathcal{A}^{\prime}$, given $N, e, c$, chooses a uniform bit $\hat{b}$ and computes $b^{\prime} \leftarrow \mathcal{A}(N, e, \langle c, \hat{b} \rangle)$; it then outputs $\hat{b} \oplus b^{\prime}$. Let $r$ be the (unknown) value such that $c = [r^e \bmod N]$. Then

$$\Pr[\mathcal{A}^{\prime}(N,e,c) = 0 \mid \mathsf{lsb}(r) = 0] = \tfrac{1}{2}\bigl(\Pr[\mathcal{A}(N,e,\langle c,0\rangle)=0 \mid \mathsf{lsb}(r)=0] + \Pr[\mathcal{A}(N,e,\langle c,1\rangle)=1 \mid \mathsf{lsb}(r)=0]\bigr),$$

and similarly

$$\Pr[\mathcal{A}^{\prime}(N,e,c) = 1 \mid \mathsf{lsb}(r) = 1] = \tfrac{1}{2}\bigl(\Pr[\mathcal{A}(N,e,\langle c,0\rangle)=1 \mid \mathsf{lsb}(r)=1] + \Pr[\mathcal{A}(N,e,\langle c,1\rangle)=0 \mid \mathsf{lsb}(r)=1]\bigr).$$

Moreover,

$$\Pr[\mathcal{A}\text{ outputs }0 \mid 0\text{ is encrypted}] = \tfrac{1}{2}\bigl(\Pr[\mathcal{A}(N,e,\langle c,0\rangle)=0 \mid \mathsf{lsb}(r)=0] + \Pr[\mathcal{A}(N,e,\langle c,1\rangle)=0 \mid \mathsf{lsb}(r)=1]\bigr),$$

and symmetrically for $\Pr[\mathcal{A}\text{ outputs }1 \mid 1\text{ is encrypted}]$. Putting everything together gives

$$\Pr[\mathsf{PubK}^{\mathsf{eav}}_{\mathcal{A},\Pi}(n) = 1] = \Pr[\mathsf{RSA\text{-}lsb}_{\mathcal{A}^{\prime},\mathsf{GenRSA}}(n) = 1],$$

which shows the scheme is CPA-secure if the RSA problem is hard relative to $\mathsf{GenRSA}$.

## 12.20

> **题目**　Fix an RSA public key $\langle N, e \rangle$ and assume we have an algorithm $\mathcal{A}$ that always correctly computes $\mathsf{lsb}(x)$ given $[x^e \bmod N]$. Write full pseudocode for an algorithm $\mathcal{A}^{\prime}$ that computes *x* from $[x^e \bmod N]$.

**Solution.** Let $\gamma \stackrel{\mathrm{def}}{=} [2^{-1} \bmod N]$. The intuition is that $x^e \cdot \gamma^e = (x\gamma)^e \bmod N$; thus, multiplication by $\gamma^e$ can be used to effect a right-wise bit-shift (i.e., division by 2), which can in turn be used to learn all the bits of *x* one-by-one. There are, however, some technicalities.

**Algorithm 12.3-S.**

**Input:** $\langle N, e \rangle$; $c \in \mathbb{Z}_N^*$; $\ell$

**Output:** the $\ell$ least significant bits of $[c^{1/e} \bmod N]$

**if** $\ell = 1$, return $\mathcal{A}(N, e, c)$

$\gamma := [2^{-1} \bmod N]$

$x_0 := \mathcal{A}(N, e, c)$

$x^{\prime} := \mathsf{GetBits}(N, e, [c \cdot \gamma^e \bmod N], \ell - 1)$

**if** $x_0 = 0$ **return** $x^{\prime} \,\|\, x_0$

**else** **return** $[2x^{\prime} - N \bmod 2^\ell]$

When $\mathsf{lsb}(x) = 0$ then $[\gamma \cdot x \bmod N]$ is indeed just a right-shift of *x* (since *x*, viewed as an integer, is divisible by 2). But when $\mathsf{lsb}(x) = 1$, then $[\gamma \cdot x \bmod N] = \frac{x+N}{2}$. (Note that *N* is odd.) We take this into account in Algorithm 12.3-S, which is described recursively. The algorithm relies on the assumed algorithm $\mathcal{A}$ for computing $\mathsf{lsb}(x)$. When called with $\ell = \|N\|$ it returns all the bits of $x = [c^{1/e} \bmod N]$.
