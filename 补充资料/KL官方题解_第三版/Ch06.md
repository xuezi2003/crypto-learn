## 6.2

> **题目**　Let $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ be two hash functions. Define $(\mathsf{Gen}, H)$ so that $\mathsf{Gen}$ runs $\mathsf{Gen}_1$ and $\mathsf{Gen}_2$ to obtain keys $s_1$ and $s_2$, respectively. Then define $H^{s_1,s_2}(x) = H_1^{s_1}(x) \| H_2^{s_2}(x)$.
>
> (a) Prove that if at least one of $(\mathsf{Gen}_1, H_1)$ and $(\mathsf{Gen}_2, H_2)$ is collision resistant, then $(\mathsf{Gen}, H)$ is collision resistant.
>
> (b) Determine whether an analogous claim holds for second-preimage resistance and preimage resistance, respectively. Prove your answer in each case.

**Solution.**

(a) Let $\mathcal{A}$ be an adversary that with probability $\varepsilon(n)$ outputs a pair $x, x^{\prime}$ such that $H^{s_1,s_2}(x) = H^{s_1,s_2}(x^{\prime})$. In such a case, by the definition of $H$, we have that $H_1^{s_1}(x) = H_1^{s_1}(x^{\prime})$ *and* $H_2^{s_2}(x) = H_2^{s_2}(x^{\prime})$. Thus, with probability $\varepsilon$, the adversary $\mathcal{A}$ finds a collision in both $H_1$ and $H_2$. A full reduction is straightforward (to attack $H_1$ with key $s_1$, run $\mathsf{Gen}_2$ to get $s_2$, invoke $\mathcal{A}$ with key $(s_1, s_2)$, and then output the pair that $\mathcal{A}$ outputs).

(b) An analogous claim does hold for second-preimage resistance. Informally, this is again because a collision in $H$ yields a collision in both $H_1$ and $H_2$. A formal proof is straightforward.

The same does not hold for preimage resistance, i.e., it is possible that (say) $H_1$ is preimage resistant yet $H$ is not. We sketch a counter example demonstrating this. Let $\widehat{H}$ be a preimage resistant hash function mapping $n$-bit inputs to $n/4$-bit outputs. Define $H_1^s(x_1 \| x_2) = x_1 \| \widehat{H}^s(x_2)$, where $x_1, x_2 \in \{0,1\}^n$. Note that $H_1$ is compressing and preimage resistant. Define $H_2$ as $H_2^s(x_1 \| x_2) = x_2$. Then

$$\begin{aligned}
H^{s_1,s_2}(x_1 \| x_2) &= H_1^{s_1}(x_1 \| x_2) \| H_2^{s_2}(x_1 \| x_2) \\
&= x_1 \| \widehat{H}^{s_1}(x_2) \| x_2,
\end{aligned}$$

and it is trivial to find a preimage in $H$.

## 6.3

> **题目**　Let $(\mathsf{Gen}, H)$ be a collision-resistant hash function. Is $(\mathsf{Gen}, \widehat{H})$ defined by $\widehat{H}^{s}(x) \stackrel{\mathrm{def}}{=} H^{s}(H^{s}(x))$ necessarily collision resistant?

**Solution.** Yes. Let $x, x^{\prime}$ be a collision for $\widehat{H}$; that is, $H^{s}(H^{s}(x)) = H^{s}(H^{s}(x^{\prime}))$. There are two cases:

(a) $H^{s}(x) = H^{s}(x^{\prime})$: in this case, $x, x^{\prime}$ is a collision for the original $H$. Therefore, such a pair can only be found with negligible probability.

(b) $H^{s}(x) \ne H^{s}(x^{\prime})$: set $y = H^{s}(x)$ and $y^{\prime} = H^{s}(x^{\prime})$. By the assumption in this case, $y \ne y^{\prime}$ and yet $H^{s}(y) = H^{s}(y^{\prime})$. Thus, $y, y^{\prime}$ is a collision in $H$. Once again, this implies that such a pair $x, x^{\prime}$ can be found with only negligible probability (otherwise, by computing $H^{s}$ once on each one obtains a collision $y, y^{\prime}$ in $H^{s}$).

## 6.4

> **题目**　Provide a formal proof of Theorem 6.4 (i.e., describe the reduction).

**Solution.** Let $\mathcal{A}$ be a probabilistic polynomial-time adversary and $\varepsilon$ a function such that $\mathcal{A}$ succeeds in the Hash-coll experiment with $(\mathsf{Gen}, H)$ with probability $\varepsilon$. We construct an adversary $\mathcal{A}^{\prime}$ that succeeds in the Hash-coll experiment with $(\mathsf{Gen}, h)$ with probability $\varepsilon$. Upon receiving $s$, $\mathcal{A}^{\prime}$ invokes $\mathcal{A}$ on $s$ and receives in return values $x, x^{\prime}$. If $H^s(x) \ne H^s(x^{\prime})$ then $\mathcal{A}^{\prime}$ halts. Otherwise, $\mathcal{A}^{\prime}$ uses the strategy described in the proof of Theorem 6.4 to find a collision in $h$. Specifically, if $L \ne L^{\prime}$ then $\mathcal{A}^{\prime}$ outputs $z_{B-1} \| x_B$ and $z^{\prime}_{B^{\prime}-1} \| x^{\prime}_{B^{\prime}}$. Otherwise, if $L = L^{\prime}$, then $\mathcal{A}^{\prime}$ works backwards from the last block to the first to find the maximal $i^*$. Then, $\mathcal{A}^{\prime}$ outputs $I_N, I_N^{\prime}$ as defined in the proof of Theorem 6.4. (Note that $\mathcal{A}^{\prime}$ can compute all the $z$-values by evaluating $H^s$ on $x$ and $x^{\prime}$.) As argued in the proof of Theorem 6.4, whenever $\mathcal{A}$ finds a collision $\mathcal{A}^{\prime}$ also finds a collision. Thus, $\mathcal{A}^{\prime}$ succeeds in Hash-coll for $(\mathsf{Gen}, h)$ with probability $\varepsilon$, implying that $\varepsilon$ is negligible. Thus, $(\mathsf{Gen}, H)$ is collision-resistant.

## 6.6

> **题目**　Consider the following modification of the Merkle-Damgård transform: append a 1 to the input $x$, followed by enough zeros so that the length of the resulting string is $n$ more than a multiple of $n^{\prime}$. Parse the resulting string as $z_0, x_1, \ldots, x_B$, where $|z_0| = n$ and $|x_i| = n^{\prime}$. Then for $i = 1, \ldots, B$, compute $z_i := h^s(z_{i-1} \| x_i)$; output $z_B$.
>
> Show how to find a collision in the resulting hash function when this transform is applied to any compression function $(\mathsf{Gen}, h)$.

**Solution.** We assume for concreteness that the compression functions map inputs of length ${2}n$ to outputs of length $n$. Given a key $s$, let $y = h^s(0^n, 0^n)$. We claim that $H^s(0^n, 0^n, 0^{n-1}) = H^s(y, 0^{n-1})$. This follows since

$$H^s(0^n, 0^n, 0^{n-1}) = h^s(h^s(0^n, 0^n), 0^{n-1}1) = h^s(y, 0^{n-1}1) = H^s(y, 0^{n-1}).$$

## 6.8

> **题目**　Assume collision-resistant hash functions exist. Show a construction of a fixed-length hash function $(\mathsf{Gen}, h)$ that is *not* collision resistant but such that the hash function $(\mathsf{Gen}, H)$ obtained from the Merkle-Damgård transform to $(\mathsf{Gen}, h)$ *is* collision resistant.

**Solution.** Without loss of generality, say the first bit of the $IV$ used in the Merkle-Damgård transform is 0. Let $(\mathsf{Gen}, \widehat{h})$ be a collision-resistant compression function mapping inputs of length ${2}n-1$ to outputs of length $n-1$, and define $(\mathsf{Gen}, h)$ mapping inputs of length ${2}n$ to outputs of length $n$ by setting

$$h^s(0 \| x) = 0 \| \widehat{h}^s(x) \quad \text{and} \quad h^s(1 \| x) = 1^n.$$

Clearly $(\mathsf{Gen}, h)$ is not collision resistant, but one can show that the hash function $(\mathsf{Gen}, H)$ obtained from applying the Merkle-Damgård transform to $(\mathsf{Gen}, h)$ is collision-resistant.

## 6.9

> **题目**　Prove or disprove: if $(\mathsf{Gen}, h)$ is preimage resistant, then so is the hash function $(\mathsf{Gen}, H)$ obtained by applying the Merkle-Damgård transform to $(\mathsf{Gen}, h)$.

**Solution.** (Note: for preimage resistance to be defined we must specify some input length. We consider inputs of length $L$, where $L$ is arbitrary.) This is, in general, false. To see this, let $(\mathsf{Gen}, h)$ be preimage resistant but such that $h^s(x \| L) = 0^n$ for all $s$ and all $x \in \{0,1\}^n$. (A full answer would prove that such a hash function exists assuming preimage-resistant hash functions exist at all.) Then the Merkle-Damgård transform applied to $(\mathsf{Gen}, h)$ yields a hash function $(\mathsf{Gen}, H)$ for which every $L$-bit input hashes to ${0}^n$ (and so is clearly not preimage resistant).

## 6.10

> **题目**　Prove or disprove: if $(\mathsf{Gen}, h)$ is second-preimage resistant, then so is the hash function $(\mathsf{Gen}, H)$ obtained by applying the Merkle-Damgård transform to $(\mathsf{Gen}, h)$.

**Solution.** This is, in general, false. To see this, let $(\mathsf{Gen}, h)$ be a second-preimage resistant compression function mapping ${2}n$-bit inputs to $n$-bit outputs, and with the properties that

(a) for any key $s$ and any $x \in \{0,1\}^{2n}$, the first $n/2$ bits of $h^s(x)$ are 0;

(b) $h^s(0^{n/2} y) = 0^n$ for any $y \in \{0,1\}^{3n/4}$.【原文如此；按维度（$h$ 输入为 ${2}n$ 比特、M-D 链值为 $n$ 比特）此处疑应为 $\{0,1\}^{3n/2}$】

(A full answer would prove that such a compression function exists assuming the existence of any second-preimage resistant compression function.) Then the Merkle-Damgård transform applied to $(\mathsf{Gen}, h)$ yields a hash function $(\mathsf{Gen}, H)$ for which $H^s(x) = 0^n$ for any $x \in \{0,1\}^{2n}$, and so finding second preimages is easy.

## 6.12

> **题目**　A student has 3,500 songs on her phone and chooses songs to play at random. How many songs should the student expect to play before hearing some song twice (with probability at least 50%)?

**Solution.** This is a simple application of the birthday bound (see Lemma A.15). We want to find $q$ such that $\mathsf{coll}(q, 3500) \ge 0.5$. Since $\mathsf{coll}(q, 3500) \ge q \cdot (q-1)/14000$, we see that $q = 85$ suffices.

## 6.14

> **题目**　Fix $H : \{0,1\}^n \rightarrow \{0,1\}^{2n}$, and define the keyed function $F : \{0,1\}^n \times \{0,1\}^n \rightarrow \{0,1\}^{2n}$ by $F_k(x) = H(k \oplus x)$. Show that an attacker given oracle access to $F_k(\cdot)$ can recover the $n$-bit key $k$ with constant probability in time $\approx 2^{n/2}$ (which is better than a brute-force attack).

**Solution.** The attack works as follows: Set $q = 2^{n/2}$, choose $q$ uniform values $y_1, \ldots, y_q \in \{0,1\}^n$, and compute $z_i := H(y_i)$ for $i = 1, \ldots, q$. Then choose $q$ uniform values $\widehat{y}_1, \ldots, \widehat{y}_q$ and query the oracle to obtain $z^{\prime}_i := F_k(\widehat{y}_i) = H(k \oplus \widehat{y}_i)$ for $i = 1, \ldots, q$. Finally, if $z_i = z^{\prime}_j$ for some $i$, $j$ then guess that the key is $y_i \oplus \widehat{y}_j$.

If we define $y^{\prime}_i = k \oplus \widehat{y}_i$, then we see that $y_1, \ldots, y_q$ and $y^{\prime}_1, \ldots, y^{\prime}_q$ are all uniformly distributed. Using the result of the previous exercise, it therefore holds with probability at least ${1}/2$ that $y_i = y^{\prime}_j$ for some $i$, $j$; when that happens then $z_i = z^{\prime}_j$ and the algorithm correctly identifies the key. To complete the analysis we only need to argue that the probability that $z_i = z^{\prime}_j$ when $y_i \ne y^{\prime}_j$ (call this a *spurious collision*) is small. If we view $H$ as a random function, then this follows because every time we evaluate $H$ on a new input we obtain a uniform ${2}n$-bit output; using the previous exercise again, we see that the probability of a spurious collision at most $q^2/2^{2n}$, which is negligible.

## 6.15

> **题目**　Prove that the keyed function $F$ given in Section 6.5.1 is a pseudorandom function if $H$ is modeled as a random oracle.

**Solution.** Let us be clear about the probability spaces of the experiments we will be considering. Let the security parameter be $n$. In the first experiment, a random function $H : \{0,1\}^{2n} \to \{0,1\}^n$ and a random key $k \in \{0,1\}^n$ are chosen, and $\mathcal{A}$ is given access to $H$ as well as the function $F_k(\cdot) \stackrel{\mathrm{def}}{=} H(k \| \cdot)$. In the second experiment, a random function $H : \{0,1\}^{2n} \to \{0,1\}^n$ and an independent random function $f : \{0,1\}^n \to \{0,1\}^n$ are chosen, and $\mathcal{A}$ is given access to $H$ and $f$. We want to show that the following is negligible:

$$\left| \Pr[\mathcal{A}^{H(\cdot), H(k \| \cdot)}(1^n) = 1] - \Pr[\mathcal{A}^{H(\cdot), f(\cdot)}(1^n) = 1] \right|.$$

Observe that the views of $\mathcal{A}$ in the two experiments are identical (i.e., $\mathcal{A}$ gets uniform and independent responses from each of its oracles) until $\mathcal{A}$ makes a query of the form $k \| \star$ to its $H$-oracle in the first experiment. Since $\mathcal{A}$ has no information about $k$, the probability that it ever makes such a query is $q/2^n$, where $q$ is a bound on the total number of queries made by $\mathcal{A}$. Since $q$ must be polynomial, this occurs with negligible probability.

## 6.16

> **题目**　Prove Theorem 6.11.

**Solution.** The proof is similar to the proof of Theorem 6.4; namely, we show that a collision in $\mathcal{MT}_t$ implies a collision in $H$. Consider two inputs $(x_1, \ldots, x_t) \ne (x^{\prime}_1, \ldots, x^{\prime}_t)$ for which $\mathcal{MT}_t(x_1, \ldots, x_t) = h = \mathcal{MT}_t(x^{\prime}_1, \ldots, x^{\prime}_t)$. Following Figure 6.5, we can imagine a pair of binary trees with ${1} + \log t$ levels where $h$ is at the 0th level of both trees and the inputs ($x_1, \ldots, x_t$ in one case and $x^{\prime}_1, \ldots, x^{\prime}_t$ in the other case) are at the $t$th level of the trees. Let $i$ denote the least integer for which the values at level $i$ are equal in the two trees but the values at level $i+1$ are not. Then there must be a collision in $H$ at that level.

## 6.17

> **题目**　Show how to find a collision in the Merkle tree construction if $t$ is not fixed. Specifically, show how to find two sets of inputs $x_1, \ldots, x_t$ and $x^{\prime}_1, \ldots, x^{\prime}_{2t}$ such that $\mathcal{MT}_t(x_1, \ldots, x_t) = \mathcal{MT}_{2t}(x^{\prime}_1, \ldots, x^{\prime}_{2t})$.

**Solution.** We give a solution for $t = 2$ for concreteness. Let $x^{\prime}_1, x^{\prime}_2, x^{\prime}_3, x^{\prime}_4$ be arbitrary. Set $x_1 = H(x^{\prime}_1, x^{\prime}_2)$ and $x_2 = H(x^{\prime}_3, x^{\prime}_4)$. Then notice that $\mathcal{MT}_2(x_1, x_2) = \mathcal{MT}_4(x^{\prime}_1, \ldots, x^{\prime}_4)$.

## 6.18

> **题目**　Modify the construction of a Merkle tree so that it is collision resistant even when the number of inputs $t$ may vary.

**Solution.** Various solutions are possible here. Perhaps the simplest (without changing the output length) is to simply include $t$ as an input to the final hash; i.e., to compute the tree exactly as before except that the root is computed as $h_{1 \ldots t} = H(t, h_{1, \ldots, t/2}, h_{t/2+1, \ldots, t})$. We leave a proof that this is collision resistant (even when $t$ may vary) to the reader.

## 6.19

> **题目**　Consider the scenario introduced in Section 6.6.2 in which a client stores files on a server and wants to verify that files are returned unmodified.
>
> (a) Provide a formal definition of security for this setting.
>
> (b) Formalize the protocol based on Merkle trees as discussed in Section 6.6.2.
>
> (c) Prove that your construction is secure relative to your definition under the assumption that $(\mathsf{Gen}_{H}, H)$ is collision resistant.

**Solution.**

(a) We first define the semantics of a scheme (we note that our formulation is not the only one possible). Let $\Pi = (\mathsf{Upload}, \mathsf{Return}, \mathsf{Vrfy})$ be a triple of algorithms that work as follows:

- $\mathsf{Upload}$ takes as input files $x_1, \ldots, x_t$ and returns state $s$.
- $\mathsf{Return}$ takes as input an index $i$ and files $x_1, \ldots, x_t$, and returns a proof $\pi_i$.
- $\mathsf{Vrfy}$ takes as input state $s$, an index $i$, a file $x$, and a proof $\pi$, and outputs a bit indicating acceptance or rejection.

In the intended operation of the scheme, the client begins by computing $s \leftarrow \mathsf{Upload}(x_1, \ldots, x_t)$, sending $x_1, \ldots, x_t$ to the server, and storing $s$ locally. When the client wants file $i$, it sends $i$ to the server, who then computes $\pi \leftarrow \mathsf{Return}(i, x_1, \ldots, x_t)$ and sends back $x_i$ and $\pi$. The client then computes $\mathsf{Vrfy}(s, i, x_i, \pi)$. Correctness requires that, when run as described, $\mathsf{Vrfy}$ returns 1.

We now define security. (Again, other definitions are possible.) $\Pi$ is secure if for all PPT adversaries $\mathcal{A}$ there is a negligible function $\mathsf{negl}$ such that the success probability of $\mathcal{A}$ in the following experiment is negligible:

1. $\mathcal{A}$ outputs $x_1, \ldots, x_t$, $i$, $x$, and $\pi$.
2. Compute $s \leftarrow \mathsf{Upload}(x_1, \ldots, x_t)$.
3. $\mathcal{A}$ succeeds if $\mathsf{Vrfy}(s, i, x, \pi) = 1$ and $x \ne x_i$.

(b)

- $\mathsf{Upload}(x_1, \ldots, x_t)$ computes $h := \mathcal{MT}_t(x_1, \ldots, x_t)$ and lets $s := (h, t)$.
- $\mathsf{Return}(i, x_1, \ldots, x_t)$ computes $\mathcal{MT}_t(x_1, \ldots, x_t)$ and lets $\pi$ be the values of the nodes in the Merkle tree adjacent to the path from $x_i$ to the root (as described in Section 6.6.2).
- $\mathsf{Vrfy}(s, i, x, \pi)$, where $s = (h, t)$, uses $t$, $\pi$, $x$, and $i$ to recompute a candidate value $h^{\prime}$ for the root of the Merkle tree (as described in Section 6.6.2). It outputs 1 iff $h^{\prime} = h$.

(c) A proof of security follows by showing that if $\mathcal{A}$ succeeds in the experiment above, a collision in $H$ is found. We omit the details.

## 6.20

> **题目**　Prove that the commitment scheme discussed in Section 6.6.5 is secure if $H$ is modeled as a random oracle.

**Solution.** Binding follows immediately from the fact that $H$ is collision resistant (as discussed in Section 6.5.1). For hiding, we provide only a sketch of the proof. Consider an attacker $\mathcal{A}$ in experiment $\mathsf{Hiding}_{\mathcal{A},\mathsf{Com}}(n)$ that makes $q$ queries to $H$. Let $r$ denote the random value used by the sender, and note that (1) the view of $\mathcal{A}$ is independent of $b$ (i.e., independent of which message is chosen) unless $\mathcal{A}$ makes a query of the form $H(\star \| r)$ (since then both the commitment as well as all answers from the random oracle are uniform and independent); (2) the probability that $\mathcal{A}$ makes such a query is at most $q/2^n$.
