# Latex Tikz 作图

**Why use tikz?**

1. Tikz 能绘制一切你想要在论文中实现的效果. 例如，在文章中画一条线连接两个公式。
2. Tikz 直接使用 latex 进行编译，能够保证图片风格和文章本身一致.
3. Tikz 使用代码（坐标）对图片元素进行定位，能够保证图片内容的准确度.

**How to use tikz?**

> 使用 Tikz 最方便的做法是找到一个和想要实现的效果相似的例子，然后直接在例子的基础上进行调整. 如果在没有例子的情况下，想要直接实现. Good luck. :)

> 人话：TikZ 最好找现成例子改；没有例子从零画很难（“Good luck”是调侃）。
