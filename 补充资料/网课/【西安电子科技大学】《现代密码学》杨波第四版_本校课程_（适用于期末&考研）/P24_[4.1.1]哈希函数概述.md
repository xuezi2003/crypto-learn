## 一、什么是哈希函数？

哈希函数（Hash Function），又称**杂凑函数**或**散列函数**：
> 将任意长的消息 $M$ 映射成一个**固定长度**的短值。

$$h = H(M), \quad H: \{0,1\}^* \to \{0,1\}^t$$

| 中文名称 | 英文 |
|:--------:|:----:|
| 哈希值 | Hash Value |
| 杂凑值 | Hash Code |
| 消息摘要 | **Message Digest** |
| 指纹 | Fingerprint |

> **类比**：论文的摘要——不管论文多长，摘要都是固定的简短篇幅，但包含了论文的核心特征。

## 二、哈希函数的性质

### 2.1 基本要求

| 性质 | 说明 |
|:----:|:------|
| **易于计算** | 对任意输入 $x$，$H(x)$ 计算要**快** |
| **压缩性** | 任意长输入 → 固定长输出 |
| **单向性** | 已知 $h$ 求 $x$ 使 $H(x)=h$ 在计算上不可行（见 P25） |
| **抗碰撞性** | 找到 $x \neq x^{\prime}$ 使 $H(x)=H(x^{\prime})$ 在计算上不可行（见 P25） |

---

## 三、哈希函数的应用

| 应用 | 说明 |
|:----:|:------|
| **消息认证** | 验证消息未被篡改 |
| **数字签名** | 先哈希后签名，提高效率 |
| **口令存储** | 存储哈希值而非明文密码 |
| **数据完整性** | 下载文件时校验哈希值 |
| **区块链** | 每个区块包含前一区块的哈希值 |

### 在数字签名中的应用

先对消息 $M$ 求哈希 $h = H(M)$，再对 $h$ 签名——这样：
- 签名速度快（只需对短哈希值签名）
- 满足安全需求（哈希值可代表消息）

## 四、实际中常用的哈希函数

| 算法 | 输出长度 | 状态 |
|:----:|:--------:|:----:|
| **MD5** | 128 比特 | ❌ **已破译**（不推荐使用） |
| **SHA-1** | 160 比特 | ❌ **已理论破译**（不推荐使用） |
| **SHA-256** | 256 比特 | ✅ 安全 |
| **SHA-3** | 可定制 | ✅ 最新标准 |
| **SM3** | 256 比特 | ✅ 中国国家标准 |
