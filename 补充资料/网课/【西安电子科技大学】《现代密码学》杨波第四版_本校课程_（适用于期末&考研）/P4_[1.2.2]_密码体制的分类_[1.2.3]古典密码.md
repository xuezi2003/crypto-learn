## 一、密码体制的分类

### 1.1 两大类密码体制

| 分类 | 别名 | 特征 |
|------|------|------|
| **单钥密码体制** | 私钥密码体制、对称密码体制 | 加密密钥和解密密钥**相同**（或可容易相互推导） |
| **双钥密码体制** | 公钥密码体制、非对称密码体制 | 加密密钥和解密密钥**不同**，加密密钥可以公开 |

### 1.2 单钥密码体制的密钥管理问题

- 发送者和接收者必须拥有**相同的密钥**
- 在古典/近代密码中，可以通过事先协商或通过可靠信使传递密钥本
- 但在**大型网络**中，密钥管理成为巨大问题
  - 密钥管理 = 密钥的产生、分配、存储和销毁

#### $N$ 人网络中的密钥数量

- 每两个人之间需要一个**不同的**密钥（否则第三方可以解密）
- 总密钥数 = $\binom{N}{2} = \frac{N(N-1)}{2}$，即 **$O(N^2)$**
- 例：$N = 10000$ 人时，密钥数约 **5000万**个
- 保管、分配、存储、销毁都极其困难

### 1.3 双钥密码体制的优势

- 将**加密能力**和**解密能力**分开
- 加密密钥 = **公钥**（public key），可公开
- 解密密钥 = **私钥**（secret key / private key），需保护
- 每个人只需保护**自己的一个私钥**，与网络人数无关
- 实现**多对一**的通信：
  - 想给谁发消息 → 用谁的公钥加密
  - 收到消息后 → 用自己的私钥解密
- **不需要事先协商密钥或分配密钥**

> 公钥加密不具有认证性（因为任何人都可以用公钥加密）

#### 双钥体制的缺点

- 使用昂贵的公钥运算（如**模指数运算**）
- 效率较低，不如单钥体制

### 1.4 私钥密码体制的进一步分类

| 类型 | 特征 | 用途 |
|------|------|------|
| **流密码**（Stream Cipher） | 按字符或比特逐位加密，如 One-Time Pad（一次性密码） | 主要用于军事保密通信 |
| **分组密码**（Block Cipher） | 将明文划分为若干分组（如 128 位），一组一组加密 | 广泛用于商业应用 |

#### 流密码的挑战

- 需要产生与消息流**等长**且**完全随机**的密钥流
- 产生足够长且随机的密钥流是非常困难的

## 二、古典密码学

### 2.1 为什么要学习古典密码？

- 几乎所有古典密码现在都**已不安全**
- 但对理解、构造和分析现代密码算法**非常有用**
- 特别是理解**分组密码**的设计思想

### 2.2 古典密码的两大分类

#### 置换密码（Permutation Cipher）

- **明文字母本身不变**，只是**次序被打乱**
- 代表：斯巴达密码棒
- 类比：九阴真经被化成碎纸片——字母没变，但正确次序难以还原
- 数学描述：集合 A → 集合 A 的映射（排列）
- 26 个字母的置换方式有 ${26}!$ 种

#### 代换密码（Substitution Cipher）

- **明文字母被替代**，但**顺序不变**
- 数学描述：集合 A → 集合 B 的映射
- 分类体系：

```
代换密码
├── 单字母代换（L = 1）→ 类似流密码的思想
│   ├── 单表代换（映射 f 恒定不变）
│   └── 多表代换（映射 f 随位置变化）
└── 多字母代换（L > 1）→ 类似分组密码的思想
```

### 2.3 代换密码的数学定义

#### 符号约定

- 明文字母表：$\mathbb{Z}_q = \{0, 1, \ldots, q-1\}$
  - 例：英文26个字母 → $A \to 0, B \to 1, \ldots, Z \to 25$，即 $q = 26$
- 明文：长为 $L$ 的字母串 $(m_0, m_1, \ldots, m_{L-1})$，每个分量是 $\mathbb{Z}_q$ 中的元素
- 明文空间：$\mathbb{Z}_q^L$（向量空间）
- 密文字母表：$\mathbb{Z}_{q^{\prime}}$，密文空间：$\mathbb{Z}_{q^{\prime}}^{L^{\prime}}$
- 加密变换：在密钥 $K$ 控制下，$\mathbb{Z}_q^L \to \mathbb{Z}_{q^{\prime}}^{L^{\prime}}$ 的映射

#### 参数关系对密文的影响

| 条件 | 结果 |
|------|------|
| $q = q^{\prime}$ 且 $L = L^{\prime}$ | 构成**双射**（一一映射），密文无数据扩展 |
| $L < L^{\prime}$ | 一对多映射，密文有**数据扩展**（一般不希望） |
| $L > L^{\prime}$ | 多对一映射，类似**哈希函数**，明文数据被压缩 |

## 三、凯撒密码（Caesar Cipher）

### 3.1 基本原理

- 古罗马**凯撒大帝**发明的一种**单表代换密码**
- 将明文字母表**循环右移 $K$ 位**（通常 $K = 3$）
- 也称为**移位密码**（Shift Cipher）

#### 代换表示例（$K = 3$）

| 明文 | A | B | C | D | ... | X | Y | Z |
|------|---|---|---|---|-----|---|---|---|
| 密文 | D | E | F | G | ... | A | B | C |

- 用 D 替换 A，E 替换 B，...，C 替换 Z

### 3.2 数学公式

$$E_K(m) = c \equiv m + K \pmod{q}$$

$$D_K(c) = m \equiv c - K \pmod{q}$$

- $q = 26$（英文字母数）
- $K$ 为密钥，取值 ${0} \sim 25$
- $K = 0$ 时为恒等变换（无意义），实际可用密钥共 **25 个**
- 加密 = 右移 $K$ 位，解密 = 左移 $K$ 位

### 3.3 凯撒密码的优缺点

| 优点 | 缺点 |
|------|------|
| 加解密公式非常简单 | 所用语言是已知的，容易识别 |
| 易于理解和实现 | **密钥空间太小**，只有 25 个密钥 |
| | 容易用**穷举法**破译（暴力攻击） |
