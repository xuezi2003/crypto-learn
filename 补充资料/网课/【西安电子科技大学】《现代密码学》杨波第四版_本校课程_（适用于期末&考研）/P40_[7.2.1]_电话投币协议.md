## 一、问题背景

> 回顾课程最开始讲的 **Impossible Mission**——那些看起来不可能通过远程通信解决的问题。

**电话投币**：Alice 和 Bob 在电话中要通过"抛硬币"决定谁说了算（比如周末看电影还是听歌剧），但**双方互不信任**：

- 如果 Alice 抛硬币，Bob 会担心 Alice 作弊
- 如果 Bob 抛硬币，Alice 会担心 Bob 作弊

如何在没有可信第三方的情况下实现**公平**的远程掷币？

---

## 二、基于单向函数的电话投币协议

### 2.1 协议流程

```
Alice                          Bob
  │                              │
  ├─ 选随机数 x                  │
  ├─ y = H(x)（哈希值）───────→  │
  │                              ├─ 猜测奇偶：y 是奇数还是偶数？
  │  ←─── 猜测结果（如"偶数"）── │
  │                              │
  ├─ 公布 x 和 y                 │
  │  ────→ 验证 H(x) = y        │
  │                              │
  └─ 根据 x 的奇偶决定胜负      │
     （猜测正确则 Bob 胜）       │
```

### 2.2 安全性

- Alice 不能作弊：一旦提交 $y = H(x)$，就不能改变 $x$
- Bob 不能作弊：Bob 无法从 $y$ 推断 $x$ 的奇偶（哈希函数单向性）

---

## 三、基于承诺的电话投币协议

也可以使用**承诺方案**（Commitment Scheme）：
1. Alice 提交对 $x$ 的承诺 $c = \text{Commit}(x)$
2. Bob 猜测
3. Alice 打开承诺，验证结果

---

## 四、电话投币的意义

| 意义 | 说明 |
|:----:|:------|
| **公平性** | 没有任何一方能作弊 |
| **可行性** | 仅通过公开信道，不需可信第三方 |
| **示范性** | 展示了密码协议如何解决看似"不可能"的问题 |
