## 一、基于分组密码的 MAC（续）

使用类似 CBC 模式加密消息，取最后分组的部分比特作为 MAC：

```
P₁ → ⊕ → [E_K] → C₁
        ↑
      IV=0
              
P₂ → ⊕ → [E_K] → C₂
        ↑
      C₁

...

最后一个分组的密文最左 l 比特 = MAC
```

**问题**：对短消息，攻击者可能找到碰撞。

## 二、基于哈希的 MAC（HMAC）

**HMAC** 是目前最常用的 MAC 构造方法：

$$HMAC_K(m) = H((K \oplus opad) \parallel H((K \oplus ipad) \parallel m))$$

其中：
- $opad$：外填充（0x5c 重复）
- $ipad$：内填充（0x36 重复）
- $H$：哈希函数（如 SHA-256）

### HMAC 的优点

| 优点 | 说明 |
|:----:|:------|
| **通用性** | 可使用任何哈希函数 |
| **安全性** | 如果底层哈希函数安全，则 HMAC 安全 |
| **效率** | 仅比普通哈希稍慢 |

## 三、身份认证概述

身份认证的目标：**验证通信对方确实是他所声称的身份**。

### 身份认证的方法

| 方法 | 依据 | 举例 |
|:----:|:----:|:------|
| **你知道什么** | 知识 | 密码、PIN 码 |
| **你拥有什么** | 物品 | USB Key、智能卡 |
| **你是什么** | 生物特征 | 指纹、虹膜、面部（见 P36） |
| **你在哪** | 位置 | GPS 定位 |
| **你能做什么** | 行为 | 签名笔迹、步态 |
