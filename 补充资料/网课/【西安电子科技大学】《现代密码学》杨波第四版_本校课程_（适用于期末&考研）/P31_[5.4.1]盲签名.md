## 一、为什么需要盲签名？

在普通签名中，签名者必须**看到消息内容**才能签名。但在某些场景下，需要**保护消息的匿名性**：

- **电子现金**：银行对电子货币签名，但不应知道这笔钱花在了哪里
- **匿名投票**：投票人对选票签名，但不应暴露投票内容

> **电子现金的发展史，就是盲签名的发展史。**

---

## 二、盲签名的概念

盲签名（Blind Signature）允许：
1. **消息拥有者**将消息"盲化"（隐藏内容）
2. 签名者对盲化后的消息签名
3. 消息拥有者**去除盲化**，得到对原始消息的有效签名

**签名者看不到消息内容，但仍能签出有效签名！**

## 三、RSA 盲签名

### 3.1 流程

```
用户（消息 m）                  银行（私钥 d，公钥 e, n）
     │                                │
     ├─ 选择随机盲因子 r              │
     ├─ m' = m · r^e mod n ──────→    │
     │                                ├─ σ' = (m')^d mod n
     │  ←──── σ' ────────────────     │
     │                                │
     ├─ σ = σ' · r⁻¹ mod n
     │  (σ 是对 m 的盲签名)
     │                                │
     └─ 验证：σ^e ≡ m mod n ✅        │
```

### 3.2 关键性质

| 性质 | 说明 |
|:----:|:------|
| **不可追踪性** | 银行无法将签名与原始消息关联 |
| **不可伪造性** | 只有银行能生成有效签名 |
| **可验证性** | 任何人都可用公钥验证 |

---

## 四、盲签名的应用

### 电子现金

1. 用户从银行提取电子货币（银行盲签名）
2. 用户支付给商家
3. 商家验证签名后入账
4. 银行无法追踪谁在哪花了钱——实现了**匿名性**

### 匿名投票

1. 投票人对选票进行盲化
2. 选举委员会对盲化后的选票签名（验证投票资格）
3. 投票人去除盲化后提交选票
4. 任何人都可验证选票的有效性，但不知道谁投了谁
