## 一、RSA 简介

### 1.1 历史

- **RSA** = **Rivest, Shamir, Adleman**（MIT 三位数学家，1977 年）
- 1978 年正式发表，首次给出了**陷门单向函数的具体构造实例**
- 这是继 Diffie-Hellman（1976）之后，公钥密码领域最具里程碑意义的成果
- 早期也被称为 **MIT 体制**

### 1.2 特点

| 特性 | 说明 |
|:----:|:------|
| 可用性 | 既可用于**加密**，也可用于**数字签名** |
| 易懂性 | 仅需要基本的**模运算**知识即可理解 |
| 标准化 | 国际标准组织将其列为标准；RSA 公司后来成立并推广 |
| 专利 | 已于 2000 年到期，现在可自由使用 |
| 重要性 | RSA 年会是密码学领域最重要的国际会议之一 |

## 二、RSA 算法描述

### 2.1 密钥生成

```
① 选择两个大素数 p, q
② 计算 n = p × q
③ 计算 φ(n) = (p-1)(q-1)         // 欧拉函数
④ 选择整数 e（1 < e < φ(n)），满足 gcd(e, φ(n)) = 1
⑤ 计算 d ≡ e⁻¹ mod φ(n)         // e 模 φ(n) 的乘法逆元
⑥ 公钥 = (n, e)
   私钥 = d                     // p, q 可销毁
```

**参数要求**（当前）：
- $n$ 至少 **2048 比特**
- $p, q$ 为约 1024 比特的大素数

### 2.2 数学基础

**欧拉函数** $\varphi(n)$：

对于正整数 $n$，$\varphi(n)$ 表示 ${1}$ 到 $n$ 之间与 $n$ **互素**的整数的个数。

若 $n = p_1^{t_1} p_2^{t_2} \cdots p_l^{t_l}$，则：
$$\varphi(n) = p_1^{t_1-1}(p_1-1) \cdot p_2^{t_2-1}(p_2-1) \cdots p_l^{t_l-1}(p_l-1)$$

当 $n = pq$（$p, q$ 为素数）时：
$$\varphi(n) = \varphi(pq) = \varphi(p)\varphi(q) = (p-1)(q-1)$$

### 2.3 加密与解密

**编码**：将明文消息编码为 $[1, n-1]$ 中的整数 $m$，且要求 $\gcd(m, n) = 1$

**加密**（使用公钥 $e$）：
$$C = m^e \bmod n$$

**解密**（使用私钥 $d$）：
$$m = C^d \bmod n$$

### 2.4 正确性证明

为什么 $C^d \bmod n = m$？

$$
\begin{aligned}
C^d &\equiv (m^e)^d \equiv m^{ed} \pmod n \\
ed &\equiv 1 \pmod{\varphi(n)} \Rightarrow ed = 1 + k\varphi(n) \\
m^{ed} &\equiv m^{1+k\varphi(n)} \equiv m \cdot (m^{\varphi(n)})^k \equiv m \cdot 1^k \equiv m \pmod n
\end{aligned}
$$

最后一步使用了**欧拉定理**（或从群论角度：$m \in \mathbb{Z}_n^*$，群的阶为 $\varphi(n)$，由 Lagrange 定理得 $m^{\varphi(n)} = 1$）。

## 三、明文与 n 互素的问题

### 3.1 要求 $m$ 与 $n$ 互素的原因

如果 $m$ 和 $n$ **不互素**：
- $\gcd(m, n) \neq 1$
- 由于 $n = pq$，则 $\gcd(m, n)$ 只能是 $p$ 或 $q$
- 这样一来，攻击者就知道了 $n$ 的分解！密码系统就崩溃了

### 3.2 互素的概率

需要担心吗？**几乎不用**。

$m$ 与 $n$ 不互素的概率：
$$\frac{n - \varphi(n)}{n} = \frac{pq - (p-1)(q-1)}{pq} = \frac{1}{p} + \frac{1}{q} - \frac{1}{pq}$$

当 $p, q$ 为 1024 比特大素数时：
- ${1}/p \approx 2^{-1024}$（这个概率在物理世界几乎为 0！）
- 即使**刻意去取**一个与 $n$ 不互素的数，在不知道 $n$ 分解的情况下也几乎不可能

> **结论**：实际使用中完全不用担心 $m$ 与 $n$ 互素的问题。

## 四、RSA 的陷门单向函数

| 角度 | 公钥 $(n, e)$ | 私钥 $d$（或 $p, q$） |
|:----:|:--------------:|:---------------------:|
| 函数 | $f(m) = m^e \bmod n$ | 正向：加密 |
| 逆 | $f^{-1}(C) = C^d \bmod n$ | 逆向：解密（需私钥） |
| 陷门 | 无 | **知道 $d$ 可解密** |

**安全假设**：不知道 $n$ 的分解（即不知道 $p, q$）时，无法计算 $d$，因而无法解密。

---

## 五、思考题

> $\mathbb{Z}_n^*$（即 ${1}$ 到 $n$ 之间与 $n$ 互素的元素按模 $n$ 乘法构成的群）**是否是循环群**？

答案：**不是**（除非 $n=2,4,p^k,2p^k$ 等特殊情况）。

- 当 $n = pq$（$p, q$ 为大素数）时，$\mathbb{Z}_n^* \cong \mathbb{Z}_p^* \times \mathbb{Z}_q^*$，是两个循环群的直积——**直积不一定是循环群**
- 这一结论的严格证明可以参考毛文波的著作

## 六、RSA 算法总览

```
密钥生成
  p, q (大素数) → n = pq, φ(n) = (p-1)(q-1)
  e (公钥指数) → d = e⁻¹ mod φ(n) (私钥)
  公钥 = (n, e), 私钥 = d

加密
  C = m^e mod n

解密
  m = C^d mod n
```

> **核心**：RSA 的安全性基于**大整数分解的困难性**——没有有效的算法可以在多项式时间内分解大整数。
