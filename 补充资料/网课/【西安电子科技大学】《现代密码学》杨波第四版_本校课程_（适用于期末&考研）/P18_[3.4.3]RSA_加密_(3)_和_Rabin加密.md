## 第一部分：RSA 参数选择

### 一、素数 $p, q$ 的选择

#### 1.1 强素数（Strong Prime）

$p$ 称为强素数，需满足：

| 条件 | 说明 |
|:----:|:------|
| ① 存在大素数 $p_1$ 整除 $p-1$ | $p-1$ 含有大素因子 |
| ② 存在大素数 $p_2$ 整除 $p+1$ | $p+1$ 含有大素因子 |
| ③ 存在大素数 $r_1$ 整除 $p_1-1$ | $p_1-1$ 含有大素因子 |
| ④ 存在大素数 $r_2$ 整除 $p_2-1$ | $p_2-1$ 含有大素因子 |

**素数层级**：
- **一级素数**：$p$（强素数）
- **二级素数**：$p_1, p_2$（$p-1$ 和 $p+1$ 的大素因子）
- **三级素数**：$r_1, r_2$（$p_1-1$ 和 $p_2-1$ 的大素因子）

#### 1.2 其他要求

| 要求 | 原因 |
|:----:|:------|
| $p, q$ 足够大 | 防穷举分解（当前建议 ≥ 1024 比特，$n$ ≥ 2048 比特） |
| $|p-q|$ 要大 | 防 Fermat 分解（$p \approx q$ 时可通过估算 $\sqrt{n}$ 分解） |
| $\gcd(p-1, q-1)$ 要小 | 防迭代加密攻击（增大迭代周期） |

### 二、$e$ 的选择

| 要求 | 说明 |
|:----:|:------|
| $e$ 不能太小 | 防小加密指数攻击（$e \neq 3$） |
| $e$ 不能太大 | 太大会降低加密效率 |
| **推荐** | **$e = 2^{16} + 1 = 65537$**（二进制中只有 2 个 1，加密快又安全） |

### 三、$d$ 的选择

- $d$ 不能太小：Wiener 证明，若 $d < n^{1/4}$，可用**连分式算法**求出 $d$（Wiener 攻击）
- 实践中一般取 $d$ 与 $n$ 长度相近

### 四、共模问题

> **绝对禁止**为不同用户分配相同的 $n$——否则共模攻击可直接恢复明文。

## 五、大素数的生成

### 5.1 概率性素数检测

目前最常用的是 **Miller-Rabin 素性检测**：

| 特性 | 说明 |
|:----:|:------|
| 类型 | **概率性**算法 |
| 速度 | **非常快**（多项式时间） |
| 准确性 | 通过检测 → 极大概率是素数 |
| | 未通过检测 → 确定不是素数 |
| 漏网之鱼 | 合数通过检测的概率**非常小** |

**生成流程**：
1. 随机选择一个大的奇数（除 2 外所有素数都是奇数）
2. 用 Miller-Rabin 检测判断是否为素数
3. 若不是，重新选择

> 确定性素性检测（AKS 算法，2002 年由三位印度学者提出）也是多项式时间，但实际中 Miller-Rabin 更常用。

### 5.2 素性筛法

**Eratosthenes 筛法**是指数时间复杂度的，不适合大素数判定。

## 六、模指数运算

RSA 中最昂贵、最频繁的计算就是**模指数运算**（$a^m \bmod n$）。

### 6.1 平方-乘算法（Square-and-Multiply）

将指数 $m$ 二进制展开：
$$m = b_k 2^k + b_{k-1} 2^{k-1} + \cdots + b_0$$

算法：
```
result = 1
for i = k downto 0:
    result = result² mod n
    if bᵢ == 1:
        result = result * a mod n
return result
```

复杂度：$O(\log m)$ 次模乘（而非 $m$ 次）。

### 6.2 提高效率的技巧

选择 $e$ 的二进制表示中 **1 的个数少**，如 $e = 65537 = 2^{16}+1$（仅 2 个 1），可大幅减少乘法次数。

### 6.3 模指数运算的重要性

> **模指数运算的效率**直接决定了公钥密码体制能否实用。
>
> RSA 的模指数运算比对称密码的比特异或、循环移位等运算**慢很多**——这是公钥密码的固有特点，也是实际中**混合加密**（公钥加密会话密钥 + 对称加密数据）的原因。

## 七、RSA 模数长度演变

| 年份 | 破译的模数长度 | 说明 |
|:----:|:--------------:|:------|
| ~1996 | 129 位十进制（≈ 428 比特） | RSA-129 被破译，600 人、1600 台机器、8 个月 |
| 1999 | 512 比特（RSA-155） | 被破译 |
| 2009 | 768 比特 | 被破译 |
| ~2019 | 795 比特 | 被破译 |
| **当前建议** | **≥ 2048 比特** | 保证到 2030 年的安全性 |

> Rivest 曾悬赏 \$100 破译 RSA-129——象征意义远大于金钱价值。

## 第二部分：Rabin 加密体制

### 八、Rabin 加密简介

**Rabin 加密**由以色列科学家 **Rabin** 于 1979 年提出。

### 8.1 核心思想

- 基于**模平方根问题**：求 $m^2 \equiv C \pmod n$ 的解 $m$
- 安全性**完全等价于大整数分解问题**（RSA 尚未证明等价）

### 8.2 密钥生成

| 参数 | 要求 |
|:----:|:------|
| $p, q$ | 大素数，满足 $p \equiv 3 \pmod 4$，$q \equiv 3 \pmod 4$ |
| $n$ | $n = pq$ |
| **公钥** | $n$ |
| **私钥** | $p, q$（$n$ 的分解） |

### 8.3 加密

$$C = m^2 \bmod n$$

> 注意：在 RSA 中 $e$ 不能取 2（因为 $\gcd(2, \varphi(n)) \neq 1$），而 Rabin 直接使用平方运算，两者的数学结构完全不同。

### 8.4 解密

已知 $n$ 的分解 $p, q$，求解 $C = m^2 \bmod n$ 等价于求解方程组：

$$
\begin{cases}
m^2 \equiv C \pmod p \\
m^2 \equiv C \pmod q
\end{cases}
$$

- 对每个素数模，二次剩余方程有 **2 个解**
- 2×2 组合得到 **4 个可能的解**（通过中国剩余定理）
- 其中 3 个是伪消息，1 个是真正的明文

### 8.5 解决多解问题

从 4 个解中识别真正的消息 $m$：

- 利用**语义信息**：其他 3 个通常是乱码
- 也可以附加**鉴别信息**（如日期、发送者 ID 等）

### 8.6 Rabin vs RSA 对比

| 特性 | Rabin | RSA |
|:----:|:-----:|:---:|
| 加密 | $C = m^2 \bmod n$ | $C = m^e \bmod n$（$e \geq 3$） |
| 解密 | 解二次剩余方程 → 4 个候选 | $m = C^d \bmod n$（唯一解） |
| 安全性 | **完全等价于**大整数分解 | 未证明等价 |
| 签名 | **不能做数字签名** | 可以做签名 |
| 数据扩展 | 有（1 → 4 个候选） | 无 |

### 8.7 讽刺之处

> Rabin 虽然**严格证明**了安全性等价于大整数分解，但它在**主动攻击下非常脆弱**——因为攻击者可以利用解密 oracle 逐步逼近私钥信息。这说明**严格的数学证明 ≠ 实际安全**。
