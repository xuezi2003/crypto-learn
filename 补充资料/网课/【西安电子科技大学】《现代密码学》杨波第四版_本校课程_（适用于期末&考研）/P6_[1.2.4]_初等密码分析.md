## 一、密码分析学概述

### 1.1 定义

- 密码分析学（Cryptanalysis）是研究分析解密规律的科学
- 在**不知道密钥**的情况下，由密文推导明文或密钥

### 1.2 密码设计与密码分析

- **盾与矛**的关系——相克相爱，又相互促进
- 密码分析学帮助剔除不安全的密码，推动密码学发展

### 1.3 为什么能破译密码？

**香农**在1949年的《保密系统的通信理论》中首次透彻地阐明了这个问题：
- 根本原因：明文中存在**冗余度**
- 扩散和混淆不够充分时，冗余度在密文中有所保留

## 二、破译密码的方法

### 2.1 获取密钥（最困难但最致命）

- 密钥是密码系统的核心
- 密钥泄露后，无论密码方案设计多么好都无济于事
- 方法：间谍窃取、社会工程等

### 2.2 穷举法 / 暴力攻击（Brute-Force Attack）

- 密钥空间是**有限的**（不是无限的）
- 理论上：只要计算资源足够多、时间足够长，总能穷举出密钥
- 实际上：当密钥空间足够大时，穷举时间超出实际允许范围 → **计算上安全**
- 但当密钥空间较小时（如凯撒密码只有25个密钥），穷举法非常有效

### 2.3 确定性分析方法

- 利用数学知识，根据明文-密文对之间的**数学关系**
- 推导出等式，求出未知量（密钥）
- 对古典密码有效，对现代密码较难

### 2.4 统计分析方法

- 利用明文的**已知统计规律**
- 不同语言的字母出现频率不同（如英文字母中 E 出现最频繁）
- 字母组合也有频率差异（如 EA 频繁，ZOO 罕见）
- 利用频率分析进行破译

### 2.5 密码分析的艺术

> 破译密码需要知识、判断力、直觉，有时还需要运气。

**故事举例**：间谍潜入德军司令部找密钥，搜遍房间未果。观察到一个**不动的钟表**，时针分针秒针指向一个位置，猜测可能是保险柜密码。第一次用 `09:37:05` 不对，改为军用时间的 `21:37:05`，成功打开。

## 三、密码系统的攻击类型

攻击者（Adversary）拥有的**信息越多**，破译可能性越大。从弱到强：

| 攻击类型 | 攻击者拥有的信息 | 强度 |
|----------|------------------|------|
| **唯密文攻击**（COA） | 仅截获密文 | 最弱 |
| **已知明文攻击**（KPA） | 截获密文 + 一些已知的明文-密文对 | 较弱 |
| **选择明文攻击**（CPA） | 可访问**加密预言机**，选择明文并获得对应密文 | 较强 |
| **选择密文攻击**（CCA / CCA2） | 可访问**解密预言机**，选择密文并获得对应明文 | 最强 |

### 各攻击类型详解

#### ① 唯密文攻击（Ciphertext-Only Attack, COA）
- 敌手仅截获密文，试图推导明文和密钥
- 假设合理：公开信道上密文可被截获

#### ② 已知明文攻击（Known-Plaintext Attack, KPA）
- 除截获密文外，还获得一些已知的明文-密文对
- 可能来自以往的破译或其他途径

#### ③ 选择明文攻击（Chosen-Plaintext Attack, CPA）
- 敌手可以**有目标地**选择明文并获得对应密文
- 相当于可以访问**加密预言机**

#### ④ 选择密文攻击（Chosen-Ciphertext Attack, CCA / CCA2）

- **CCA1**（非适应性）：敌手可以选择一组密文获取解密结果
- **CCA2**（适应性）：敌手可以根据之前获得的解密结果**动态调整**后续选择
- 相当于可以访问**解密预言机**

### 为什么要把敌手假设为最强？

> "如果用小学生来测试密码系统，他没有攻破，是因为敌手不够强。只有最强的敌手仍然攻不破，才能说明密码系统是安全的。"

- 敌手不会在脸上刻着"敌手"两个字——他很可能是系统的**合法用户**
- 合法用户有时需要解密服务，系统必须提供
- 因此我们必须做**最强的安全假设**：考虑最强的敌手，做最弱的事情
- 例如：在不可区分性框架中，让最强敌手获得解密预言机，但只要求他判断**一个比特**的信息

> "有人说是用高射炮打蚊子，有没有意义？只要把蚊子打下来就有意义。"

## 四、安全性 vs. 效率的折中

- 密码方案设计需要兼顾**安全性**和**效率**
- 有些方案非常安全但效率太差（如一次性密码本）
- 有些方案非常快但安全级别不够
- 密码设计永远是安全性和效率的**折中**

## 五、本讲总结

### 保密学的体系

```
保密学（Cryptology）
├── 密码编码学（Cryptography）—— 设计密码（盾）
└── 密码分析学（Cryptanalysis）—— 破译密码（矛）
```

### 密码体制分类

- 单钥密码体制（私钥/对称）
- 双钥密码体制（公钥/非对称）

### 古典密码学的意义

- 虽然古典密码算法已不再安全，但其思想广泛用于现代密码学
- **代换**和**置换**形成了现代密码学的雏形
- 体现了香农密码学的核心思想：**扩散**和**混淆**
  - 扩散 + 混淆 → 充分破坏明文冗余度 → 密文不可破译
  - 一次性密码本（完全随机的密钥流）= 充分的扩散和混淆 → 理论安全性

### 破译方法

| 方法 | 描述 |
|------|------|
| 获取密钥 | 间谍窃取等 |
| 穷举法（暴力攻击） | 遍历整个密钥空间 |
| 确定性分析 | 利用数学关系推导 |
| 统计分析 | 利用明文频率特征 |

### 攻击类型（由弱到强）

COA → KPA → CPA → CCA → CCA2
