## 一、密码学的历史分期

密码学是一门**古老而年轻**的学科，大致可以分为三个阶段：

### 1.1 古典密码学（约公元前3000年 ~ 1895年）

> 年代划分不是非常严格，但基本如此。

- 古埃及的符号替换（特殊语言文字）
- 古希腊的隐写术、斯巴达密码棒
- 古罗马的凯撒密码
- **维吉尼亚密码**（Vigenère cipher）
- **Kerckhoff 原则**等

#### 古典密码的两大分类

| 类型 | 特征 | 数学描述 | 类比 |
|------|------|----------|------|
| **置换密码** | 明文字母**顺序**改变，字母本身**不变** | 集合 A → 集合 A 的映射（排列） | 20个学生排队，每节课排队方式不同，但人不变 |
| **代换密码** | 明文字母被**替代**，但顺序**不变** | 集合 A → 集合 B 的映射 | 每个人坐在一把椅子上，人和椅子形成代换关系 |

- 置换密码的变换方式有 $N!$ 种（$N$ 个字母的全排列数）
- 代换密码进一步分为：
  - **单字母代换**
    - 单表代换
    - 多表代换
  - **多字母代换**

> **注意**：置换密码和代换密码的本质区别——
> - 置换密码：字母不变，顺序变
> - 代换密码：字母被替代，顺序不变

### 1.2 近代密码学（1895年 ~ 1976年）

#### Enigma 密码机

- 由德国在**二战**期间使用的机械密码
- 深受德军青睐，是机械密码的典型代表
- **波兰数学家**截获并研究了 Enigma 密码机
- 德军随后对 Enigma 进行升级，对欧洲人民造成巨大损伤

#### 图灵与 Enigma 的破译

- 天才的英国数学家**图灵**（Turing）研制了一种破译机
- 成功破译了 **Enigma** 密码
- Enigma 的破译使得**二战缩短了约2~3年**（字幕中"缩短了8年"应为"缩短了至少2年"的识别误差）
- 图灵对人类的贡献巨大

#### 紫密（Purple Cipher）

- 日军使用的密码
- 1940年被破译

### 1.3 现代密码学（1976年 ~ 至今）

#### 划时代的开端

- **1976年**，**Diffie**（蒂菲/迪菲）和 **Hellman**（赫尔曼）发表了划时代的论文
  - **《New Directions in Cryptography》**（密码学新方向）
  - 被称为密码学中的"里程碑"
  - 开启了从**对称密码学**到**非对称密码学**的新纪元
  - 但论文中**并未给出**具体的加密算法构造

#### 现代密码学的重要里程碑

| 时间 | 事件 |
|------|------|
| 1976年 | Diffie 和 Hellman 发表《密码学新方向》，提出公钥思想 |
| 1977年 | **Rivest**、**Shamir**、**Adleman** 提出 **RSA** 算法 |
| 1977年 | 美国公布 **DES**（Data Encryption Standard）——**私钥**算法 |
| 1985年 | **椭圆曲线密码学**（ECC）被发明 |
| 1990年代 | Goldreich/Goldwasser/Micali（GM）提出**不可区分性和可模拟性**理论框架 |
| 1997年 | GGH 格基密码体制提出 |
| 1998年 | **DES** 被破译 |
| 2000年 | **AES**（Advanced Encryption Standard）——先进的加密标准公布 |
| 之后 | 全同态加密等新型密码技术被提出 |

## 二、密码体制分类

### 2.1 两大密码体制

密码学包括**密码编码学**（设计密码）和**密码分析学**（破译密码）。

现代密码学的核心是研究加密和破译的科学。

#### 私钥密码体制（对称密码体制 / 单钥密码体制）

- 加密密钥和解密密钥**相同**（或容易相互推导）
- 只有一个密钥
- **代表算法**：DES（1977）、AES（2000）

#### 公钥密码体制（非对称密码体制 / 双钥密码体制）

- 加密密钥和解密密钥**不同**
- 加密密钥可以公开，称为 **public key**
- **代表算法**：RSA、ECC

### 2.2 命名对应关系

| 私钥 | ↔ | 公钥 |
|------|---|------|
| 单钥 | ↔ | 双钥 |
| 对称 | ↔ | 非对称 |

## 三、密码的破译

### 3.1 密码编码学 vs. 密码分析学

> 做密码分析的人要**更聪明**——需要语言学、数学知识，有时还需要运气、敏锐的观察力和直觉。

两者是**矛与盾**的关系，相互促进。

### 3.2 密码破译的两种技术

| 方法 | 描述 |
|------|------|
| **确定性分析方法** | 利用已知信息和数学关系进行破译，主要依靠数学工具推导 |
| **概率性分析方法** | 利用明文和已知的统计规律进行破译 |

### 3.3 密码为什么能被破译？

- **香农**在论文中早已指出：因为明文中有**冗余度**
- 明文中的统计特征（如字母频率）在密文中会保留一定的关联度
- 因此可以利用统计规律进行密码破译

### 3.4 中国密码学家的贡献

- 中国密码学家**王小云教授**成功破译了 **MD5** 和 **SHA-1**
- 这是一个世界为之震撼的结果

## 四、量子密码学

### 4.1 量子计算的威胁

- 现有密码技术都基于**图灵机模型**，利用数论技术构造
- 如果**量子计算机**造出来，现有所有基于数论的密码学（包括 RSA、ECC 等）都将**不再安全**

### 4.2 后量子密码（Post-Quantum Cryptography）

- 密码学家可以构造**后量子密码学**来继续保护数据安全和网络安全
- **NIST**（美国国家标准技术研究所）于**2012年**开始后量子密码研究工作
- 后量子密码算法分为**四大类**：
  1. **基于编码**的密码
  2. **基于格**的密码
  3. **基于多变量**的密码
  4. **基于哈希**的密码

> 量子计算机造出来后，并非所有密码都不能用了，我们有新的密码技术来保护世界。

### 4.3 量子密钥协商

- 量子密码技术目前主要用于**量子密钥协商**（QKD）
- 通过量子密钥协商产生足够长的**完全随机**密钥
- 再与数据流做**比特异或运算**，可以达到**无条件安全**（One-Time Pad 的思路）
- 这对密钥分发提出了新的要求

## 五、本讲总结

1. **密码的起源**：中国古代虎符、阴符（饮血术）、藏头诗；古希腊斯巴达密码棒；古罗马凯撒密码——密码发展源远流长
2. **Impossible Mission**：四个例子展示了密码的无处不在，密码协议是信息时代的保护身符
3. **密码发展历程**：从古代、近代到现代密码学
4. **密码学与密码分析学**：矛与盾的关系，相互促进
5. **量子密码学**：未来密码领域发展的新方向
