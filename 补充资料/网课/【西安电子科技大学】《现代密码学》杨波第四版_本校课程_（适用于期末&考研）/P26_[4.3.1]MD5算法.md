## 一、MD 系列算法发展

MD = **Message Digest Algorithm**（消息摘要算法），由 **Ronald Rivest**（RSA 中的 R）设计。

| 版本 | 年份 | 输出 | 特点 |
|:----:|:----:|:----:|:------|
| **MD2** | 1989 | 128 比特 | 消息补位为 16 的倍数，需追加 16 位校验核，速度慢 |
| **MD4** | 1990 | 128 比特 | 分组变为 512 比特，速度快但易碰撞（PC 几分钟可破） |
| **MD5** | 1991 | 128 比特 | 在 MD4 基础上增强复杂性，一度广泛使用 |

## 二、MD5 算法流程

### 2.1 基本参数

| 参数 | 值 |
|:----:|:---:|
| 输入 | 任意长消息 |
| 分组长度 | **512 比特** |
| 输出 | **128 比特**（4 个 32 位字） |
| 轮数 | 4 轮，每轮 16 步 |

### 2.2 处理步骤

```
① 消息填充
   在消息末尾添加 1 个 "1" + 若干 "0"
   使总长度 ≡ 448 mod 512
   最后附加 64 比特的原消息长度
   → 总长度是 512 的整数倍
   
② 初始化缓冲区
   A = 0x67452301
   B = 0xEFCDAB89
   C = 0x98BADCFE
   D = 0x10325476

③ 处理每个 512 比特分组
   4 轮循环，每轮 16 步
   每步使用非线性函数 F, G, H, I

④ 输出
   最终 A, B, C, D 拼接为 128 比特哈希值
```

### 2.3 每轮的非线性函数

| 轮次 | 函数 | 运算 |
|:----:|:----:|:----:|
| 第 1 轮 | $F(B,C,D) = (B \land C) \lor (\lnot B \land D)$ | 选择函数 |
| 第 2 轮 | $G(B,C,D) = (B \land D) \lor (C \land \lnot D)$ | 选择函数 |
| 第 3 轮 | $H(B,C,D) = B \oplus C \oplus D$ | 异或 |
| 第 4 轮 | $I(B,C,D) = C \oplus (B \lor \lnot D)$ | 异或-或 |

## 三、MD5 的安全性

### 3.1 破译历史

| 时间 | 事件 |
|:----:|:------|
| 1996 | 发现 MD5 的设计缺陷 |
| 2004 | 中国学者**王小云**提出**模差分攻击**，可在数小时内找到 MD5 碰撞 |
| 2007 | 可在普通 PC 上找到 MD5 碰撞 |
| 2012 | 碰撞可在数秒内完成 |

### 3.2 当前状态

> **MD5 已被完全破译，不应用于任何安全场景。**

但仍可用于：
- 非安全目的的校验和
- 旧系统的兼容（但应尽快迁移）

## 四、MD5 vs SHA-1 vs SHA-256

| 算法 | 输出 | 生日攻击复杂度 | 安全性 |
|:----:|:----:|:--------------:|:------:|
| MD5 | 128 比特 | ${2}^{64}$ | ❌ 已破译 |
| SHA-1 | 160 比特 | ${2}^{80}$ | ❌ 已理论破译 |
| SHA-256 | 256 比特 | ${2}^{128}$ | ✅ 安全 |
